# 回应 GPT 第四轮：证据顺序耦合在新 root 上复现，且三个父模型共有

2026-11-02 · Louis

## 一句话

GPT 这一轮的修正我基本全部接受：剂量上界是我算错了（我把 GLOBAL 的最大值 0.4375 套到了每个成功数 m 上；正确上界是 λ(1−1/(8−m))，m=7 时为 0，我用冻结逻辑穷举复核，与 GPT 的表逐位一致）；94% 的 G8 暴露率撤回；"参照系错误已定位"收紧为"证据顺序—选择耦合的机制假说"；全局 L 不是正确的变量。

但 GPT 要的样本外检验，现有数据里就有。SR-F6 普查（census）用的是同样三个父模型（SRF2_J6 s71001/2/3），每题 8 次回答来自同一个冻结策略（真正的 G8），16 个有边界平局的 root 与 DEV、训练集都不重叠，而且提示里没有类别列表，打印顺序只能从图上读。在那里，上一轮冻结的预测规则（"取自己证据里排在前面的平局项"）原样复现：三个父模型分别解释 91%、97%、85% 的平局选择；同题同策略内，平局块按打印顺序列出的那些 draw 选对的概率高 54–79 个百分点；以 root 为单位，方向一致的 root 分别是 13/14、8/9、10/12。

**结论的范围必须改：这不是 b1 的错误，是三个 J6 父模型共有的做法。** 普查里 TIES 家族的平局准确率 b0 0.47、b1 0.48、b2 0.60，b0 与 b1 没有差别。b0 在先导 DEV 上的 0.96，发生在提示里的 EVIDENCE CHECKLIST 按打印顺序给出类别、b0 几乎全照这个顺序列证据的条件下。我上一轮只训练 b1、把 b2 当阴性对照的设计作废。

下一步仍然是一次不更新参数的探查，在 GPT 的 C0/C_REF/C_PRINT/C_ALT 之上加两样：去掉类别列表的 C_NOLIST（检验 b0/b2 的正确是否依赖这份列表），以及 GPT 提出的前缀干预——不再作为条件式补充，而是同批跑，因为观测耦合已经在新 root 上复现，剩下的只有因果问题。C_ALT 改成"字母序与打印序一致/冲突"各半的平衡 root，预测是一个交叉。三个父模型都跑，共 3,456 条推理。

## 新证据：普查上的样本外检验

普查在先导之前完成：9,216 条回答，3 个父模型×384 题×8 次，每题 8 次来自同一个冻结策略。三个父模型在普查和先导配置里都是 SRF2_J6_s71001/s71002/s71003。DEV_CAL 的世界与 DEV_EVAL、DEV_PILOT 精确重叠数为 0。普查提示是 v1（srf6_ref/design.py 的 visible_prompt）：写了 "Break ranking ties by printed left-to-right order"，但没有类别列表，打印顺序只在图上；先导的 EVIDENCE CHECKLIST 是之后的 interface-v3 才加的。

边界平局题共 68 道、跨 16 个 root（TIES 51 题/8 root，SIGNED 12/5，IMPACT 3/2，BINDING 2/1），每个父模型 544 条，97–99% 解析出可用的平局选择。预测规则是上一轮在 DEV 上写下的，没有改动。

一个典型对子（同一张图、同一提示、同一策略）：b0，DEV_CAL_IMPACT_0002_P0_v1，打印顺序 Vase, Mug, Clock, Chair, Lamp, Desk，Vase 与 Desk 的 Alpha 都是 48，只取一个。draw 0 先列 Vase → 选 Vase（对）；draw 6 先列 Desk → 选 Desk（错）。

列举习惯（普查，排序系列 ≥ 3 条）：按打印顺序 b0 14%、b1 2%、b2 24%；按数值排序 42%、66%、38%；其余是其他顺序。数值排序的列表里，等值块保持打印顺序的比例是 66%、51%、66%，倒序 18%、24%、15%。也就是说，三个模型在平局处得到的顺序基本来自它们怎么列单，而不是图上的位置。

边界：这仍然是观测。普查提示与先导提示的差别不只是类别列表（证据要求、格式说明也不同），所以 0.96 对 0.47 不是"列表的作用"的干净估计；探查里的 C_NOLIST 才是。站得住的是同题同策略内的耦合和它在独立 root 上的复现。

## 这改变了什么

**诊断变了：一个共有的程序，加上各自不同的列单习惯。** 三个父模型都按"自己列出的平局项顺序"破平局（以下简称这个程序）。列表恰好是打印顺序时，它给出正确答案。先导提示的类别列表把打印顺序写进了文本，b0/b2 照抄（DEV 里 98% 按打印顺序列举）所以对；b1 更多按数值排序，而它在数值排序里的平局顺序一半不是打印顺序，所以错。b1 在 DEV 上可见的缺口是列单习惯的差别，不是它独有的规则错误。b0 在 DEV 上的正确很可能以这份列表为条件，待 C_NOLIST 与 C_ALT 检验。

**J 为什么没修它。** 先导训练的真 G8 里，边界平局题 S 在组内有差异的比例是 b0 28%、b1 57%、b2 59%。J 修好了 b2 的平局错误（DEV 0.79→0.96），而 b2 父模型在 DEV 上本来就 98% 按打印顺序列举——它的错不是这个程序造成的。b1 有同样多的信号，12 步 J 和 J+S 都没动（0.54→0.50–0.57）。也就是：J 修了不是这个程序造成的错，没修这个程序造成的错，即使组内有信号。对 b0 而言，训练提示下几乎没有可修的。

**数值排序是有用的习惯，不该被惩罚。** 普查里非平局 top-k 题，数值排序列举时选择正确 99%，打印顺序 92–95%，其他 82–90%。J 训练把 b1 在 DEV 非平局 TOPK 题上的列举从打印顺序 32% / 数值排序 35% 推到了 16–20% / 48–49%。一个未经检验的解释：J 在大量非平局题上偏好数值排序，平局块内的顺序对 J 不可见。所以正确的做法是"按数值排序、等值保持打印顺序"，全局 L 这个支架会和有用的习惯打架。

**测量指向的是语境决定，而不只是标签决定。** 在训练提示下，这个程序对 b0 是看不见的，对 b1 是看得见但 12 步没动。在把列单顺序与打印顺序分开的语境里（去掉列表，或强制别的列单顺序），它会制造大量组内差异：普查真 G8 里，平局选择正误在组内有变化的边界题比例是 b0 85%、b1 56%、b2 82%。这正是 GPT 自己写下的分支："如果证据显示问题在正确行为支持而非反馈内容，另立一个支持/探索实验"。它也满足 GPT 的另一个要求：不约束正常的替代解法，数值排序仍然合法。

这也把前几轮的空结果接上了一点：加项的公式、剂量、步数都不是第一限制；训练分布本身把剩下的语义捷径藏起来了（b0）或只给了很少的机会（b1：每臂 12 步共约 36 个边界平局组）。

## 回答 GPT 的八个问题

**1. 收紧为机制假说，写明 4 个 root 的限制？** 接受。现在的准确表述是：在 4 个 DEV root 上发现、在 16 个独立 root 和真 G8 上复现的观测耦合，三个父模型都有；因果未定。

**2. 全局顺序、同值块顺序、最终集合分开？** 同意，并撤回全局 L。普查证明它是错的变量：b1 全局 L 只有 2%，平局块按打印顺序时却 98% 选对。

**3. 加一个同样规范但顺序不同的主动对照？** 接受，并改成平衡交叉。字母序在一半 root 上与打印顺序给出同一平局决策、在另一半上冲突。如果列单顺序决定选择，C_ALT 下一致 root 高、冲突 root 低，C_PRINT 下两组都高。一致 root 本身就是"C_ALT 是否只是让任务变难"的对照。三个父模型都跑：如果 b0 在冲突 root 上也跟着字母序错，它在 DEV 上的 0.96 就来自列举顺序。

**4. C_PRINT 有效后是否需要前缀干预？** 需要，而且建议同批跑。观测耦合已经在新 root 上复现，剩下的只有因果问题，前缀是最直接的检验：同一组真实排序单元格按数值排序，只把平局块正序或倒序，其余全同——这就是 GPT 6.4 节的设计。576 条短续写。无关非同值项的 placebo 可选。

**5. 采用按同 J 层大小更正的上界，撤回 94%？** 都接受。真 G8 的数字：普查提示下，平局块顺序在组内有差异的边界题比例是 b1 40%、b0 69%、b2 77%；全局 L 在所有 TOPK 题上是 8%、40%、56%。先导提示下的真 G8（训练行）只有 S，没有文本；b1 边界题 S 在 57% 的组内有差异。训练语境下的值靠干跑实测。

**6. 若要证明"诊断选中了更合适的标签"，同步数同重复重跑 S/B？** 如果要做标签主张，同意。但新证据把决定从标签移到了语境：b1 有组内信号、J 与 J+S 都没动；b0 在训练提示下没有可修的错。我建议训练比较的是三个决定（R、M、D，见训练一节）；S/B 臂只在要做标签主张时加。

**7. 用 A 和未见参照/自然接口表现作学习成功依据？** 同意。主终点是新 root 上的答案准确率，分别在原提示、去列表、训练中没出现过的列举约束（例如按 Beta 列）和自然接口下报告；S 次要；平局块顺序只作机制指标；对照臂不设"必须不动"。

**8. 作为第一个闭环病例，不收窄整个项目？** 同意。新证据让它更贴近原问题：三个 J6 父模型共有、答案正确时可能掩盖、J 在训练语境下看不见或看见了也没动的一个程序性捷径。平局只是它的第一个实例。

## 修改后的探查

不更新参数；三个父模型；48 个新 root（四种边界平局结构各 12 个：二向取 1、三向取 1、三向取 2、四向取 2；每种结构里 6 个 root 的字母序与打印序给出同一平局决策，6 个冲突）。题目、图、公开列表和 oracle 在任何生成前冻结；旧 DEV、普查和训练数据只用于提出假说，不用来挑 root。

| 条件 | 改什么 | 若列举顺序决定选择（H1） | 若列举只是伴随信号（H2/H3） |
|---|---|---|---|
| C0 | 先导原提示（含类别列表） | b0≈0.95，b1≈0.55，b2≈0.8–0.9 | 同左 |
| C_NOLIST | 只删去列表里的类别名，保留"为图中每个类别报告 Alpha" | 三个都降到普查水平 0.5–0.65 | b0/b2 不降 |
| C_REF | 平局句明确为"x 轴从左到右的位置，即公开列表的顺序" | 不确定，取决于规则澄清能否覆盖列单 | 不确定 |
| C_PRINT | 加一句"排序证据按打印顺序列" | 三个都 ≥ 0.9 | ≈ C0 |
| C_ALT | 加一句"排序证据按类别名字母序列"，长度、语气与 C_PRINT 匹配 | 一致 root ≥ 0.9，冲突 root ≤ 0.3，三个父模型都如此 | 一致 ≈ 冲突 ≈ C0 |
| P_STABLE | 前缀：全部真实排序单元格按数值排序、平局块按打印顺序，模型续写其余 | ≥ 0.9 | ≈ C0 |
| P_REVTIE | 同 P_STABLE，只把平局块倒序 | ≤ 0.3，且 ≥ 70% 选前缀里排在前面的平局项 | ≈ P_STABLE |

规模：自然生成 5 条件 × 48 root × 4 draw × 3 父 = 2,880；前缀 2 条件 × 48 × 2 draw × 3 父 = 576；共 3,456 条（GPT 版为 2,304）。多出的 1,152 条回答两个问题：b0/b2 的正确是否依赖类别列表；列举顺序在因果上是否足以决定选择。前缀用现有的 assistant prefill 接口（现在是 "{"），只是更长，在生成前固定。

分析：以 root 为单位，同 root 跨条件配对；按分配条件分析全部回答，另报列单服从率；A 与 S 同时报告；平局块顺序只作机制指标，不在干预后的 L 子集上比较正确率。交叉效应 = [C_ALT(一致) − C_ALT(冲突)] − [C_PRINT(一致) − C_PRINT(冲突)]，24 对 24 个 root；前缀效应按 root 配对。表中数字是预测，不是门槛；零、反向、不确定都照实报告。

**结果怎么改变下一步**

| 探查结果 | 含义 | 下一步 |
|---|---|---|
| C_ALT 交叉、P_REVTIE 跟随前缀、C_NOLIST 让 b0/b2 下降 | 共有程序成立，b0/b2 的正确依赖列表 | 训练比较 R/M/D，D 的语境含去列表和强制列单 |
| 交叉与前缀跟随成立，C_NOLIST 不降 | 程序存在，但训练提示里的列表不是关键 | D 只用强制列单语境 |
| C_ALT 不交叉、P_REVTIE 不跟随 | 列举顺序是伴随信号 | 不做任何 L 类支架；D 只保留去列表语境，前提是它仍制造组内差异 |
| C_PRINT 或 C_REF 让三个都 ≥ 0.9 | 存在提示修复 | 先承认提示方案；训练只为撤提示后的稳健性服务 |
| C_NOLIST 不降、也无交叉 | 普查与 DEV 的差距来自 root 或其他提示差异 | 这个病例只剩 b1 的列单习惯，不值得训练；回到更宽的方案找第二个缺口 |

## 探查之后的训练（条件式，不是授权）

如果决策表第一或第二行成立，训练比较三个决定，其余全部相同：同父模型、同 seed、同步数、同 RL 载体、同 J、同题目与顺序。

| 臂 | 由什么决定 | 改什么 |
|---|---|---|
| R | 不用诊断 | 原提示、原题目配比，继续 J |
| M | 边际诊断：家族 A/J/S 显示 TIES 最弱 | 原提示下提高 TIES 占比（例如 1/6 到 1/3），总题数不变 |
| D | 联合诊断：列单顺序决定选择 | 同题目、同顺序，提示模板按探查结果抽样（例如 50% 原提示、25% 去列表、25% 强制列单约束） |

D 对 R、M 对 R 各是单因子；D 对 M 就是 GPT 要的"诊断信息的决策价值"。这次两种诊断确实作出不同的决定：边际统计对 b0 根本不会选 TIES（DEV 0.96），对 b1 会选更多 TIES；联合诊断对三个父模型都选去耦语境。所以这个比较有内容，不是同一个决定的两个名字。标签路线（J+稳定排序信用，或同步数的 S/B）不在最小设计里，只在要做标签主张时加。

**操纵检查（登记，不当门槛）**：TIES 训练组里 J 有组内差异的比例。R 预期与先导相当，D 预期接近普查语境里的 56–85%。干跑一步就能实测。如果 D 没有把这个比例提上去，这次比较没有发生。

**终点**：另一批新 root（不同于探查的 48 个）上，原提示、去列表、训练里没见过的列单约束（例如按 Beta 列）和 P_REVTIE 前缀下的平局答案准确率；自然接口；非平局 TOPK 和其他家族的保持，用预登记的不劣区间。

**规模算例**：每路径 24 步 × 128 = 3,072 条。b0+b1 × 2 seed × 3 臂 = 12 路径 = 36,864 条；三个父模型 = 18 路径 = 55,296 条。用哪几个父模型由探查决定：只用在 C_NOLIST/C_ALT 下显示出这个程序的。
