# 00｜为什么做这一轮：从诊断价值到实际学习价值

## 0.1 固定研究问题
原始科学动机是“答案变对是否意味着感知和推理更可靠”。当前方法主线是：代表性且可辨识的题组 → 可验证语义行为测量 → 判断信息是否有用 → 奖励/信用/on-policy训练 → 未见变化下泛化与能力保持。

J/J6 已经检查答案、真实且充分的证据、协议与生成完成。本轮不是从无语义奖励到有语义奖励，而是在已有语义约束上检验新增信息。不要说“J是纯结果奖励”，也不要把本轮负结果说成“所有语义信息无用”。

## 0.2 当前事实与假说分开
|已有材料支持|本轮尚待验证|
|---|---|
|F4-C 严格信用只有2/576组，12条回答，集中最后一步|更可靠仪器是否在后续策略上持续提供信号|
|只有1组能在同J/P层交换出差异|SHUF是否形成足够、贯穿训练的真实对照|
|J=1内存在错误选择/过程声明与正确答案共存的病例|这些标签是否预测受控相关题失败，并可被训练修复|
|宽容解析原型等号截断会读错正确名单|本包新字段提取是否稳定并覆盖真实输出|
|89非零组≠60可交换组≠43次实际改变|新的信号量能否产生可重复能力收益|
|J0的51条正信用中，30条答案已正确、21条错误|哪一种行为状态的信用贡献了什么变化|
|历史单更新代码 ratio=current/current.detach()，前向恒1|真实GPU概率路径和梯度是否与参考实现一致|

宽容重放只能作为设计线索，不作为新的金标或确定的选择能力趋势。新增协议同时改变了可观测接口，因此本轮只在新共同协议内识别奖励/信用效应；不与旧 C 的百分点直接作因果比较。

## 0.3 预登记研究假说
H1：LOCAL 在未训练语义组合上的答案准确率优于共同协议 J。
H2：LOCAL 优于 HARD，说明收益不只是增加一个二元成功条件。
H3：LOCAL 优于 SHUF，并有实际交换记录，支持正确语义对应的价值。
H4（机制性次要）：LOCAL 相对 DENSE 的差异反映信用在序列中的分配方式，不证明内部能力模块隔离。
H5（行为性次要）：改善不局限于声明正确，而体现在配对变化、自然接口或外部保持。

H1成立而H2不成立：可以支持“信息帮助”，不能支持复杂局部机制优于简单联合验证。H3不成立不自动否定全部信息价值；如果交换机会不足，应报告对照识别不足。H1不成立而声明正确率上升：只证明输出审计性提高，不能声称能力改善。

## 0.4 本轮有意不做什么
不同时引入教师CE、动态题目分配、新模型、更大G、learned verifier或跨题关系奖励。这些会把信息内容与训练机制混在一起。

题组关系在本轮用于设计和独立行为验证，**不进入本轮优化目标**。这不是放弃题组价值，而是先区分“选择信息本身是否有用”。若以后研究跨题关系信用，需要另一个同题组/同预算的随机化对照，不得把本轮结果写成已经证明跨题奖励有效。

## 0.5 成功的最低含义
必须同时知道：标签测了什么、它何时改变了目标、实际更新是否持续、独立新组合表现是否改善、原有能力是否得到保持。只有更高的解析覆盖、更多非零信用或更高奖励分，都不是最终成功。
