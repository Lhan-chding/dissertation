# 01｜方法不是不断叠加条件：用五臂拆开不同解释

## 1.1 三个层次的分数
A：最终数值答案是否按冻结精确规则正确。
J_legacy_projection：移除新增 selected 字段后，用历史 scorer 评分，用于兼容性审计。
J_M3：新共同协议的结构有效、生成完成、答案正确、证据真实且充分的联合事件。

**J_M3 不检查 selected 的集合大小是否等于k、是否选对类别、是否与计算吻合。**这些是额外语义条件。所有臂共用 J_M3 的格式要求，避免“只有新方法能被解析”的不公平对比。

S：在严格可解析的最终 selected 字段中，集合是否等于 oracle 最终集合。只规范化标签两端空白与大小写，不纠正拼写；顺序不重要；重复、遗漏、额外对象或错误标签都是已知 FAIL；字段缺失/非法才是 UNKNOWN。它是“声明的最终对象集合”，不是模型内部思维。

## 1.2 五臂的唯一差异
- **J**：用 J_M3 的组内标准化优势；无语义辅助。
- **HARD**：把奖励改为 J_M3 × 1[S=PASS]，重新以该二值奖励计算原生优势。没有辅助局部项。
- **DENSE**：保留 J 的优势，添加中心化 S 信用，分配至整条生成回答。
- **LOCAL**：保留相同 J 优势、相同 S 信用，改为分配至 selected 数组原始token。
- **SHUF**：与 LOCAL 相同，但 S 在同一道题、同J、同P层内均匀置换一次。

P仍记录“已提交非空事实是否全真”，不代表完整感知。P可以取UNKNOWN，作为置换层的一个值；它不再是选择信用的准入条件。不存在新的 EVID 训练臂，因为旧分布下该通道没有实际差异；这不意味着感知研究已经解决。

## 1.3 为什么保留 HARD
单纯要求“答案、证据、选择都正确”是自然且强的替代解释。如果它效果相同或更好，就应该采用或进一步研究简单方案，而不是把局部方法包装成必需。

HARD会把部分原J1改为0，可能使组更稀疏或产生新分歧。这是其设计的一部分，不能为了“公平有效组数”替它补采数据，或把全0组删除。

## 1.4 为什么 DENSE 不能省
没有 DENSE，LOCAL 优于 J 只能说明整体新方案有效，不知道是否需要token定位。DENSE与LOCAL用同一可判集K和同一信用，都是每条回答的辅助系数总质量为c_i。LOCAL按局部长度归一，DENSE按全长归一；因此这比较的是信用分布而非严格等梯度范数。不得声称单独隔离“位置效应”而完全排除了梯度尺度。

## 1.5 SHUF 的含义与限制
置换层为 `(qid, J_M3, P)`。允许原样置换；不得反复抽直到标签变了。保持每层S计数和原生奖励关联，不保证保持真实梯度范数或优化难度。它是语义对应关系的破坏对照，不是完美的“零信息但无伤害”对照。

同时记录：非零信用组、可交换组、实际信用变化组、变化回答数、涉及独立root/家族/时间窗。LOCAL−SHUF的优势若只有在SHUF明显劣于J时出现，要明确“可能主要由破坏性控制退化造成”；仍须检查LOCAL−J与LOCAL−HARD。

## 1.6 哪些问题本轮不能回答
没有新的A-only臂，因此不把结果归因为“有语义优于完全无语义”。没有随机位置但长度匹配的辅助臂，因此不声称局部选择位置具有独一无二的因果作用。没有改变题组构造的独立训练臂，因此不能从所有臂共享题组后的涨分宣称“题组构造的独立贡献已经验证”。

这些不是通过添加越来越多臂一次解决。本轮只求一个可解释的学习证据，后续按具体正面或负面结果选择最必要的对照。
