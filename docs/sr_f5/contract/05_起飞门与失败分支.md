# 05｜起飞门：让“方案已实现”与“方案真的被检验”分开

以下数值是本次**工程/可实施性准则**，不是理论上普适的语义价值阈值，也不是显著性检验。全部在正式实验前冻结。不能看过正式效应后降低门槛。

## G0｜来源、身份与优化合同
必须有：原CONFIG与父路径核对、代码commit、依赖版本、trainable参数清单、reference身份、原生J/损失投影等价、无未知字段。不得重新扫描全部基模权重做多余哈希；复用登记snapshot身份，对adapter和必要小文件保存已具备摘要/大小/commit。

源码核验必须明确实际ratio恒1、一次optimizer step、KL出现一次、padding/prefill排除、旧奖励条件。发现与本包假设不符，先更新实施映射与测试，不猜测。

## G1｜CPU、数学与图像
必过：所有单元测试、双oracle逐题一致、主面板有限小数条件、全部训练家族holdout扫描、世界/谱系不跨split、提示无gold字段、selected正确性不进入J、masked梯度边界与SHUF条件、128分母、重复恢复fixture。

渲染检查包括实际processor尺寸下标签可读、同值/颜色legend唯一、印刷顺序无歧义。程序输出真实reviewer类型；如果只有自动几何检查，不能写“已经人眼确认全部图片”。

## G2｜真实父模型普查：4608条，禁止跳过
3父模型×192 DEV_CAL题×G8=4608回答。新提示、新scorer、新tokenizer跨度全部使用正式候选实现；无更新。每父模型192组，每家族32组。旧文本全UNKNOWN的重放不可以替代G2。

每父模型要求：
- 完整结构可观测S比例≥90%，每家族≥80%；mask成功比例在结构已知回答中≥99%。
- 非零语义信用组≥20/192；同J/P可交换组≥10/192；登记单次置换实际变化组≥5/192。
- 非零信用覆盖至少4/6家族、12个独立root；不能由一个特殊root重复8次撑起。
- 截断比例≤2%；存在精确可评分回答，单位/分数解析不存在系统错误。
- 360唯一回答的结构/标签/跨度核对无未解释系统分歧；全部已知bug成为回归夹具。

同时报告全0/全1/混合J、A×J×S状态、P已知率、各项信用量。**不要求某个固定J0正信用比例**；成功答案中的不可靠选择是研究对象，不是无价值声明噪声的同义词。

这些门用于判断此五臂设计是否有足够的实际比较机会，不代表0.25或72步必然产生效应，也不证明“所有语义方法都需要这些比例”。

## G2失败后的定向决策
- S覆盖低：先查新字段提示、top-level parser和生成停止规则。不要用gold引导自由文本抽取，也不要悄悄开启语法约束。修复/改协议只在开发版本，重新跑完整普查。
- mask低：修实际token decode/边界映射，不能重分词补造跨度。
- S全PASS或全FAIL但覆盖高：这是当前分布的行为结果；先按家族看系统性规则误解与碰撞结构。不能逐题挑“八次有差异”的样本进入训练。
- 非零多、交换少：当前信息主要与J同向；DENSE/HARD仍可能有价值，但本轮预指定LOCAL−SHUF识别不足。冻结失败报告，不冒充已满足五臂机制验证。
- 截断高：检查冗余声明与证据负担，不将预算不足写成能力不足。任何改max_tokens须新开发版本并全臂一致。

最多一次登记的开发配方修订：必须说明具体原因、改变哪一部分、其他部分为何仍一致，使用新DEV_CAL/DEV_PILOT种子，保留v1结果。第二版种子固定为 `seed_for(master_seed, "recipe_v2", split)`（函数见generator.py）；其config必须在新采样前落盘，不能反复试seed。不是“失败就一直改到成功”。第二版仍不通过则本次停止在方法可实施性诊断，不启动正式矩阵。

## G3｜12步开发先导：23040条，不拿效果选赢家
3父模型×5臂×12步×128=23040回答，独立DEV_PILOT库；不继承到正式训练。主要检查连续信号和数值实现，不以哪个臂准确率最高挑λ/步数/题型。

LOCAL每父模型的三个4步窗口均至少4个非零组；SHUF每窗口至少2个实际改变组；整段信用覆盖≥4家族和≥12root。LOCAL和SHUF都必须出现“非零更新→下一步各自生成→后续仍有干预”，不能只在末步触发。

S可观测性不低于父模型90%门的主要标准；低于标准先说明是协议崩塌、系统性标签错误还是方法行为。只有测量错误可当技术修复；方法把模型推向无法观测状态本身是负面结果。

检查所有臂的：全序列loss等价、实际非零梯度、J/HARD真实奖励不同、DENSE/LOCAL用相同公式、SHUF独立随机流、单次step和恢复、采样/训练/reference概率尾部。效应大小和统计显著性不是G3通过条件。

## G4｜正式冻结
数据与图像、协议、scorer、mask、loss、优化器、生成参数、步骤/重复、全部评价与统计、数据随机种子、代码commit、环境身份形成 `FROZEN.json`。确认测试模型输出尚未生成。门回执NOT_RUN不能填成PASS。

`launch_guard.py`只检查回执完整性，不保证回执内容真实；Codex仍需绑定可追溯证据文件。formal manifest和gate hashes改变则不可继续旧run。

## G5｜正式运行后的规则
跑满72步，不因分数下降而早停，不因信号少而加步数，不因某seed不利而替换。保存12/36/72 checkpoint，主结果只用72。

观察性覆盖/信号下降继续记录，作为方法失败或作用范围限制，不自动终止以避免删去困难路径。非有限参数、损坏checkpoint、token身份错位等技术故障停止当前未提交step并诊断；不能删除失败记录后把新run伪装原run。

正式科学结论要求报告干预是否贯穿训练，但不能仅保留满足“持续信号”的路径作per-protocol赢家分析。所有45条进入意向实验报告；缺失端点不当成随机缺失，也不按已完成小分母平均。
