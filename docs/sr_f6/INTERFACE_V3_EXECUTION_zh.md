## 采用与不采用的建议

只采用一个公开提示候选：每个对象的键只写一次；每条 evidence 只记录一个原始
`(series, category, value)` 单元；同一单元不重复；selected 必须是实际 JSON 数组。
按公开题意逐题列出证据要求：TOPK 的完整排名系列、最终所选类别的运算系列；INTERVAL
应用端点规则后的公开类别，若有正值过滤则保留过滤前的两系列原值。差值由 Alpha 和 Beta
两个单独证据对象支持，bindings 中才填写差值。清单不读取隐藏答案、图表数值或选择结果。

不采用附件的宽松解析、重复键自动去重、字符串 selected 自动转换或扩大数字范围。
这些变化会改变有效性/奖励含义，也不能直接修复冲突事实与证据缺失。
原严格消费者、scorer、A/J/V/S/B 定义、FP32 原生采样、停止规则、1536 token 上限、
温度1、top-p1、top-k0均保留。旧原始数据若已按用户要求删除，不声称完成其逐行回归。

不采用新增的 P1 暴露率门、按结果删减到36路或20% J缺口门。原54路、六臂、seed、lambda、
步数与完整评测保持。筛查中的 A/J 缺口属于必须报告的诊断，不成为事后增设的科学门。

## 预先固定的工程判定

每父合并两个因子的192行，分别计算 V、S-known、B-known；known 不等于正确。

| 阶段 | 固定规则 | 后续 |
| --- | --- | --- |
| 1 | 三项均至少173/192 | 该父 PASS |
| 1 | 任一项至多163/192 | 该父 FAIL，整版本停止 |
| 1 | 其余情况 | 该父 GRAY |
| 2 | 灰区父合并两阶段后三项均至少346/384 | 该父 PASS |
| 2 | 任一项不足346/384 | 整版本停止 |

先完成阶段1三个父的全部576行并核验原始轨迹、worker及调用账本，再评价门。
任何父阶段1 FAIL 都阻断所有阶段2；仅在没有FAIL时，GRAY父可执行已冻结的阶段2。
全部父阶段1 PASS 则不运行阶段2。阶段2每灰区父仅192行，总预算最多1152行，无第三阶段。
第二阶段授权重新核验阶段1完整封存结果，而非接受手写PASS或文件计数。

该门只是资源受限的工程筛查，不是总体90%合格率或IID二项置信保证。共同seed、重复anchor、
同根视图及同题重复回答存在相关性。报告每父×因子及家族分层，即使合并PASS也保留低表现格。
旧 v2 逐格门与新门不同，不能用新门追认旧结果，或以不同样本的差异宣称因果提升。

## 题组价值必须分层验证

筛查报告有限候选 C_resp/C_abs、anchor别名及碰撞揭露、强造与非强造层、真实A/J、
UNKNOWN、双端错误却相对差值正确等反例。两draw的四种配对是相关的描述性组合，不能当四个
独立样本。原索引0/1和2/3各12根、6强造根；这个50%比例不能推广至TRAIN或完整DEV_CAL。

每次完整评估必须分解 A=1、J=0：接口无效、证书不可读、事实真实但证据不充分、错误证书及
其它J条件。解析失败后的零默认标志不能当作证据已被判错；独立内容诊断保留UNKNOWN。
工程筛查不能估计完整G8信用，也不能证明有限候选库覆盖真实错误，更不能证明训练收益。

只有SCREEN_PASS后才构造并冻结独立 `DEV_SCHEMA_CONFIRM`：原生成器、master20261028、
六家族各索引0至7、原model-blind拒绝规则；不得根据结果挑seed或题。48根384题、三个父各G8，
共9216行。每父×因子1536行，V/S-known/B-known各至少1383，原18项逐格确认门保留。
原COND/SHUF支持门、原288个TRAIN根覆盖门、新360条独立真实回答审核、实际数值准入门都保留。
确认集必须另有实际新来源、图像、重复/泄漏检查及生产编排；缺少时先实现和测试，不能借旧FAIL
或占位许可推进。只有全部门通过，才按原合同执行12步先导、恢复验证、54路72步和完整评测。
最终学习价值仍由未见COMPOSITION的D0、固定对照与不确定性判断，保留负结果。
