# 00｜最终决定与一页合同

**SR-F6 / 2026-10-27 / v1.0。交付性质：已冻结的实验设计与可运行 CPU 参考包；不是 GPU 训练结果，也不是已绑定服务器的生产训练器。**

## 研究主问题
怎样把可验证的语义行为信息用于多模态 on-policy/RL，使模型在未见语义组合上学得更好，同时保持原有能力？J/J6 是本项目已构建的联合奖励基础，不是外部的纯答案奖励。主线不被收窄为 selected、人工碰撞、题组筛选或一个动态控制器。

## 本轮只检验一个明确实例
同一类语义信息分别通过两个途径进入学习：**题组提供能揭露错误行为的实例；反馈直接核验当前回答的任务子目标。**采用一个 2×2 确认实验，将二者分开，再用两个固定强对照解释反馈机制。首轮覆盖对象选择与任务相关取值绑定；视觉事实、执行自洽、跨题响应继续测量，不把尚未验证的每个分量都塞进奖励。

|运行名|题组|训练反馈|身份|
|---|---|---|---|
|U00|P0，匹配编辑成本的普通合法题组|J|主四格|
|U01|P0|J＋条件化 oracle 语义信用|主四格|
|U10|P1，同编辑成本、最大化有限候选类的响应区分覆盖|J|主四格|
|U11|P1|J＋条件化 oracle 语义信用|主四格|
|C_GLOBAL|P1|同标签、同权重、同 λ，但不按 J 分层的简单过程信用|预登记强对照|
|C_SHUF|P1|在相同 J 与可判模式内，一次置换信用对应|预登记对应关系对照|

四格不混用跨题 GRPO 分母：每题独立采 G8 并计算原生优势。不同题的回答不互相提供答案、隐藏状态或上下文。

## 固定数字
- Qwen3.5-9B 固定 snapshot；原 b0/b1/b2 J6 父 adapters；每条路径从父参数重新初始化优化器。
- **3 父模型 × 3 独立训练重复 × 6 臂 = 54 路径**。其中主四格 36 条、强对照 18 条。三个父模型不是三个同父随机种子。
- 每路径 72 次更新；每次 4 roots × 4 views × 8 draws = 128 回答。每路径 9,216 条，正式训练共 497,664 条。
- 共同训练库：6 家族 × 48 roots × 4 views = 1,152 题/数据因子，一遍曝光。P0/P1 同根配对，反馈有无不改题目。
- 固定 λ=0.5，S/B 各 1/2。只在同题、同 J、同可判模式内居中；不在线拟合权重、不按信用 L1 比自动放大。
- 序列级信用，无局部 mask；继承原生单次更新损失、KL、参考父模型；全 FP32。
- 主终点：独立 COMPOSITION 面板 768 题 × 4 次回答的**最终答案正确率**。额外语义字段错误不直接将答案判错。
- 四个确认对比：数据效应 D0、P0 反馈效应 F0、P1 反馈效应 F1、交互 I，全部双侧、Holm 校正。2pp 为事前实质效应参考，不承诺一定有能力检出。
- 三个重复不是“保证显著”的承诺；是避免仅两次重复把训练方差估计压到三个自由度。实际不确定性必须报告。
- GPU 小时只记账，不构成科学停止门槛。集群单作业时限用事务检查点跨作业续跑，不扩张训练步数。

## 明确不做
不训练状态控制器；不做在线采样策略；不增加教师 CE；不奖励“两题都错但一致”；不把一轮代理标签称为内部真实思考；不以显著性、预期格子排序或置换必须无效来决定先导通过；不复活 F5 的 FAIL 合同。

## 启动顺序
SOURCE_BINDING → 数据/测量预检查 → PARENT_CENSUS采集与真实测量审核 → 两门最终回执 → RUNTIME_PILOT → FORMAL_FREEZE → 正式训练 → 全部端点提交后解封测试。

# 02｜题组如何构造：不靠猜模型会错什么

## 2.1 实验单位与可见信息
world 是图表真实数据；root 是一个世界与查询及其派生编辑的共同谱系；每个数据因子有 anchor＋3 个编辑视图。P0/P1 anchor 完全相同，编辑视图可以部分重合，禁止为了差异而强制 P0 避开好题。

模型单次只看当前图像、当前题目和共同格式约定。不能看到 world JSON、gold、候选错误规则、coverage、P0/P1 名称、collision 标记、相邻题答案或生成元数据。输入只使用模型可见字段白名单；更改 sidecar 中 gold/factor/root_id 必须不改变 prompt。

## 2.2 世界与任务语法
沿用已验证的六家族、TOPK / INTERVAL 查询、sum / mean、Alpha / Beta / Alpha−Beta。6或8个无自然顺序商品名；印刷顺序随机。数值12,18,…,84；坐标轴0–100，无逐柱数值标签；主答案必须整数或有限小数。主实验不新加难以辨认的图像或数字，不依靠更短输出预算造错误。

|家族|本轮 anchor 的任务结构|错误候选及测量职责|
|---|---|---|
|BINDING|排序列与取值列交叉|错列、错取值角色、选择/绑定不一致|
|IMPACT|固定选择规则后聚合相关取值|选错但数值相同、相关/无关编辑响应|
|TIES|明确印刷顺序破同值|反向破同值、边界成员替换|
|SIGNED|对所选对象算有符号差再聚合|符号、角色、聚合类型|
|INTERVAL|按图上位置定端点，再作正差筛选|端点、漏筛、区间与最终集合混淆|
|K_DIRECTION|不同k与最大/最小方向|方向、k、边界替换|

这只是首个可核验实例；不能声称语义行为等于选择集合。B 进一步核验所需数值及其对象绑定；P与E另行记录。

## 2.3 预先定义的有限错误库
不读取父模型输出来定义错误库。当前参考库：boundary_swap、wrong_value、wrong_aggregate；TOPK 另有 wrong_rank、wrong_direction、k_minus、k_plus、reverse_tie；INTERVAL 另有 toggle_start、toggle_end、toggle_filter；diff任务另有 reverse_difference。

`boundary_swap` 明确定义为：保留正确集合的其余成员，把印刷顺序中的最后一个选中对象换成首个非成员；INTERVAL 优先取区间外非成员。它是一个受控的候选错误行为，不被称为模型实际采取的错误程序。其他候选由任务算子做单点变异。

一个候选在当前编辑池没有任何可区分响应时，记录为 pool blind，不从报告里悄悄删掉。覆盖率分母另外报告“全部登记候选”和“当前池内活跃候选”，避免只显示有利分母。

## 2.4 区分证书：有绝对锚点，也有响应信息
对正确函数 f*、候选 h、编辑 e，保存：

D(e,h)=1[(f_h(e(x))−f*(e(x))) ≠ (f_h(x)−f*(x))]。

这是候选错误相对正确函数的**响应差异**，不是简单“一道编辑题是否答错”。基题的绝对差也保存。对原本碰巧答对的候选，D=1意味着该编辑可揭露它；对基题已经答错的候选，D刻画其对变化的响应区别。

证书只对列出的候选、实际合法编辑池和精确算术成立。不声称恢复模型隐藏程序、不声称排除全部错误、不声称coverage高必然学得好。常数偏差可能位于响应零空间，必须靠绝对正确性排除。

## 2.5 P0/P1 的匹配机制（参考实现已提供）
每个 root 枚举：对 Alpha 或 Beta 的一个单元格做 ±6 编辑。逐项检查取值边界、金标非空、有限小数、保留组合规则、双oracle一致。不能因为模型答错率或信用稀疏而接受/拒绝某题。

把候选编辑按以下描述分桶：编辑列、正负号、绝对幅度、金标集合大小是否改变、金标答案变化量。预登记 seed 随机选择3个不同桶：

- P0：每桶均匀选一个编辑，不查看覆盖率。
- P1：在相同3桶内，枚举三项组合，最大化响应差异覆盖的并集；并列由同一预随机顺序决定。

这样每个配对视图都匹配操作成本和上述真实任务属性。P1 不增加题数、生成次数、oracle调用权限或候选池。P0不是专门挑选“无用题”。

**不能声称难度绝对相同。**哪一单元格被改、候选错误与真实任务的关联，是本来要操纵的因素；它也可能影响模型难度。父模型难度、长度等只描述，不在正式结果后重新匹配，也不据此删除实验效应。CPU覆盖差验证的是操纵存在，不是学习有效。D0识别的是这个覆盖优化生成策略的整体效应，不是把coverage数值与所有难度因素完全分离后的纯因果效应；金标成员是否发生替换等未精确匹配属性必须另行汇报。

## 2.6 碰撞比例与范围
训练每家族48 roots中，每第三个anchor（16个）构造对 boundary_swap 的数值碰撞，共96/288=1/3。修改非成员的取值，使该候选与正确函数在anchor上同答案，同时保留正确选择；独立oracle及编辑见证必须验证。

这是**设计的候选碰撞比例**，不是模型自然侥幸率；未强造的anchor也可能偶然与其他候选同答案。实际候选碰撞和实际模型的 A/J/S/B 事件分别记录。首轮不要求父模型出现20%–40%错误，不为满足错误率筛题。

构造碰撞需要合法边界与不改变真实选择；最多256次按登记数学约束重建。禁止看模型后选更容易制造显著效果的候选。此次构造聚焦边界替换，其他错误类仍进入覆盖和测试；不把该受控子层外推为自然数据发生率。

## 2.7 划分与独立组合
同一root所有P0/P1编辑和渲染都在同split。跨split还检查忽略名称、忽略顺序后的两列事实多重集，防止重命名泄漏。所有旧F4/F5公开测试病例只作开发知识。

训练中全局排除以下六种连接，而非只在某个家族排除：
1. Beta排名＋Alpha取值＋mean；
2. Alpha排名＋diff取值＋smallest＋mean；
3. 排名边界同值＋smallest；
4. diff取值＋k4＋mean；
5. INTERVAL＋positive_only＋mean；
6. k4＋smallest＋mean。

COMPOSITION每家族32 roots；每个root四个视图都满足对应保留组合。使用独立种子、普通合法随机编辑生成确认测试，不用P1最优化挑有利测试。主面板排除在登记**活跃有限候选库**内的答案碰撞；不能简称为排除了所有可能错误的“零碰撞”。

CLASSOUT另设未参与覆盖最优化的双算子错误与双格编辑±12；具体内容只按2.9，首轮不再增加右到左呈现因子。需独立oracle和清楚语言。它是次终点，不和主COMPOSITION混合。

## 2.8 图像与人工/程序审核
生产渲染固定1280×896、同字体尺寸、同柱宽与图例位置。原图每6单位高度≥30像素，processor后的柱间距、字体框另记。不要将程序几何检查写成人类读得懂。

先每家族抽8张开发图（48张），含两个类别规模、同值、负差、端点和两列角色互换；审核必须针对实际processor图。审核者来源写 human/vision-agent/program，不虚构人工。没有图像检查或发现题意歧义，停止生产数据发布。

本包提供数据/证书参考实现与开发样例，不提供未核验的生产CLASSOUT或旧数据下载替代品；这些属于 Codex 的明确交付任务。


## 2.9 CLASSOUT的唯一实现规范
48新roots（每家族8），seed=2026102718。原任务规则仍取合法非保留组合，以隔离“新输入编辑/错误类”与COMPOSITION；不强造碰撞，不最大化P1覆盖。

每root使用4views：anchor，以及3个不同的双cell编辑。一次编辑在不同类别的两个格子分别施加±12；两格可同列或跨列，按固定seed在全部合法候选中均匀无放回抽取。数值在[12,84]、答案有限小数、集合非空非全、双oracle一致，三个编辑互异；所有视图与其他split的世界指纹隔离。训练只允许单cell±6，所以该编辑目录未进入训练。

类外诊断候选是两种查询运算同时错：TOPK为错rank+错direction、错direction+错value、k+1+错aggregate；INTERVAL为toggle-start+toggle-filter、toggle-end+错aggregate、错value+错aggregate。这些组合不参与P1编辑选择。它们只是明确的有限类外探针，不能覆盖所有未建模模型行为。

类外主报告仍看真实答案A；候选签名匹配允许UNKNOWN与多重兼容，不强制归因。测试构造不筛除“模型不犯这些错”的题，也不按类外候选匹配率挑选checkpoint。

# 03｜标签、协议、J 与评分：逐项堵住混淆

## 3.1 共同输出协议
六臂完全相同，字段：`evidence, selected, bindings, aggregate, answer`，另可带自由文字 `work`。不使用字符串内嵌转义的SELECT/COMPUTE，不把候选池误称最终集合，不按金标从散文中挑一段“最像正确”的列表。

```json
{"evidence":[{"series":"Alpha","category":"Mug","value":12}],
 "selected":["Mug","Lamp"],
 "bindings":[{"category":"Mug","operand":18},{"category":"Lamp","operand":30}],
 "aggregate":"sum","answer":48,"work":"Optional concise working."}
```

上例仅示意结构，单条evidence不被宣称充分。模型可自由安排work，不做教师CE，不新增SFT，不使用语法约束解码。最大输出长度统一1536（相对F5是公开的新共同协议设置）；主比较内部全部相同，不把历史不同协议准确率直接横比。

## 3.2 三类正确性分开
- A：最终答案精确正确。只要求能从一份合法、无歧义的最终JSON提取answer，不要求额外selected/bindings正确或存在。非法/截断且无法提取答案为0；不重采。
- V：共同格式与字段类型有效。不能把“集合必须等于金标”“bindings必须覆盖金标”混入V。
- J：继承F5实际M3联合奖励的答案、证据真实性与充分性、协议和完成条件，再与本轮共同V相交。投影删除本轮bindings/aggregate等新增字段，保留原evidence/answer/selected/work。必须通过原生评分器回归，不以CPU简化评分器替代。

**J不检查S、B或执行语义是否正确。**将一个格式合法的selected或bindings改成错误值，但保持答案和原证据不变，J必须不变。字段缺失或非法类型导致共同V失败，是共同接口要求，不是“选择奖励”。

A、J、V、finish分别存储。J=0不能称为答案错误。A评分不能被新增声明格式的失败拖成0，否则“语义奖励改善答案”会混入协议改善。

## 3.3 两个实际训练事件
|事件|输入及真值|PASS|FAIL|UNKNOWN|
|---|---|---|---|---|
|S 最终对象|selected与查询oracle的最终集合|无重复、集合完全相等；顺序不限|空、重复、额外、遗漏、错对象，且声明可读|声明缺失/不可读或生成无法完整核验|
|B 任务相关取值绑定|bindings与**金标最终集合对应的任务操作数映射**|对象键完整且无额外、无重复，每个operand等于真实世界按题目取出的值|错范围、错列、错差值、错数值、遗漏或重复|范围可核验但operand明确缺失/不可解释，或整体不可读|

B的任务操作数可以是Alpha、Beta或有符号Alpha−Beta。不奖励“任选一个容易对象然后读对”，不允许空列表真值为真。B核验的是任务所需数值映射，不仅是任意已提交事实的真实性。

S与B可以不一致，例如selected写错、但bindings恰好列对真正对象。两者分别反映可观察子目标，不强行把它们等同模型内部步骤；另记 `consistency=1[两份声明的对象键相同]`，不将它单独奖励。

本轮权重固定S:B=1:1。若二者在某组高度相关或分量互相抵消，按实际记录报告，不自动重新加权。正确反馈可能仍有捷径风险，最终由独立答案与泛化评测约束解释。

## 3.4 不进入主信用的诊断
- P：提交证据的真实性；不是完整感知成功率。
- E_raw：模型声明的bindings按其aggregate计算是否等于answer。可在全部数值错误时成立，不能单独当正确进展。
- E_anchored：B通过、aggregate等于题意、答案等于真实所需操作数的聚合。此时代数上等于 B∧正确运算∧A，明显与A重叠，不能当独立新奖励。
- 受控跨题关系：答案变化是否匹配真值关系；必须与绝对正确、整组全对共同报告。模型两题都加90也可能关系一致。
- 声明与使用证据的一致：是外显一致性，不是内部因果忠实性。

## 3.5 UNKNOWN与数值
UNKNOWN记None，不回填0或1。空但完整可读的集合是明确错误，不是UNKNOWN。本轮共同协议禁止bindings中的null或非数值operand；这类回答V=0、J=0，测量记UNKNOWN而不冒称语义FAIL，不能靠输出null逃避负信用。只有可完整核验的生成进入信用；真实缺失率单独报告。

使用Fraction/Decimal，拒绝布尔值、NaN、Inf、重复JSON键与超界数值。主数据本身保证整数/有限小数，但仍接受引号分数的等价精确表示；不通过改变容差制造提升。压力面板可另报预登记近似分，不替代主分。

## 3.6 标签验证不是只看“程序审核PASS”
必须同时有：双oracle、结构变异夹具、gold-blind抽取测试、原生J投影回归、真实回答分层复核。不能只在旧解析器已知的行上检验新覆盖区域。

真实复核抽样：每个父模型×P因子选60个唯一(qid,完整文本)，每家族10个，合计360；优先覆盖A/J/S/B所有实际出现的组合以及UNKNOWN/无效，再随机补足。按root去重上限每root最多4条；不是按row_id取前24条。稀有J1/S0、J1/B0、S1/B0、S0/B1全量列出，超过上限按预登记hash抽样另记总数。

每个审核者独立判断后才看程序标签；回执区分人工、视觉代理、程序。所有存在歧义的条目保存，不事后改成有利标签。360只是覆盖样本，不代表全量分布；按完整数据另报率。

# 04｜信用与实际优化目标

## 4.1 原生任务优势不变
同题G=8，j_i∈{0,1}：

A_i^J=(j_i−mean(j))/std_population(j)。std=0时全部为0。

全成功/全失败没有原生组内区分，但不意味着整个训练梯度为0：KL和语义项仍可能存在。不得删除恒定J组或补采到混合。

## 4.2 固定的条件化语义信用
每条回答m_i=(1[S已知],1[B已知])。只对V有效且生成可完整核验者使用语义信用。按同题、相同J、相同m分层，层记K_i。

对已知分量d∈{S,B}：

c_i = 0.5 × Σ_d [ (1/2) × m_{i,d} × (z_{i,d}−mean_{k∈K_i}z_{k,d}) ]。

|K_i|<2时c_i=0；分量UNKNOWN贡献0，不将其余分量重新归一成总权重1。所有c_i按本层合计为0。可判模式分层避免把UNKNOWN误当失败，并使置换能准确保持系数分布。

这是**事前明确的训练代理规则**。因为层取决于回答本身，不能声称它是J+λS的无偏策略梯度；包含自身的样本均值也带有限组大小缩减。分层信用不保证共享神经参数上不干扰J。理论只保证本层系数中心化与边界，不保证学习单调提升。

为什么λ固定0.5：给 bounded、未单独白化的信用一个明确、可重复的幅度，避免按稀疏事件反向放大。它不是经验最优值。系数L1比例不是梯度比例，更不是学习价值。正式结果只覆盖此剂量；不显著不能推出所有剂量无效。

## 4.3 两个强对照
C_GLOBAL：同S/B、权重与λ，在同题同可判模式内居中，不再按J分层。它是公平的简单oracle过程信用基线，不冒称完整复现VPS的SFT与动态权重流程。它与COND的实际信用量可能不同，这也是条件化操作的一部分，应实测报告。

C_SHUF：先计算与COND完全相同的c，再在同题、同J、同可判模式内做**一次**均匀置换。保存原系数、实际系数、permutation索引和seed。不能重抽直到发生改变、不能强制错位、不能删掉未改变的组。系数多重集、层内L1/L2和总和严格保留；只有与原回答对应的关系被打乱。

“置换后必须等于J”不是零假设。即使条件期望辅助系数为0，有限随机信用仍可能改变优化噪声和后续策略；两者差异作为实验结果。语义对应的证据来自U11与C_SHUF的实际端点差，而非预先要求C_SHUF无效。

不设联合成功跨题对照：本轮根本不使用跨题配对、关系奖励或共同组标准化，没有需要排除的联合成功耦合。如果以后启用ConsistRoll/OT类载体，必须另行加入相应对照，不把本轮当作已经比较过它们。

## 4.4 可检查的四个例子
1. 同题八个J全0，S/B有明确真假差：COND仍可有非零信用。不要求出现J1/S0。
2. 七个J1、一个J0，而七个成功子目标全真、失败层只有一条：COND无差异。不能为了制造差异改分层或重采。
3. J1层内出现错误任务绑定：即使答案正确，可信的B差异可产生负信用。
4. S1/B0与S0/B1各一条：等权总信用可能相同。记录两种状态，但不臆造哪个一定更值得奖励。

## 4.5 继承的实际损失
按原F5 FP32配方：current logp=l，实际采样logp=l_s，固定父reference=l_ref；old=stopgrad(l)；r=exp(l−old)；w=stopgrad(min(2,exp(old−l_s)))。

P(a,t)=−w_t·min(a·r_t, a·clip(r_t,0.8,1.2))。
K_t=expm1(l_ref,t−l_t)−(l_ref,t−l_t)。

L_i=mean_all_tokens[P(A_i^J,t)+P(c_i,t)+0.02·K_t]。

J臂c=0，GLOBAL/SHUF只改变c。KL只计算一次；原生与辅助均用整条实际采样序列归一，不做selected局部mask。每批所有128回答等权，包括UNKNOWN和零信用；padding/prompt不计入。EOS与thinking token边界严格继承并冻结。

每批一次optimizer update，old来自当前前向的detach，r的前向值是1；clip不能被宣传为多epoch PPO信赖域。本轮不顺手换优化器，以隔离信息途径。

## 4.6 真正的数值与梯度证据
登记步1/12/36/72，在同一个固定子集上分别算native、aux、KL、total梯度；记录范数、夹角、分位数与参数更新。分解回传必须清空并恢复，不能混入正式梯度。只对同一步、同一子集比较范数；不能相除两个不同时刻的最大值。

记录所有token的sampler/train和reference/current差异；均值小不等于尾部稳定。超过原冻结阈值停止未提交更新、保留原始token与概率；不静默夹到±10、屏蔽异常token或换种子后标为通过。

# 05｜阶段门、父模型普查、先导与冻结

## 5.1 先说明哪些决定现在固定

## 5.2 SOURCE_BINDING

生产 J 回归：至少 300 个程序生成夹具覆盖六家族，逐一比较旧原生 J 与新增字段投影后的旧 J；再对其中每个保持 V 合格地修改 selected/bindings 的内容，验证 J 不会意外随 S/B 真值变化。新增 V 的字段类型约束单独列出；它们是所有臂共享的协议变化，不能拿差异冒充旧 J 完全未变。

标注审核至少 360 条**不同原始回答**，每父模型×数据因子 60 条，六家族各10；每 root 至多4条。预先按 PASS、FAIL、UNKNOWN 与 A/J 分层，稀有状态不足则全取并报告缺额，不能复制补满。原文、盲抽取结果、oracle、判定见证和复核方法同存；抽取器与判定器的同源一致不等于独立真值验证。错误的 oracle、假 PASS、标签使用 gold 反向抽取均为阻断问题。

1. 六家族×父×因子的 A×J×S×B×证据状态表；J=0、A=0分别计算。
2. 全零J、全一J、混合J组内的语义变化；非零信用组、存在可交换差异组、单次实际置换改变组分别计数。
3. 在所有样本、V合格样本和标签已知子集中分别报分母；正/负信用对应何种 A/J 状态。
4. P0/P1覆盖差、任务难度和输出长度；禁止按模型表现删除根或重新平衡。
5. 候选行为签名拟合与未使用编辑预测，仅开发诊断。仅“原题对、变体错”叫脆弱响应，不自动叫碰巧答对或已识别错程序。

# 06｜生产训练、数值一致与事务恢复

## 6.1 固定运行条件
Qwen3.5-9B，3个原J6父 adapter，基模/浮点图像输入/current/ref/generation全部FP32；冻结父模型作为每条路径KL参考。继承父LoRA结构；新AdamW：lr=1e−5，betas=(0.9,0.999)，eps=1e−8，weight_decay=0，constant schedule，global clip norm=1。adapter-only训练，dropout=0；不得暗加教师CE、grammar decoding、重采样过滤或长短回答筛选。

每题temperature=1、top_p=1、top_k=0、max_new_tokens=1536。1536是共享的新输出上限，所有臂及本轮父评测一致；与F5不同，不能把跨轮差值当本方法效应。超过上限的回答保留分母，finish状态影响J，不补采“完整答案”。

4 roots×4 variants×8 draws=128序列/更新，16个独立题内G8。variant不混成32样本的GRPO组；每题单独原生居中。每条路径72更新，288训练roots各一次。训练根顺序按重复种子生成，每12步覆盖每家族8roots；同一父/重复的全部六臂共享根顺序和采样种子。

同seed是方差控制，不保证更新后原文相同，也不能把相同计数当参数相同。P0/P1不同图像可能使采样分叉；单题draw seed由父、重复、步、槽、variant、draw派生，不含arm。

## 6.2 一次更新严格顺序
1. 锁定当前checkpoint和RNG；完整收集本步128条，保存实际prompt/image摘要、原始token IDs、采样logprobs和finish；即使J=0也保留。
2. 用冻结parser/scorer计算A/J/V/P/S/B/E与oracle见证。按qid×父×policy hash验证每组正好8条。
3. 计算原生A^J与本臂c，记录COND/GLOBAL/SHUF反事实统计但仅本臂c进入梯度。置换只一次，种子由路径/步/组派生。
4. 使用真实采样token，生成时的同一chat template、图像预处理和特殊token。padding/prompt不进loss；EOS属于实际完成token。不得通过重新encode整个字符串替代token轨迹。
5. microbatch=1，128个序列loss各除128后累积；每个序列内按实际完成token长度平均。不得按有效信用条数重算分母。KL只一次，辅助λ只一次。
6. 在任何optimizer更新前完成概率一致、有限性、梯度诊断；全局梯度裁剪一次，optimizer.step一次。禁止在一个128批次中偷偷更新多次。
7. 原子保存新adapter、optimizer、scheduler、全部RNG、采样计数器、已消耗qid表、信用和更新摘要；提交COMMIT.json后步号才递增。

公式见04与`objective.py`。本包单次更新继承F5：ratio以当前参数detach为旧值，前向为1，TIS修正采样/训练差异。它不是多epoch PPO，不声称clip提供多epoch信赖域。

## 6.3 数值检查与诊断
每步记录sampler/train的mean/max/分位数和超过0.01、1、5 nat的token计数；mean>0.01、max>5 nat、TIS触顶比例>1%均为阻断警报，任何非有限值立即阻断。还要逐步保存reference−current分位数和KL总量，不能用sampler/train差来解释reference/current的极值。

不静默截断log-ratio、不mask异常token继续跑、不把失败步换成新的回答。出错先存原始token、概率、精度、batch形状、缓存状态、kernel环境；使用同一只读诊断复现。科学配方已冻结后若必须修改数值目标，原路径结束并标FAIL，不恢复成“同一正式实验”。

登记诊断步1、4、8、12、36、72：在同一批次固定8个qid/共64序列上，用同一前向与同一参数顺序分别计算native、aux、KL向量范数、内积/cosine、合成梯度与实际更新范数。诊断不optimizer.step、不改变RNG；所有臂都做。辅助范数很小不直接推出效果小；不得把不同步最大范数相除叫剂量。

单独记录：c的L1/L2、非零比例、J分层零和、TIS后实际梯度、裁剪前后范数。零和是系数性质，不保证各任务完全无干扰。

## 6.4 事务与故障恢复
run_id包含experiment/parent/repeat/arm；同run只能一个worker持独占锁。缺COMMIT的部分步：恢复**上一已提交**checkpoint，优先重用与其hash/RNG严格匹配的已完成rollout，不能跳过/重复optimizer。

step0/12/36/72保留永久checkpoint，其余事务checkpoint可保留两代，但原文/信用/更新不可删。恢复验证按adapter、optimizer tensor、scheduler、CPU/CUDA/python/numpy RNG、token、logprobs、credit、step计数与日志内容逐项比较。

内容身份用SHA256/规范化tensor摘要；共享文件系统st_dev、inode不是科学身份。跨节点路径相同或inode相同均不足以证明内容相同。b0/U11恢复验证只支持所验证路径，不冒称所有路径跨硬件bitwise一致。

集群TimeLimit是作业调度约束，不是科学训练预算。壁钟中断只续跑剩余登记步；不得增加更新数。默认单GPU worker并行数1，提交前读取实际队列和权限，不取消无关作业。配置中的account/partition/qos仅是已有环境值，必须核对真实可用性，不能通过改模型/精度绕过资源限制。

## 6.5 正式顺序与测试锁
用预登记随机顺序在每个父×重复块中执行六臂，平衡执行时间；不能始终先跑主候选、效果好才跑控制。每条正式路径从父模型而非先导端点开始。

36步仅跑独立DEV_EVAL一次固定96题，用于透明轨迹记录，不用于早停/调参/选择checkpoint。所有54条72步端点提交前，服务器不允许任何模型访问正式TEST图像/问题；完成后一次解封统一评测。数学oracle审查测试数据不等于模型测试揭盲，但人工发现题目错误必须在模型访问前更正并更改数据hash。

# 07｜评测、统计、预算与结论

## 7.1 面板与任务范围
所有54个正式端点和3个父checkpoint都评下列同一面板；不能只选b0评外部任务。每个checkpoint共6,010次回答：

|面板|题数×draw|用途|
|---|---:|---|
|COMPOSITION|768×4|主终点：6种全局未训练组合，每族32roots×4views；相对于活动有限候选库排除答案别名，不宣称所有可能错法零碰撞|
|ID|384×2|同规则新根、新数值，非未见组合|
|MECHANISM|192×4|自然/登记碰撞分层、相关/无关变化、绝对与关系正确性；不作为挑选赢家指标|
|CLASSOUT|192×2|48新roots×4views；双cell±12新编辑和复合错误候选，训练编辑库未用|
|NATURAL_INTERFACE|128×2|与正式图表任务配对但不要求新字段，检查收益是否依赖声明接口|
|LEGACY|128×4|冻结旧题ID，使用旧原生prompt/scorer；能力保持|
|CHARTQA|250×1|冻结外部题ID和既有两套评分口径；迁移与保持边界|

额外的NATURAL_INTERFACE问题由ID每家族前16题=96，再按固定散列从剩余ID取32，共128。它与ID是配对接口探针，不算新的独立root；单独报告，不合入主终点。自然接口末尾固定追加“Give brief working and end with exactly one line: Answer: <exact number>. Do not output JSON.”；冻结提取最后唯一Answer行，重复Answer标记、非精确值或末尾追加内容均判0，不按金标搜索数字。参考`natural_answer_score`。旧LEGACY/ChartQA仍用其原接口与原评分，不强套这条新规则。

LEGACY128和ChartQA250优先用项目已冻结题ID；若不可访问，不从网页寻找替代私有数据，也不悄悄换题。SOURCE_BINDING中确认真实ID、原始文件及scorer；缺失则不能声称完整保持/外部验证，正式矩阵先停以避免盲点。缺失不是模型负结果。

CLASSOUT严格实现见02补充：双cell编辑幅度12；不按候选覆盖最大化选择测试；世界/图形规则仍无歧义。该面板检验有限扩展，不声称覆盖任意自然图表。所有主面板失败、截断、无法提取答案留在分母。

## 7.2 主指标、四个估计量
主指标是答案A，与额外selected/bindings是否正确分开。draw→qid→root四views→六家族等权→三个固定父模型等权→三个重复等权。分层分母永久保留。

D0=U10−U00；F0=U01−U00；F1=U11−U10；I=U11−U10−U01+U00。单位同时报比例与百分点。交互可正可负；Claude的负交互只作竞争机制预期，不作单侧检验或通过条件。

四项使用双侧α=.05的Holm校正；若某项训练方差为零导致p不可定义，保留原始NA，校正家族中暂用p=1保守占位，不能删掉它减少比较数；同时报各项98.75% Bonferroni区间，不事后挑较容易显著的方法。总效应U11−U00和反馈平均效应作透明补充，不替换四项主估计量。

预登记机制对照在P1：U11−C_GLOBAL、U11−C_SHUF，单独两项Holm。仅当相应反馈在任务表现上有支持时解释机制；否则照报但不凭机制分数升级成功。不因控制臂更强而删除它。两个对照不在P0，不能用P1的打乱结果证明P0独有效应一定来自语义对应。C_GLOBAL与COND虽共享λ与标签，居中改变会连带改变系数幅度；此比较识别两个固定反馈方案的整体差异，不能单独归因为排除了幅度后的信息优势。

## 7.3 训练重复与固定父模型推断
对每个比较，在同父×同重复的臂端点上先做配对差d[b,r]。目标是三个固定父模型的均值，不把他们当全模型总体的随机样本。每父r=3独立训练重复。

主参数不确定性：各父内样本方差s_b²；V=Σ_b s_b²/(B²r)，SE=√V；Satterthwaite df=V² / Σ_b[(s_b²/(B²r))²/(r−1)]。用t区间与双侧p，再做Holm。名义上B(r−1)=6个训练重复自由度，实际异方差df可更低。若方差全为零，程序返回NA而不是CI=点值的“绝对确定”；检查共享seed/相同权重/评测粒度并另报条件root区间。

正式同时给交叉重采样敏感性：每父内重采3个paired repeats；家族内重采roots，所有臂/父共享root索引；10,000次，固定seed。它包含测试根与训练重复的可见变动，但3重复下bootstrap尾部本身不稳定。与t分析不一致时两者都报、结论收紧，不择优。

候选基线与所有端点评测共享draw种子只降方差，不能把4draw×768题当3,072个训练重复。保留按family/root/draw原始记录以复核。

## 7.4 精度与停止含义
2pp为预先定义的实质效应参考，不是已经保证的最小可检效应。须报告本次区间宽度与2pp关系。不显著不等于等效；只有合理区间整体落在[−2,+2]pp之内，才能在该范围内讨论实践等效。区间太宽：INCONCLUSIVE，不说信息无用。

旧LEGACY保持容许下降1pp，ChartQA容许下降2pp，作为单独非劣问题报告置信下界；250题本身限制外部精度，不能靠高点估计宣布无退化。多重保持判定和确认性/探索性分组在报告中明确，若同时宣称两项都保持需控制两项家族错误率。

父模型普查不是72步训练方差。一个开发重复的9条先导不能提供正式功效保证。当前选择3重复而非2是为了增加同父随机性证据，仍然有限。不得为得到显著增加第4重复、延长到96步或重定义题族。

## 7.5 预算：完整披露，不假装比24路便宜
Claude建议24主路径（3父×2重复×4）；本方案为36主路径+18必要控制，共54路径。增加来自训练重复和机制对照，不是同时开发多个新算法。用户未设GPU小时上限，故固定科学规模并透明列出实际生成量。

|阶段|最多回答数|
|---|---:|
|父模型普查|9,216|
|先导训练|13,824|
|恢复验证|1,024|
|先导评测|2,304|
|正式训练|497,664|
|36步开发监测|5,184|

由`scripts/budget.py`计算。精确缓存会减少普查调用；失败任务和恢复不能变成额外训练预算。报告input/output token、图像像素数、optimizer次数、真实GPU小时和峰值内存；不承诺所需墙钟时长。资源无法执行这份规模时，在正式结果揭盲前提请独立缩减合同，不能边看效果边决定省略哪条臂。

## 7.6 允许出现的结果
- D0正、F0/F1无可靠增量：主要是本题组数据设计价值；不硬称新反馈算法胜利。
- F0/F1正、D0无增量：oracle反馈在该任务有学习价值；不硬称可辨识题组是必要原因。
- F0大于F1：与信息替代机制相容，非唯一因果解释；也可能饱和/难度不同，需配套轨迹。
- F1大于F0：与互补机制相容，同样不唯一。
- C_GLOBAL不差/更好：采用简单过程反馈；不维护条件化公式。
- C_SHUF也同样提升：不能把全部收益归因于语义对应，检查辅助扰动与优化效应。
- 声明变好但A/泛化不变：只支持声明行为变化，不支持真正任务能力改善。
- 全部区间宽：不确定；充分窄且无实质效应：限定分布、剂量、模型与任务的负结果。
- 只人工碰撞子集有效：报告该边界，不声称普遍多模态可靠性提升。

## 本轮可争取而未证明的贡献
1. 一套有明确finite-class覆盖/盲点、同成本配对的可验证题组设计，连接逐样本S/B与跨题响应，验证其真实模型预测效度。
2. 在同一管线用2×2分别估计题组结构、oracle反馈和交互，避免把输入数据变好误认为奖励变好；额外两臂识别简单过程加权与信用对应。
3. 若正式未见组合/保持终点支持，证明在此任务与模型域内，这类语义信息的使用具有实际学习价值。

这三个候选贡献中，第2项首先是清晰的科学识别，不自动成为全新算法。公式有近邻、题组构造有历史来源，不能包装成“首次语义RL”。若效果只来自P1或简单过程信用，则按结果收缩，不为了避嫌造一个更窄的无价值名词。

# 10｜风险、停止与预登记答疑

## 10.1 不再混淆的十件事
|风险|本轮预先处理|仍保留的局限|
|---|---|---|
|J被叫纯答案奖励|原J/证据/新V逐项分开|不能据本轮证明J相对A的独立贡献|
|协议更严格造成分数提升|所有臂同协议；主A不依赖语义字段；自然接口探针|共同接口仍可能改变任务行为|
|额外标签重复答案正确|S/B用于反馈；E_raw与E_anchored只诊断|S/B有相关与重叠，须报联合表|
|错误对象的真实读数获得奖励|B校验gold任务所需对象→值，不是自选集合|仍是外显声明，不读内部思维|
|两错一致获得额外奖励|关系不进当前奖励；同时报告绝对正确|不评价未来更复杂关系算法|
|条件居中看似天然安全|说明行动依赖baseline与单例归零；C_GLOBAL强对照|没有单调改进或无干扰定理|
|置换对照被要求无效|一次固定置换；实际结果自由|随机噪声可能伤害或帮助优化|
|有意义信息被称只在碰撞存在|J失败内部分进展纳入普查|有限任务可用信号可能仍稀少|
|P0被设计得刻意差|同bin均匀抽；禁止模型结果筛选|有限成本bin不等于匹配所有难度|
|预测/测量成功被叫训练成功|独立最终A、未见组合、保持与成本|oracle合成域到自然任务范围有限|

## 10.2 什么可以修，什么不能自动改
正式前纯实现错误（索引、hash、公式与合同不一致）允许修复并保留diff与失败日志；修复后重新生成科学受影响的全部开发证据，不能拿旧回执解锁新代码。

改变λ、权重、反馈标签、任务家族、碰撞比例、数据筛选、训练规模、主终点或因子构造属于科学变更；必须产生独立版本合同并由用户确认，不能称小补丁。当前包不授权无限配方搜索。

正式中硬件中断按同事务续跑；真实非有限值/不可恢复污染记录本路径异常并停止该路径，不自动替换seed。完整主矩阵不足时说明缺失模式，不能只分析完成的有利臂并维持原确认声称。

## 10.3 对“为什么不一次做感知、执行、动态控制”的回答
研究主线包含这些能力。首个可识别实验不等于定义了整个方向的边界。现有可验证语义信息足以先检验任务选择与绑定的学习价值；视觉P只检查提交事实，既不能说感知解决，也不能为了让P失败而制造歧义。真实视觉负担扩展是后续独立版本，不混入当前首次反馈效应。

执行自洽若无任务锚点可能鼓励错误；完全任务锚定的执行又接近答案正确性。所以本轮先测不奖，后续若发现独立可验证执行子目标再设计。

控制器需要跨独立状态的足够反馈响应样本，不能拿三个父模型的九个端点拟合高维控制器并声称泛化。本轮固定反馈不是退回只做selected，而是控制混淆所需的首项具体实例。

## 10.4 不应报告的结论
“P≈1，所以没有感知问题”；“S/J相关，所以S毫无价值”；“全组J=0，所以只有探索有效”；“预测不到错误，所以不能改善训练”；“条件熵非零，所以一定值得奖励”；“信用质量达到20%，所以能检出2pp”；“shuffle无效已证明”；“P1数学覆盖高，所以模型规则被识别”；“72步必然更好”；“未显著，所以方法等效/无用”。

## 10.5 决策账本
所有正式结论必须同时填写：用的证据层（oracle/测量/目标/参数更新/任务效果/泛化）、配对单位、置信范围、可替代解释、范围限制。提前记录Claude关于负交互和本稿关于可能互补的不同预测，最终不按哪一方猜中选择报告。
