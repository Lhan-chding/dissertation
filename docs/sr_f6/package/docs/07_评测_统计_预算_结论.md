# 07｜评测、统计、预算与结论

## 7.1 面板与任务范围
所有54个正式端点和3个父checkpoint都评下列同一面板；不能只选b0评外部任务。每个checkpoint共6,010次回答：

|面板|题数×draw|用途|
|---|---:|---|
|COMPOSITION|768×4|主终点：6种全局未训练组合，每族32roots×4views；相对于活动有限候选库排除答案别名，不宣称所有可能错法零碰撞|
|ID|384×2|同规则新根、新数值，非未见组合|
|MECHANISM|192×4|自然/登记碰撞分层、相关/无关变化、绝对与关系正确性；不作为挑选赢家指标|
|CLASSOUT|192×2|48新roots×4views；双cell±12新编辑和复合错误候选，训练编辑库未用|
|NATURAL_INTERFACE|128×2|与正式图表任务配对但不要求新字段，检查收益是否依赖声明接口|
|LEGACY|128×4|冻结旧题ID，使用旧原生prompt/scorer；能力保持|
|CHARTQA|250×1|冻结外部题ID和既有两套评分口径；迁移与保持边界|

额外的NATURAL_INTERFACE问题由ID每家族前16题=96，再按固定散列从剩余ID取32，共128。它与ID是配对接口探针，不算新的独立root；单独报告，不合入主终点。自然接口末尾固定追加“Give brief working and end with exactly one line: Answer: <exact number>. Do not output JSON.”；冻结提取最后唯一Answer行，重复Answer标记、非精确值或末尾追加内容均判0，不按金标搜索数字。参考`natural_answer_score`。旧LEGACY/ChartQA仍用其原接口与原评分，不强套这条新规则。

LEGACY128和ChartQA250优先用项目已冻结题ID；若不可访问，不从网页寻找替代私有数据，也不悄悄换题。SOURCE_BINDING中确认真实ID、原始文件及scorer；缺失则不能声称完整保持/外部验证，正式矩阵先停以避免盲点。缺失不是模型负结果。

CLASSOUT严格实现见02补充：双cell编辑幅度12；不按候选覆盖最大化选择测试；世界/图形规则仍无歧义。该面板检验有限扩展，不声称覆盖任意自然图表。所有主面板失败、截断、无法提取答案留在分母。

## 7.2 主指标、四个估计量
主指标是答案A，与额外selected/bindings是否正确分开。draw→qid→root四views→六家族等权→三个固定父模型等权→三个重复等权。分层分母永久保留。

D0=U10−U00；F0=U01−U00；F1=U11−U10；I=U11−U10−U01+U00。单位同时报比例与百分点。交互可正可负；Claude的负交互只作竞争机制预期，不作单侧检验或通过条件。

四项使用双侧α=.05的Holm校正；若某项训练方差为零导致p不可定义，保留原始NA，校正家族中暂用p=1保守占位，不能删掉它减少比较数；同时报各项98.75% Bonferroni区间，不事后挑较容易显著的方法。总效应U11−U00和反馈平均效应作透明补充，不替换四项主估计量。

预登记机制对照在P1：U11−C_GLOBAL、U11−C_SHUF，单独两项Holm。仅当相应反馈在任务表现上有支持时解释机制；否则照报但不凭机制分数升级成功。不因控制臂更强而删除它。两个对照不在P0，不能用P1的打乱结果证明P0独有效应一定来自语义对应。C_GLOBAL与COND虽共享λ与标签，居中改变会连带改变系数幅度；此比较识别两个固定反馈方案的整体差异，不能单独归因为排除了幅度后的信息优势。

## 7.3 训练重复与固定父模型推断
对每个比较，在同父×同重复的臂端点上先做配对差d[b,r]。目标是三个固定父模型的均值，不把他们当全模型总体的随机样本。每父r=3独立训练重复。

主参数不确定性：各父内样本方差s_b²；V=Σ_b s_b²/(B²r)，SE=√V；Satterthwaite df=V² / Σ_b[(s_b²/(B²r))²/(r−1)]。用t区间与双侧p，再做Holm。名义上B(r−1)=6个训练重复自由度，实际异方差df可更低。若方差全为零，程序返回NA而不是CI=点值的“绝对确定”；检查共享seed/相同权重/评测粒度并另报条件root区间。

正式同时给交叉重采样敏感性：每父内重采3个paired repeats；家族内重采roots，所有臂/父共享root索引；10,000次，固定seed。它包含测试根与训练重复的可见变动，但3重复下bootstrap尾部本身不稳定。与t分析不一致时两者都报、结论收紧，不择优。

候选基线与所有端点评测共享draw种子只降方差，不能把4draw×768题当3,072个训练重复。保留按family/root/draw原始记录以复核。

## 7.4 精度与停止含义
2pp为预先定义的实质效应参考，不是已经保证的最小可检效应。须报告本次区间宽度与2pp关系。不显著不等于等效；只有合理区间整体落在[−2,+2]pp之内，才能在该范围内讨论实践等效。区间太宽：INCONCLUSIVE，不说信息无用。

旧LEGACY保持容许下降1pp，ChartQA容许下降2pp，作为单独非劣问题报告置信下界；250题本身限制外部精度，不能靠高点估计宣布无退化。多重保持判定和确认性/探索性分组在报告中明确，若同时宣称两项都保持需控制两项家族错误率。

父模型普查不是72步训练方差。一个开发重复的9条先导不能提供正式功效保证。当前选择3重复而非2是为了增加同父随机性证据，仍然有限。不得为得到显著增加第4重复、延长到96步或重定义题族。

## 7.6 允许出现的结果
- D0正、F0/F1无可靠增量：主要是本题组数据设计价值；不硬称新反馈算法胜利。
- F0/F1正、D0无增量：oracle反馈在该任务有学习价值；不硬称可辨识题组是必要原因。
- F0大于F1：与信息替代机制相容，非唯一因果解释；也可能饱和/难度不同，需配套轨迹。
- F1大于F0：与互补机制相容，同样不唯一。
- C_GLOBAL不差/更好：采用简单过程反馈；不维护条件化公式。
- C_SHUF也同样提升：不能把全部收益归因于语义对应，检查辅助扰动与优化效应。
- 声明变好但A/泛化不变：只支持声明行为变化，不支持真正任务能力改善。
- 全部区间宽：不确定；充分窄且无实质效应：限定分布、剂量、模型与任务的负结果。
- 只人工碰撞子集有效：报告该边界，不声称普遍多模态可靠性提升。
