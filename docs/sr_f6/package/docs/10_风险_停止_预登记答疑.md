# 10｜风险、停止与预登记答疑

|J被叫纯答案奖励|原J/证据/新V逐项分开|不能据本轮证明J相对A的独立贡献|

## 10.2 什么可以修，什么不能自动改
正式前纯实现错误（索引、hash、公式与合同不一致）允许修复并保留diff与失败日志；修复后重新生成科学受影响的全部开发证据，不能拿旧回执解锁新代码。

改变λ、权重、反馈标签、任务家族、碰撞比例、数据筛选、训练规模、主终点或因子构造属于科学变更；必须产生独立版本合同并由用户确认，不能称小补丁。当前包不授权无限配方搜索。

正式中硬件中断按同事务续跑；真实非有限值/不可恢复污染记录本路径异常并停止该路径，不自动替换seed。完整主矩阵不足时说明缺失模式，不能只分析完成的有利臂并维持原确认声称。

## 10.3 对“为什么不一次做感知、执行、动态控制”的回答
研究主线包含这些能力。首个可识别实验不等于定义了整个方向的边界。现有可验证语义信息足以先检验任务选择与绑定的学习价值；视觉P只检查提交事实，既不能说感知解决，也不能为了让P失败而制造歧义。真实视觉负担扩展是后续独立版本，不混入当前首次反馈效应。

执行自洽若无任务锚点可能鼓励错误；完全任务锚定的执行又接近答案正确性。所以本轮先测不奖，后续若发现独立可验证执行子目标再设计。

控制器需要跨独立状态的足够反馈响应样本，不能拿三个父模型的九个端点拟合高维控制器并声称泛化。本轮固定反馈不是退回只做selected，而是控制混淆所需的首项具体实例。

## 10.4 不应报告的结论
“P≈1，所以没有感知问题”；“S/J相关，所以S毫无价值”；“全组J=0，所以只有探索有效”；“预测不到错误，所以不能改善训练”；“条件熵非零，所以一定值得奖励”；“信用质量达到20%，所以能检出2pp”；“shuffle无效已证明”；“P1数学覆盖高，所以模型规则被识别”；“72步必然更好”；“未显著，所以方法等效/无用”。

## 10.5 决策账本
所有正式结论必须同时填写：用的证据层（oracle/测量/目标/参数更新/任务效果/泛化）、配对单位、置信范围、可替代解释、范围限制。提前记录Claude关于负交互和本稿关于可能互补的不同预测，最终不按哪一方猜中选择报告。
