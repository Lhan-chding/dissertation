# 01｜Claude 最新建议：采纳什么，改变什么

来源 A1=`sources/CLAUDE_ON_GPT_ROUND2_zh.md`；A2=`sources/f14_checks.py`。本章将来源观点与本设计决定分开，不把我们的修改写成 Claude 已经同意的结论。

## 采纳
1. 以 P0/P1 × J/固定 oracle 反馈作为首个核心实验，控制器不进本轮。原始研究问题保持宽，本轮实验保持可解释。
2. 不使用未锚定的关系残差奖励；部分反馈来自世界与查询可判定的任务子目标。
3. 同时保留声明、任务事实与跨题行为响应，任何一种都不宣称能够替代所有测量。
4. 在真实父模型上先检查协议、标签和实际信用，再开展正式训练。
5. 收回“J 不改善选择”“执行提升四到六倍”“72 步肯定小于 1pp”等旧强结论；C-LOCAL 的 +3.993pp 仍含覆盖变化，不升级为能力因果机制。

## 修改，且已写进实现
|Claude 最新提议|最终决定与理由|
|---|---|
|24 条正式路径，两个训练重复|主四格三个重复＝36 条，另两个必要强对照18条。预算没有用户给出的 GPU 小时上限；不能用更多回答 draw 假装增加训练重复。见精度敏感性表，而非承诺检出1pp。|
|S＋绑定＋执行都进反馈|主反馈固定 S 与任务相关 B；执行作为独立诊断。若执行完全以正确操作数和正确运算为锚，它与答案正确重叠；若只检查自写算式，就可能奖励一致错误。|
|绑定等于“所选对象”的世界值|B 必须覆盖**题目真正要求的对象及数值**，不是任选一个容易集合后如实读数就得分。原始声明集内的取值正确性另记诊断。|
|λ由信用系数质量达到某比例确定|λ=0.5、权重1/2固定；信用量、真实梯度与参数变化都记录，但不把系数比当学习价值，也不为稀少事件无限放大。|
|置换信用后必须与 J 统计上不可区分|取消。随机信用可能改变梯度方差、长度偏好和有限步轨迹；与 J 不同不是实现错误。C_SHUF 用于实测语义对应的作用。|
|J 对父模型必须显著改善才通过校准|取消。新协议和新题不保证短期 J 有显著收益。通过条件是正确实施、测量可用和数值有效；效果正负均可。|
|只看 FAIL 且 J=1 的不一致率|查看完整 A×J×S×B×证据分量，也检查全 J=0/全J=1组内信用。失败侧部分进展同样可能提供信息。|
|预期负交互|仅记录为 Claude 的方向性假设。竞争、互补、冗余均可能；确认检验双侧，不用方向筛结果。|
|将三个反馈分量的普通均值按J居中|采用同 J＋同可判模式居中，明确 UNKNOWN、单样本层与有限样本缩减；附简单全组信用对照。|
|预测效度为零就不能训练|不设普遍否决。预测未来失败与造成训练收益是不同估计对象；预测作为诊断，不伪装为反馈必然有效或无效的充分条件。|
|视觉事实P高＝感知已解决|不成立。P只是提交事实真实性。首轮不新造视觉退化，但保留视觉事实诊断；后续视觉负担实验必须单独注册。|

## 对 f14 实际重跑的补充
原脚本可执行，且残差一致错误反例、联合成功梯度权重、32次零成功上界、常数奖励抵消成立。**第3项的注释与数值不一致**：7/8 成功组中唯一失败的优势应为 −√7≈−2.646，不是 −0.378；该例两个项都为负，不存在所谓符号翻转。文件保留原脚本和原输出，不篡改；更正检查在 `qa/math_checks.json`。

这不是整份 Claude 分析失效，而是再次要求以具体公式与实际代码为准。所有新机制都须经同样核查。

## 最重要的边界
通过门只说明这个具体实验能够执行、存在某些比较机会，不证明论文贡献已经成立。Oracle 验证和条件化优势都有直接相关工作，不能把现成构件组合后自动称为首次算法。
