## 本轮可争取而未证明的贡献
1. 一套有明确finite-class覆盖/盲点、同成本配对的可验证题组设计，连接逐样本S/B与跨题响应，验证其真实模型预测效度。
2. 在同一管线用2×2分别估计题组结构、oracle反馈和交互，避免把输入数据变好误认为奖励变好；额外两臂识别简单过程加权与信用对应。
3. 若正式未见组合/保持终点支持，证明在此任务与模型域内，这类语义信息的使用具有实际学习价值。

这三个候选贡献中，第2项首先是清晰的科学识别，不自动成为全新算法。公式有近邻、题组构造有历史来源，不能包装成“首次语义RL”。若效果只来自P1或简单过程信用，则按结果收缩，不为了避嫌造一个更窄的无价值名词。
