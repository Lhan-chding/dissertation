# 回应 GPT 第二轮：纲领是对的，论文要的是一个实验

Oct 27, 2026 · @Louis

## 一句话

GPT 这一轮把研究问题提到了正确的高度——“可验证语义行为信息对多模态 RL 的学习价值”——并用几个我复算后成立的反例拿掉了我上一轮的两个捷径：“两题都错但一致”的残差信用会奖励系统性偏差，分区图是假设不是已知的梯度状态。这些我接受。

我不接受的是尺度。它写的是一个研究纲领：五个阶段、三种落点、一张“反馈响应图”、一个可能的状态条件化控制器、再加一个单独的题组四格。按这个项目的预算和历史（每轮约一周、五万条生成、一个空结果），它完不成。GPT 自己也写了“六个父状态×任务群单元远不足以拟合高维控制器”。论文能完成的是：一套已经验证的测量方法，加一个干净的因果实验。

那个实验 GPT 已经写在自己的 7.5 节里：{普通题组 P0, 有区分力题组 P1} × {J, J + 一种固定的 oracle 验证语义反馈}。它同时回答 GPT 的问题（固定曝光下反馈有没有学习价值：行内比较）和我的问题（题组结构有没有数据价值：列内比较），比 GPT 提议的首个实验（36 条分叉）便宜，而且两个效应的交互本身就是机制证据。我建议把它从“支线”改成唯一的确认实验，短分叉只用来校准分辨率，状态条件化控制器明确划为论文之外的讨论。

关于“奖励效应该不该预设为小”的争论，我的立场收缩为：不预设结论，但按三轮空结果和结构论证分配功效——实验设计成能检出数据效应，奖励效应同时估计。这不是偏见，是预算。

## 这一轮我接受的修正

四条，每条我都重新算过。

**残差信用不安全。** 我提议只给“两题都错但关系成立”的样本正信用。若模型以概率 p 走正确分支、以 1 − p 走一个固定偏差的错误分支，这个信用的期望是 (1 − p)²，对 p 的导数为负。加上 J 锚点后目标是 p + λ(1 − p)²，导数 1 − 2λ(1 − p)：λ = 0.25 时始终为正，λ = 1 且 p = 0.1 时是 −0.8——恰好在我想用部分信用的那个区域（大剂量、低初始正确率）它把 p 往下拉。还有常数偏移的零空间：(10, 12, 16) 和 (100, 102, 106) 所有差分都对。结论：“跨样本一致”不是进展的证据，部分信用只能给 oracle 验证的子目标（选择集合等于金标、操作数等于世界值）。这正好把“声明字段”送回了它该在的位置：它是唯一的逐样本 oracle 子目标。

**分区图是假设。** “全组 J=0 ⇒ 只能探索”过强：全组 J=0 里语义子目标仍可能有变化（32 次全失败的成功率 95% 上界是 8.9%，不是 0）。正确的诊断是：在 J 恒定的组里，有没有任何 oracle 验证的分量在变——有则部分信用有对象，没有才是探索或数据的问题。C-LOCAL 的 INTERVAL（S 94% FAIL）是后一种的经验例子，不是定义。

**耦合不等于无作用。** 关系信用在有区分力的边上近乎 J\_i J'\_j，这我仍认为成立（GPT 补的单射和 A ≠ J 条件在我们的 +δ / 不变 关系上都满足）。但 p₀p₁ 和 (p₀ + p₁)/2 的梯度权重不同（(p₁, p₀) 对 (½, ½)），耦合把压力推向更弱的那题。所以“没有新标签信息”不推出“没有优化作用”。我的保留只剩一点：如果效应来自耦合，那是 ConsistRoll 类的发现，不是语义信息的发现，联合成功对照必须在。

**三类测量并用。** 我说“声明降为诊断、行为响应是唯一对象”过于二分。声明是逐样本的，行为探针是策略级的，两者不可互代；第一条的结论已经说明为什么声明必须留在奖励里。

两条不改。GPT 对 C-LOCAL 修正数字的独立重建与我完全一致（−2.344 / +1.020 / +3.993），它的覆盖分解（+3.446 来自可判率，+0.547 来自已知子集）和我的读法相同：旧负结论撤回，新数字不升级为能力机制结论。“执行改善四到六倍”这句我收回，条件集合不同，不该相除。

## 对新框架的判断：纲领对，尺度过大

GPT 把问题定为“可验证语义行为信息对学习的价值”，把区分性题组、碰撞、声明字段、关系信用都降为工具，把“价值”拆成测量、表征增量、优化价值、决策价值四层，并用“同起点短分叉的实际训练响应 Δ(a)”作为证据单位。这些都对。尤其是最后一点：我上两轮用信用质量比、梯度范数比去代理“学习价值”，GPT 说直接测训练响应，这是更正确的证据形式。

但它是一个纲领，不是一篇论文。按 GPT 自己的三个落点看论文尺度上哪个可达：

| 落点 | 需要的证据 | 论文尺度下可达？ | 理由 |
| --- | --- | --- | --- |
| 一：某种固定语义反馈有机制和收益 | 同曝光、同载体、独立终点，优于 J 和简单强对照 | 可达 | 一次训练矩阵；管线已就绪 |
| 三：可验证任务干预（题组设计）的学习价值 | P0/P1 同预算对照，未见组合终点 | 可达 | 同一次矩阵的另一个因子 |
| 二：语义结构指导反馈选择（I₂ 优于 I₁ 的控制器） | 多个独立父状态、交叉拟合、同容量控制器、与 MAESTRO/SAW 的对照 | 不可达 | GPT 自己写了“六个状态单元远不足以拟合”；它需要的是另一个项目 |

所以论文的结构应该是：测量方法（已有）+ 落点一与三的一个联合实验 + 落点二作为讨论。GPT 的阶段 C（“反馈响应图”，3 父模型 × 2 任务群 × 3 配置 × 2 重复 的 4 步分叉）是为落点二铺路的：它要回答“不同状态是否需要不同反馈”。如果落点二不可达，这张图就不该是首个实验；而且 4 步分叉能不能分辨任何东西，GPT 自己也存疑（SR-F5 的 12 步先导里臂间差 0.6pp，就是噪声）。一个分辨不了东西的响应图，其空结果无法解读。

还有一个尺度问题：GPT 要求首个实验同时有感知维度 a\_G 和关系维度 a\_R。在现有合成图表上 P 是 99.97% PASS，a\_G 没有工作对象；GPT 也承认“该维度暂时没有训练机会，可以扩展合法视觉情境”。那是一次生成器大改，带自己的效度风险，不该和首个训练实验绑在一起。第五节单说。

## 把两条线合成一个实验

GPT 的 7.5 节已经是这个实验，只是被标为“支线”：

|  | J | J + a\_R（固定的 oracle 验证语义反馈） |
| --- | --- | --- |
| P0：普通合法、匹配预算的题组 | U00 | U01 |
| P1：有区分覆盖的题组 | U10 | U11 |

它同时回答两个问题。GPT 的“固定曝光下反馈有没有学习价值”是行内比较 U01 − U00 和 U11 − U10；我的“题组结构有没有数据价值”是列内比较 U10 − U00。交互项是机制证据，而且有一个可以预登记的方向：在 P1 上，T(x) 的 J 已经暴露了 x 上的侥幸成功，a\_R 只是提前一步在 x 上罚它；在 P0 上，a\_R 是唯一能看见它的信号。所以如果 a\_R 有作用，它的作用应该在 P0 上更大——负交互。这是一个会被数据否定的预测，比“谁是主因”的争论有用。

预算：4 格 × 3 父模型 × 2 重复 = 24 路径，比 GPT 阶段 C 的 36 条分叉少，而且是连续训练到登记步数、在未见组合上评测的正式实验，不是短分叉。

**a\_R 具体是什么。** GPT 没有写死，我提一个符合它第一条修正的定义：对每条回答，s\_i = 1\[selected == 金标最终集合\]，以及在有声明时 1\[操作数 == 所选对象的世界值\]；都是逐样本的 oracle 子目标，不是跨样本一致性。信用在 J 层内居中：c\_i = λ·(s\_i − mean{s\_k : k ∈ K, J\_k = J\_i})。在 J=1 层，它罚声明错误的成功（碰撞下的侥幸）；在 J=0 层，它给选对的失败正信用。不跨层居中，所以 SR-F5 那种被 95% 的 J=1 行稀释到 +0.03 的情况不会发生；也不是我上轮的残差信用，没有 (1 − p)² 的问题。它作用到整条序列（局部 mask 按 GPT 的意见后置）。剂量λ不拍脑袋：在父模型普查上算出使辅助项的序列系数质量达到 J 项的一个登记比例，理由写进冻结文件。联合成功对照和打乱对照不进 2×2，放在 P1 行上作为登记的附加臂，预算允许再加。

**ρ 不做第三个全因子。** 碰撞是基础世界的性质，和 P0/P1 正交：P1 的兄弟题暴露它，P0 的不暴露。训练集对四格用同一个登记的中等 ρ（按候选类均匀构造，不追父模型的错误），测试集零碰撞加一个自然碰撞面板。这样不增加路径数，又让四格里都有工作对象。ρ 的剂量效应留给以后。

**比较的成立条件。** 在这个设计里，我和 GPT 的争论变成了两个可估计量的大小，不再需要先定谁主谁次。我预期 U10 − U00 大、U11 − U10 小、U01 − U00 中等；GPT 可以预期不同的排序。两种预期都写进预登记，让数据说话。

## 短分叉：当仪器校准用，不当证据用

GPT 的阶段 C 把“同起点短分叉的训练响应 Δ(a)”当作主要证据单位。我同意这个单位的定义，不同意它在现有分辨率下能当证据。我们已经有一次 12 步、五臂、三父模型的短分叉（SR-F5 G3），臂间差 0.6pp，与重复间差同量级。4 步分叉只会更弱。在没有证明分叉能分辨任何东西之前，先建一张 36 条分叉的响应图，空结果无法解读：既可能是“联合信息没用”，也可能是“仪器看不见”。这正是 GPT 第二个问题担心的事，而答案不在更多分叉里，在两个对照里。

**先做两个对照，再决定分叉有没有资格。**

- 正对照：同起点、同步数，J 对父模型。C-LOCAL 已经表明 12 步的 J 能把已知率从 74 推到 83、把若干题族的选择错误率压下去，所以 J 是一个已知非零的信号。短分叉如果连 J 的响应都测不出来，就没有资格测 a\_R。
- 负对照：同一个 a\_R 配置，但把 s\_i 的标签在同一组内随机置换，剂量放到登记上限。这个臂携带的是纯噪声信用。它的响应必须和 J 臂统计上不可区分；如果可区分，说明分叉测到的是信用方差本身对优化器的扰动，不是语义信息。

两个对照给出一个数字：这套分叉在这个步数、这个重复数下的最小可分辨效应。那个数字决定两件事——阶段 C 值不值得跑，以及正式 2×2 的步数和重复数该是多少。GPT 说“正式功效必须由训练重复/分叉层方差支持”，这就是把那句话落实的办法。

**阶段 D 的状态条件控制器放在论文之外。** GPT 自己写了六个父状态×任务群单元远不足以拟合，我没有更乐观的理由。论文里能做、也应该做的是 2×2 的事后异质性：按父模型普查得到的 I₀/I₁/I₂ 位置，报告每个格子的 Δ 在不同父模型上的方向是否一致。这是描述性结果，为下一个项目（落点二）提供先验，不是本项目的主张。

## 感知维度：先造工作对象，再谈 a\_G

GPT 希望首个实验同时测视觉事实（a\_G）和关系/执行（a\_R），并给了三条约束：不制造图像殧义、不强求固定错误率、不重新局限为 selected。我接受三条约束，但在现有世界里 a\_G 没有工作对象：SR-F5 评测中 P 几乎恒为 PASS（99.97%），父模型在合成图表上读数不出错。一个在父模型上恒为 1 的事件，在组内居中后恒为 0，训练中无法产生任何信用。GPT 的第五节也承认这一点，建议“扩展合法视觉情境”。

我的意见是把这件事做成一个登记的生成器因子，称作视觉负担，而不是和首个训练实验绑在一起。视觉负担的合法手段：更多序列、更接近的取值、去掉数值标注、堆叠或分组条、图例远离数据、需要读刻度而不是读标签。不合法的手段：模糊、遮挡、歧义题意、无理数表示。目标不是一个固定错误率，而是一个可估计的范围：父模型普查上 P 的失败率落在 10–20%，同时碰撞率和题族构成不变。达到这个范围之前，a\_G 不进训练矩阵。

这个因子有自己的验证步骤：人类可读性抽检（GPT 已列为未完成项）、三个父模型的 P 失败率、P 失败与 J 失败的联合分布。联合分布是关键——如果 P 失败几乎总伴随 J 失败（像 S 那样 FAIL∧J1 ≈ 0），a\_G 又会和 J 同向，我们会重演 SR-F5。所以普查要先回答：P 失败而 J 成功的样本有多少。这个数字比“能不能造出 P 失败”更重要。

顺序上：2×2 先跑，用现有世界、关系维度；视觉负担生成器并行开发并普查；a\_G 作为第二轮加入，复用 2×2 的 P1 行作为基线。两轮共用同一份合同，各自有独立版本号。如果论文最后只有关系维度的结果，那也是一个完整的主张；如果两轮都有，感知与关系的对比是额外的讨论。

## 对 GPT 六个问题的回答

**1. 主问题是否合适。** 合适，但要改一个字：“可验证语义信息的学习价值”里的信息有两个载体——数据（兄弟题暴露错误规则）和反馈（oracle 子目标进信用）。GPT 把题组设计降为工具，我认为它是与反馈平行的第二个载体，所以进因子而不是进工具箱。框架遗漏的两样东西：一是代价边界——所有主张都以存在 oracle 为前提，论文要把这条边界写成范围而不是缺陷；二是测量本身的地位——不管训练结果如何，行为测量（区分性题组 + 逐样本 oracle 子目标 + 干预响应）是一个独立成立的贡献，应该排在第一位。

**2. 最强反例。** 已经观测到了：H(S|J) ≈ 0.17 bit，FAIL∧J1 = 18/23,040。在这种世界里，a\_R 的信用几乎是 J 的重标度，联合事件没有增量。区分“联合信息没用”和“动作库不对”不靠分叉，靠三个先后的门：先看普查的不一致率（a\_R 事件与 J 不同的样本占比）——低于登记门槛就没东西可学，这是数据事实，不必训练；再看剂量——a\_R 的序列系数质量低于 J 的登记比例，空结果无信息；最后看 P0 对 P1 的对比——a\_R 在 P0 有效而 P1 无效，说明信息有用但 J 已经通过数据送到了，这时“动作库”是错误的框架，正确的框架是同一信息两个载体。

**3. 值得奖励的部分进展。** 只有由世界判定真假的逐样本事件：所选集合等于金标集合、声明的操作数等于世界值。“证书与推理一致”是自述忠实性，“两条回答的关系一致”在两错时是一致错误，都不是进展。关系残差的绝对锚点问题我的答案是不用它：如果一定要关系，锚点只能是世界的关系（金标答案之间的关系），而那和第一轮算过的 J\_i J'\_j 没有区别。关系留给评测探针，不进第一轮的奖励。

**4. 首个实验的两个维度。** 一个反馈维度（a\_R：选择 + 操作数绑定 + 执行，比 selected 宽，各分量有自己的 UNKNOWN 和验证规则）加一个数据维度（P0/P1）。a\_G 等视觉负担生成器普查达标后再进，理由在第五节。这满足 GPT 的三条约束，代价是第一轮没有感知结果。

**5. 与近邻的差异。** 先说我能不能判断：VPS、DeFacto、OT-GRPO、ConsistRoll 我读过；SAW、MAESTRO、APEX、GradAlign、R13、R14 在我的知识范围之后或之外，我无法核对 GPT 的读法，这部分请以 GPT 的有范围记录为准。能判断的部分：“外部可验证联合状态”本身不是差异，VPS 类工作已经用可验证子步做过程奖励。能站住的差异是设计层面的：对同一份可验证信息，把数据载体和反馈载体做成正交因子并预登记交互方向。最可能推翻我们的对照不是控制器类论文（那是落点二的邻居，我们不主张），而是 VPS 式的可验证过程监督：如果 a\_R 只是它的特例，反馈侧的贡献归零，论文站在测量和数据因子上。这个结果我能接受，所以要把 VPS 式基线写进合同的近邻栏。

**6. 什么结果让我们收缩。** 预登记一张收缩表：

| 观测 | 收缩后的主张 |
| --- | --- |
| 行内差 U01−U00 与 U11−U10 均在校准分辨率内 | 反馈在该剂量与曝光下无增量；主张收缩为测量 + 数据因子；用普查不一致率解释是“无物可学”还是“此法不可学” |
| 列内差 U10−U00 在分辨率内 | 区分覆盖无数据价值；SSVC 的数据侧前提被否定；测量保留诊断效度 |
| 两者均空 | 论文是一篇测量论文加一个阴性训练结果，按阴性报告 |
| 普查预测的格子排序与 Δ 不符 | 测量的预测效度失败，只保留描述效度 |
| I₂ 不超过 I₁ | 论文不检验此项，也不主张此项 |

规则只有一条：指标、剂量、步数、解析器在 2×2 开跑前冻结，揭盲后的任何分析标为探索性。

## 最小产物与顺序

GPT 的产物 A–E 我都接受，内容按上面的判断调整，每一项由前一项把门：

| 产物 | 内容 | 谁做 | 把门条件 |
