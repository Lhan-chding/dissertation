# SR-F6 题组设计：用途、实际操纵与尚未证明的环节

2026-10-27。本次诊断只读取已经生成的注册数学 bank，不修改任务、臂、seed、
阈值或冻结数据，不调用模型，不重复核验图片。

**结论：P1 确实产生了非空、可复算的有限候选区分增量；这一增量并非主要由
重复候选权重或隐藏分母造成。但它目前只证明生成策略按定义改变了题目分布，
尚不能证明真实模型能利用这些题目学得更好。多数新增区分涉及在 anchor
已经答错的候选；不能把全部 coverage 增量解释为揭露“碰巧答对”。**

## 信息实际怎样进入训练

P0/P1 每个 root 含 anchor 和三个编辑视图，但模型每次只接收一道题。G8
和原生优势也只在该题内计算。当前实验没有把四题一起展示给模型，没有
跨题损失，也没有把有限候选区分证书直接当奖励。因此 P1 的作用路径是：
选择不同的合法训练实例 → 让某些错误行为更容易在逐题回答中暴露 → J 或
S/B 反馈可能改变参数。四题关系本身不会自动变成模型已经获得的信息。

这一路径有三个尚须用真实证据连接的环节：有限候选与父模型实际错误行为的
重叠、实际回答中可利用的信用机会、更新后的未见任务收益。CPU 证书只覆盖
第一环节的一部分数学前提。不能因证书成立就宣称已识别模型错误程序，
也不能因某个模型回答不匹配有限库就删除该回答或认为它没有价值。

## 已固定 TRAIN 的实际诊断

来源为 `.local/sr_f6_cpu_preparation/DATA/ROOT_CERTIFICATES_PRIVATE.jsonl`。
完整逐 root 见 `.local/sr_f6_group_diagnostics/MATH_ROOTS.jsonl`；分层汇总见
同目录 `MATH_SUMMARY.json`。以下均为 288 个 TRAIN roots 的真实数学结果。

|覆盖口径|P0|P1|差值|
|---|---:|---:|---:|
|每根活跃候选等权覆盖率均值|0.765520|0.896978|+0.131458|
|每根全部注册候选等权覆盖率均值|0.720238|0.841787|+0.121548|
|合并完全相同 pool 区分签名后的覆盖率均值|0.750223|0.894130|+0.143907|
|被覆盖的 root×候选个数|1,665|1,945|+280|
|anchor 同答案且活跃的候选被编辑揭露个数|145|188|+43|

每根平均注册 8 个候选、活跃 7.5104 个；合并完全相同的二进制编辑区分签名后
为 6.6597 个。重复签名主要集中于 INTERVAL 和 SIGNED。为检验“重复候选
刷高”，本诊断在相同三桶的所有可行编辑组合上额外计算去重签名覆盖上限；
**288 根现有 P1 全部也达到该敏感性目标的可行最优，没有低于去重最优的根。**
这只是诊断，不替换注册目标或重新挑题。保留全部注册候选分母时仍有
0.12155 增量，说明 active 分母筛选也不能单独解释操纵。

pool blind 保留完整计数：reverse_tie 为 114/240 个注册出现，wrong_rank
3/240，toggle_start 8/48，toggle_end 12/48，wrong_aggregate 4/288。
这些候选在当前合法编辑池没有响应区分证据；没有从全候选报告中删除。
“pool blind”不等于永远正确或现实中不会出错。

家族的 active 覆盖率平均增量分别为：BINDING 0.191964、IMPACT 0.162202、
TIES 0.080729、SIGNED 0.100777、INTERVAL 0.107242、K_DIRECTION 0.145833。
96 个强造碰撞 roots 的平均增量为 0.130634；192 个非强造 roots 为
0.131870。操纵并非仅靠强造子层存在，不过两层都仍是同一合成任务分布。

### 保留的不利和无差异病例

- P0/P1 整个四题组完全相同为 **20/288（6.94%）**；三个编辑视图中逐槽
  相同为 **321/864（37.15%）**。anchor 原本就全部共享。保留这些重复是
  合法随机基线的结果，不能为了加大差异强制 P0 择差。
- 活跃 anchor 同答案候选共有 222 个。覆盖净增 280 中，净增的同答案候选
  揭露只有 43；其余净增涉及 anchor 已错误候选的响应变化。两种证据都可
  有训练意义，但不应混为同一件事。
- `TRAIN_IMPACT_0015`、`TRAIN_SIGNED_0046` 中，P1 揭露的 anchor
  同答案候选个数反而少于 P0。整体响应覆盖最大化不保证每个局部目标单调。
- 96 个强造 boundary_swap 碰撞 roots 中，现有 P1 有 3 根仍没有揭露该
  特定碰撞：`TRAIN_BINDING_0039`、`TRAIN_IMPACT_0015`、
  `TRAIN_TIES_0021`。它们的合法池存在见证，但所选三桶/三编辑的整体目标
  没有保证选择这个见证。原合同优化全候选响应覆盖，没有承诺每根都揭露
  boundary_swap，因此记录局限，不改数据、不加 gate、不重选 seed。

## 匹配了什么，还有什么没有匹配

所有 864 个配对编辑槽的成本桶和真实答案变化量匹配。成本桶包含编辑列、
符号、幅度、金标集合大小是否改变、答案变化量。由于共享 anchor 与答案
delta，两个因子的平均绝对答案完全相同，均为 88.303935。

这些约束没有让所有难度属性相同：

|实际编辑属性|P0|P1|
|---|---:|---:|
|金标最终成员发生变化|9.4907%|9.9537%|
|集合大小不变但成员替换|8.9120%|9.3750%|
|TOPK 排名边界同值|22.5000%|24.7222%|
|编辑的是 anchor 原选中类别|46.4120%|48.3796%|
|TOPK 边界数值间隔均值|7.7417|7.7500|

因此 D0 的对象仍是整个 P1 题目构造策略的效果，包括所改变的具体输入和
可能连带的任务难度。它不是把所有难度完全控制以后“coverage 这个数字”
的纯因果效应。正式结果后不能根据父模型准确率重新匹配题目或删除困难根。

## 真实父模型数据到达后如何验证相关性

`census_diagnostics(records, private_tasks)` 仅接收已有 DEV_CAL 原始回答。
它重新评分以检测陈旧标签，校验原始回答身份与固定父策略，并保留所有
无效回答、UNKNOWN、无有限候选匹配和未完整 G8。部分普查明确记
`DERIVED_PARTIAL_MATRIX`；不输出科学门 PASS，不追加推理。

输出包括：

1. 每父 × 因子 × 家族 × 全部/强造/非强造的 A/J/V、S/B 可判率，anchor
   与编辑视图的 A/J，以及同父同 root 同 draw 的 P1−P0 配对差。
2. anchor 正确而编辑后错误的脆弱响应；两题绝对均正确；答案变化量正确；
   两题都错但变化量正确单列。相对关系 UNKNOWN 保留原因及完整分母。
3. 完整 G8 的 COND 非零、可交换、单次 SHUF 实际改变和真实信用量；
   coverage 与非零组比例的描述性相关按 root 汇总，不给 p 值或因果归因。
4. 固定使用 anchor、v1、v2 拟合候选行为，v3 只作留出预测；同时报告
   绝对答案兼容和允许加法偏移的响应差兼容。没有候选、多候选、不同候选
   对 v3 预测不一致、无法解析均保留。匹配不叫“识别内部程序”。

跨视图按 draw 索引配对只是描述性匹配；这些回答独立采样，不共享隐藏轨迹。
相同因子 anchor 使用共同 seed 也不是新的独立重复。留出预测只检查有限
行为模型的外推，不构成优化收益。此段函数通过程序夹具测试，但**尚无真实
SR-F6 模型普查结果**，不能将夹具计数当父模型表现。

## 验证与结论边界

数学诊断通过现有 bank 重算；对应源代码为 `src/sr_f6/group_diagnostics.py`。
数据、调度及本诊断合计 **19 个测试通过**，Ruff 通过。新增测试专门保留
两错一致反例、留出答案不能影响拟合、无效回答分母、缺失 G8 的 UNKNOWN、
陈旧评分拒绝，以及上述全部不利数学病例。

另已修复一个数据审核漏洞：CLASSOUT 三个编辑原先缺少实际世界去重检查。
现在每 root/factor 四个世界必须互异，CLASSOUT 描述必须恰好对应实际两个
不同类别 ±12 改动。复制视图和伪描述的回归测试通过；从现有完整 bank
重新审核 4,704 题仍 PASS，未修改数据。

下一步是否继续使用当前题组，应依据登记的真实可观测性/曝光门；不能将
此处额外描述性数值变成事后调题或择优门。最终数据学习价值仍由 D0 衡量，
反馈作用由 F0/F1 和交互 I 衡量，并同时报告固定强对照、全部父模型/重复、
不确定性、LEGACY/ChartQA 保持边界。负结果或不确定结果必须保留。
