# Qwen3.5-9B 固定公共起点测量结论

测量已完成384题×4次回答，共1536条，来自16个根家系。公共起点是未经本轮训练的Qwen3.5-9B；两个格式面板均384/384合格，没有触发SFT桥接。

精确P/C/A六格按111、100、011、010、001、000排列为：1451, 58, 14, 13, 0, 0。全部1536条具备联合评分字段；容差八格单独保留，不能套用精确六格恒等式。

58条属于读数正确而答案错误，均出现在range任务；27条读数有误，其中14条仍在自身读数计算一致的条件下给出正确答案（011格）。预定义的001补偿格为0。不能把这些输出分类当作内部认知机制。z的重采样区间[0,0]反映当前面板无此事件，不证明总体不可能发生。

S仅在27条非零读数误差回答中定义，其余1509条为missing。根等权条件S仅由6/16个根支撑；不能把缺失补0，也不能当成全根固定权重均值。2000次重采样中1997次有定义、3次undefined。误差分解恒等式逐条核验的最大精确残差为0。

128组匹配sum/difference提示的根等权C11=0.986979、C22=0.989583、C12=0.989258；噪声校正差异为−0.0009765625，95%描述区间[−0.0029296875,0]。负估计照实保留，不截为0，不用于内部机制结论。

384题中13题在四次回答内观察到非恒定答案奖励。G=8插件值和Beta(1/2,1/2)后验仅为带假设的支持诊断，不是训练收益或安全置信界。self字段NLL/熵与gold teacher-forcing指标分别呈现；gold答案前缀包含真值读数，不能替代自由生成性能。

本轮不依据这些结果调题、换种子、增加奖励或延长训练。ENGINE只做预登记的恢复一致性测试，不替换公共起点。最终工程状态与成本见[最终审计报告](FINAL_AUDIT_REPORT_zh.md)，完整量化表及分母见[科学报告](SCIENTIFIC_RESULTS_zh.md)。MM-DEV、MM-LOCK、MM-CAL与在线阶段均未授权。
