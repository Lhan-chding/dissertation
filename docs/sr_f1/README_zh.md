## 原包之外的技术修复

`src/sr_f1/contract.py` 保持参考奖励和评分语义，给 Decimal 数字解析增加转换前的界限检查，并把极端指数的 `decimal.InvalidOperation` 转为可记账的无效回答。原参考实现对短载荷 `1e99999999999999999999999999999999999999` 会抛出异常，对 `1e999999999` 可能在检查界限前构造巨大整数。补丁不改变有限合法答案的精确判据，原包不改写；回归覆盖巨正/负指数、零和分母边界。
