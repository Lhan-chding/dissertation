# 本次执行决定与最近讨论的对应

| 讨论中的问题 | 本次选择 | 是否新决定 |
|---|---|---|
| 先预测数据配方，还是直接研究奖励 | 直接固定数据比较5反馈；不拟合外层响应预测器 | 承接最新方向 |
| 两板块/三模块 | 程序题组与测量构成模块I；固定反馈学习构成模块II的首轮 | 承接最近讨论 |
| 新意过度收窄为门控率 | 主读数是未见目标J、普通问答A、组合与外部迁移；门控率只作接口审计 | 承接最新讨论 |
| 所有组件都无先例才值得做？ | 不要求；真实实施GDPO式强对照，简单PART也保留 | 承接最近讨论 |
| 条件题的evidence到底包含什么 | 覆盖能核验条件的全部必要值，不只报参与答案的值 | 承接证据契约并落实到四类AST |
| 语言表达如何生成 | 首版3套固定模板，2训练1持出；不调用外部教师、不自由回译搜索 | 新的范围决定；不声称已蒸馏大规模题库 |
| 哪些组合任务 | CROSS、THRESHOLD、TOPK、INTERVAL；每族8变体；4个AST组合留出 | 新的事前设计 |
| 奖励比较数量 | A/J/PART/DEC/GATE共5臂，3seed、96步、B16/G8 | 新的数值决定，不是旧提议已签收 |
| GDPO与PART是否同组件 | (J,E,E*p)；权重(1,.5,.5)；PART的β=.5恰与其原始标量组成对应 | 新的公平对照落实 |
| 混合J组是否保留失败内部信用 | κ=.25有界精化；不声称保证能力提高；有CPU反例 | 候选进入真实对照，κ本次固定 |
| 计算支持何时加入 | 5种诊断视图只测不训，下一轮另注册支持干预 | 承接“不偷偷加SFT” |
| 动态语义状态的真实增量 | 本轮不认证；后续比较最佳固定/常规/语义/错配诊断 | 阶段划分，不取消长期目标 |
| F2地位 | 独立；不取消/修改、不用其终点挑起点 | 保持用户边界；本地不知道服务器进度 |
| GPU时间 | 无累计时间停止；调度器租约正常续跑 | 用户已明确要求 |

本文件明确的是一项有限实验，不宣称本配方最优、不承诺96步足够分辨任何小效应。没有观察到清楚收益时，按原身份完成报告；不能从“定义和CPU测试都对”推断方法有效。
