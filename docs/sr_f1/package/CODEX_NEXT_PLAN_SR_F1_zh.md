## 0. 本轮最终决定：做什么、为什么做、到哪里结束

### 0.1 本轮真正的问题

> **在同一套具有条件理解、证据读取和组合运算要求的图表题上，只改变强化学习反馈：答案奖励、精确联合奖励、固定部分奖励、GDPO 式处理、目标优先的有界门控精化，哪些反馈能提高未见任务的证据—答案联合正确性，并迁移到不要求证据字段的普通问答？**

这一步不以“门控触发率预测准确”作为成功，不要求先学一个数据配方响应预测器。它回答后续诊断驱动训练首先必须知道的事：**可用反馈库里到底有什么是有效的，什么不足以解决当前失败。**

### 0.2 本轮授权范围

1. 在独立目录实现、校验并渲染新题组；恢复已授权的 9B 多模态接口。
2. 检查新 `evidence + answer` 协议；仅在格式覆盖确实不足时进行一次所有臂共有的短桥接。
3. 在固定监测题上采样，形成语义事件、奖励区别和实际优势的测量。
4. **5 种固定反馈 × 3 个配对训练种子 = 15 条科学训练路径，每条 96 次更新。**
5. 全量完成注册终点、题组变化、无证据字段问答、组合/表达/外观迁移及 ChartQA 外部评价。
6. 原始回答级独立重评分、完整成本和失败记账、一次性揭晓并交付中文报告。

### 0.3 这一步与长期方法的连接

长期问题仍是“语义诊断是否帮助给出有效反馈并改善能力”。本轮直接检验**反馈内容与信用接口**，提供后续反馈选择所需的实证基础。它**不独立证明**慢尺度语义状态比简单难度更会匹配反馈，也不证明诊断题组优于所有常规生成数据。

本轮之后的诊断路由、错配诊断对照、动态课程和计算支持训练，需要根据本轮结果另写方案。**本文件不自动启动它们**，不把未知规则塞进一个“智能 agent”。

### 0.4 不改变的用户约束

- 不换 3B、不换其他 9B、不换量化版本；使用指定 Qwen3.5-9B 字节身份。
- 不恢复 SER-J23；不新增符号机制科学训练。
- 旧 F2 不是本轮前置条件。**不读 F2 终点挑起点或选超参数，不追溯修改 F2，不自动取消其已运行作业。**本轮模型起点从原未训练 9B 建立。
- 全项目最多使用当前实际获批的 5 个单卡 worker；若 F2 正占卡，统一排队，不另行多占 5 张。
- GPU 小时仅记账。调度器单作业租约照常遵守，以检查点续跑；它不是科学实验停止标准。
- 不用“没有时间阈值”解释为可以训练到显著、随结果加难题或不停加种子。

## 2. 任务设计：让错误具有语义结构，不靠故意做模糊图

### 2.1 固定世界与视觉载体

- 每个根世界含 January、February、March、April 四个有序类别；主系列为 Alpha、Beta。
- 数值为 10–90 的整数 count。图轴固定 0–100，主刻度10、细网格5；不画数值标签。
- `grouped_bar` 与 `line` 两种载体；程序渲染 1024×768。图标题仅为 `Quarterly quantities`，不含根ID、答案或查询类型。
- 第三个系列 Gamma 仅在无关信息变体中出现，问题不使用其值。
- 数值真值由程序独立执行；不将教师回答当真值。
- 原生 processor 采用固定的 786,432 像素目标预算，记录 resize 后尺寸及视觉 token。合成图期望保持 1024×768；不允许裁掉图例、刻度、类别。
- 在实际 processor 后检查：每 count 至少3像素、主要字符有效高度至少9像素。它们是技术可读性条件，不是人类或模型100%正确保证。

本地renderer只是参考实现。若服务器字体不同，先定位同一字体字节；不得随每个臂更换字体/布局。禁止分享字体文件；只登记本地路径和hash。

### 2.2 四类训练查询

| 族 | 基础查询 | 需要核验的事实 | 它没有单独认证的内部能力 |
|---|---|---|---|
| CROSS | 对 Alpha 严格大于 Beta 的类别，求 Alpha 值之和 | 两系列全部4类别，共8值；包括最后被排除的类别 | 不把完整证据输出视为“已看到内部筛选过程” |
| THRESHOLD | Alpha 至少为50的类别有多少个 | Alpha全部4值 | 不把答案错唯一归为算术错误 |
| TOPK | 按Alpha选最高两个类别，求这些类别的Beta之和 | 两系列全部4类别，共8值 | 不要求唯一语言推理链 |
| INTERVAL | February到April（含端点）内，逐类别Alpha−Beta的最大值 | 区间内两系列，共6值 | 不把时间条件和数值计算假设为相互独立 |

各族还有下表规定的变体，因此模型不只记住一条运算。模型需要理解自然语言中的比较、范围、排序和聚合关系。**E度量证据覆盖，不是自动读出模型心中选中了哪些类别。**

### 2.3 八个同根变体，均在独立上下文提问

| ID | 变换 | 精确契约 |
|---|---|---|
| v0 | 原题 | 原世界和基础查询 |
| v1 | 表面等价 | 只改调色/图例顺序；实体含义、数据和查询不变 |
| v2 | 无关信息 | 新增Gamma；目标答案不变，不要求报告Gamma |
| v3 | 相关证据改变 | 只改一个所需Alpha或Beta单元；程序保证真实答案改变；不使用模型选择值 |
| v4 | 运算变化 | CROSS sum→mean；THRESHOLD count→sum；TOPK sum→range；INTERVAL max→min |
| v5 | 同义表达 | 图像与AST都不变，使用第二个已冻结英文表达模板 |
| v6/v7 | 查询语义对 | CROSS和THRESHOLD在同一含等号边界的世界问严格/非严格；TOPK问最高2/最低2；INTERVAL问含/不含左端点 |

v6/v7每对图像完全相同、查询不同、真实答案不同。v3保证答案改变。v4只保证查询改变，**不强行保证每根答案都不同**；同答案和异答案分别记账。

无关信息、表面变体不能被当作完整内部机制辨识。它们提供外部受控行为测试；两题都对不等于证明采用了某条神经算法。

### 2.4 真实语言生成的边界

首版使用程序可执行AST和本包冻结的3组自然语言表述：`train_a`、`train_b`、`test_c`。前两组进入训练；第三组仅用于表达迁移。这些是本次写作阶段生成并经查询规则对齐的受控模板，**不是额外调用教师生成了一个大语料库**。

本轮执行不依赖外部API或另一个教师checkpoint，不开自由式教师改写、蒸馏或回译搜索。这样先隔离反馈效果，避免语言生成质量和奖励同时变化。后续扩大语言覆盖是独立增量；当前不能称为开放域语言理解基准。

模板保持英文；中文报告用于研究交流。不要在同一训练比较中临时切换中文题目。

### 2.5 查询空集、分数和并列的规则

- 空选择：sum/count = 0；mean/range/max/min = null。
- 一个值的range = 0。
- 均值必须精确，可输出JSON整数/精确有限小数，或形如 `"98/3"` 的分数字符串；不允许按gold四舍五入。
- 排序并列按图上打印的类别顺序处理；优先级在所有提示中一致。
- 所有证据读数要求整数count；答案可为负数或分数。
- 不做单位换算、双轴、对数轴和开放式否定范围。本版难度来自明确组合，而不是缺少定义。

每池按四类查询根数等分。16题/根 = 两种图 × 八变体。不是把4,800道题当4,800个独立根。

### 3.2 组合迁移的明确内容

训练已见：CROSS sum/mean；THRESHOLD count/sum；TOPK sum/range；INTERVAL max/min。

组合留出为：CROSS range；THRESHOLD mean；TOPK mean；INTERVAL mean。对应基本比较、选择、差值及聚合运算均在训练其他组合中出现。清单检查得到 **12种训练AST骨架、4种留出AST骨架、交集为0**。

这是一种有限的组合迁移，不是任意深度推理外推。表达和外观分别独立成池，不把同时改变多因素的数据称为单因素迁移。

### 3.3 根隔离与构造选择

完整根及其相关值、边界值、外观、措辞变体不得跨池。程序同时检查跨根的Alpha/Beta完整数值世界碰撞。按规则重抽冲突或不满足答案变化契约的候选合法；按模型答错/答对重抽不合法。

CROSS/THRESHOLD事前规定每8个同族根中有一个空选择原题；其余原题非空。INTERVAL构造使左端点的差值为区间最大，保证边界对可辨。**这改变了具体任务分布，应如实记录；它不是模型表现筛选。**

答案相同不等于泄漏，不全局排除等答案问题。训练确实可能看到同根多种视图，这是本轮的数据处理；不得称96个根为1,536个独立语义世界。

### 3.4 文件与模型输入隔离

- `ROOTS_AUDIT_ONLY.jsonl`：真值世界，仅生成器/验证器可读。
- `TASKS_GOLD_AUDIT_ONLY.jsonl`：题目和评分真值，仅审核侧使用。
- `MODEL_INPUTS.jsonl`：执行端按qid取图像与text；**qid和路径不能串入prompt**。
- `manifests/schedules/`：3份已生成的固定输入流，所有奖励臂按种子配对。

运行前负测试：修改sidecar的answer/required_evidence/root标签，模型输入张量必须不变；只有真正更改图像或问题时模型输入才改变。PNG不写入gold文本元数据。

## 4. 输出与评分契约：两字段，不奖励参考措辞

### 4.1 原始目标协议

```json
{
  "evidence": [
    {"series": "Alpha", "category": "January", "value": 30},
    {"series": "Beta", "category": "January", "value": 20}
  ],
  "answer": 56
}
```

上面仅示意entry格式，不是完整查询的gold输出。CROSS实际必须报告8个entry，不能只报参与求和的两个值。

证据顺序自由，实体标识使用图中原标签。不给唯一CoT真值；不要求复制op、chart_type或教师解释。生成的全部completion都进入同一序列级loss，包括evidence和answer；本轮不引入token前缀信用的新变量。

### 4.2 指标

- `E`：所报告实体键集合恰好等于需要核验的集合；不多、不少、不重复。
- `p_read`：所有所需实体中，数值正确的比例；缺失计错。合法但多报时可保留此诊断，但下面的反馈用 `E*p_read` 防止靠多报得分。
- `P`：E=1且所有读数正确。这里P是完整证据正确，不直接等同旧F2的裸读数向量正确率。
- `A`：模型答案满足原任务精确真值。
- `J=P*A`：完整证据与答案均正确，首要指标。
- `C`：证据完整可评分时，将模型报告数值代入真实查询，看模型答案是否与该计算一致。**只作诊断，不单独奖励自洽的错误世界。**

同时输出各字段合法性、缺失、多报、重复、截断、格式覆盖。`E=1,P=1,A=0`称“正确证据下的任务执行失败”，不唯一称为纯计算瓶颈；可能涉及条件、排序或聚合。

### 4.3 解析规则

以 `reference/semantic_contract.py::score` 为精确参考：

- 整个输出必须为可解析JSON对象；重复JSON键、非有限数、代码围栏、未知顶层键均不修复，整条无效。
- 顶层允许字段缺失；缺evidence不删除一个原本可评分的answer，反之亦然。语义评分与字段覆盖分开。
- evidence entry的键必须恰为series/category/value；重复实体导致该evidence字段无效，不“只取最后一个”。
- JSON布尔不是数字；无穷、NaN、表达式、科学计数法字符串不是允许答案。标准JSON数值按精确Decimal读取。
- answer分数字符串分母必须是正整数；拒绝除零和过大载荷。`null`只在真实空集的相应聚合上正确。
- 不允许通过搜索原文多个数字再挑一个匹配gold；无容差奖励，无人工修复；诊断可另报数值误差。
- 模型截断属于真实失败并留在分母；尚未生成的技术缺失不是答错，列为未完成。

这是一项明确输出契约，不声称任何合法自然语言答案都被此协议接收。普通answer-only评价另外进行，防止格式学习冒充能力迁移。

## 5. 五种固定反馈：完整写到最终进入loss的优势

### 5.1 共同记号

每道相同提示采G=8条当前学生轨迹；**不是同根八个不同变体拼成一个组**。令对应分数为 `A_i,J_i,E_i,p_i`。所有优势detach，但detach不构成无偏性或保持保证。

总体标准差（`correction=0`）：

\[
 Z_q(x)_i=\frac{x_i-\bar x}{\sqrt{G^{-1}\sum_j(x_j-\bar x)^2}+10^{-8}}.
\]

精确常数组输出零。默认不删除常数组，不补采，不按“有效组”改分母。以下均为本次固定参数，无奖励权重搜索。

### 5.2 A：答案奖励

`r_i=A_i`，优势 `Z_q(A)_i`。

它允许答案正确但证据错误/缺失的回答拿到奖励，这是被比较的目标粗细差异，不偷偷给A臂另加证据门槛。

### 5.3 J：精确联合奖励

`r_i=J_i`，优势 `Z_q(J)_i`。

这一臂非常重要：若它已是最佳或与复杂反馈相当，不强行保留复杂方法。

### 5.4 PART：固定、真值锚定的部分反馈

\[
 h_i=\tfrac12E_i(1+p_i),\qquad
 r_i=J_i+\tfrac12(1-J_i)h_i.
\]

优势为 `Z_q(r)`。完整成功=1，失败最多0.5。它保证的是单条评分优先级，不保证真实优化只提高J。

在一致评分契约下，这与

\[
 r_i=\frac{J_i+0.5E_i+0.5E_ip_i}{2}
\]

完全相同。这一恒等式用于与DEC对账，不能用不一致的人工score绕过。

### 5.5 DEC：GDPO式组件处理强对照

组件固定为 `(J,E,E*p_read)`，权重固定为 `(1,0.5,0.5)`，与PART的未归一化标量组成对应。

先各提示、各组件做组标准化，再加权：

\[
 u_{qi}=Z_q(J)_i+0.5Z_q(E)_i+0.5Z_q(Ep)_i.
\]

随后在**整个更新批次16×8=128条序列上**再次标准化：

\[
 \widehat A^{DEC}_{qi}=\frac{u_{qi}-\bar u_{batch}}{\operatorname{std}_{batch}(u)+10^{-8}}.
\]

保留常数组及其零优势进入批次尺度计算。组件互相抵消时如实记录；不改成只对活跃组件平均。

这是本任务对GDPO方法的明确适配：保留逐组件与批次处理，采用本实验统一的总体std/epsilon与组件权重；**不是声称完整复制其原始模型、奖励及基准结果**。[R1]

### 5.6 GATE：目标优先、有界的组内语义精化

本次固定κ=0.25。

**分支1：J有成功也有失败。** 先 `a=Z_q(J)`。失败集合F={i:J_i=0}，仅在F内计算

\[
 u_i=h_i-\operatorname{mean}_F h,\quad
 t_i=\begin{cases}u_i/\max_F|u|,&\max_F|u|>0,\\0,&\text{否则},\end{cases}
\]

成功轨迹t=0，m=min_F(-a_i)>0，最终优势

\[
 \widetilde A_i=a_i+\kappa mt_i.
\]

其可验证性质：成功优势不变，失败仍为负，组内总和为零，失败内部保留部分真值区别。**最终不再整组/批次归一化，否则成功优势不变的性质被破坏。**

**分支2：J全1。** policy优势全0，不额外奖励格式或简单字段。

**分支3：J全0、E有差异。** 用`Z_q(E)`。

**分支4：J全0、E全1、p_read有差异。** 用`Z_q(p_read)`。

**分支5：其他情况。** policy优势全0，标记`no_semantic_contrast`。不混入教师轨迹、不造正确答案、不自动加计算支持。

本轮之前已有数学反例显示，有界的近失信用仍可损害J；因此这只是一种具有明确接口性质的候选，必须接受真实比较。[S2]

### 5.7 公平性与尺度说明

所有臂共享学生、训练题流、rollout机会、loss归约、学习率和KL。它们的优势尺度与有效组权重可能不同，这正是反馈方法的一部分；完整报告而非暗中把所有臂再做相同二次normalise。

本轮不隔离GATE所有子机制：GATE优于J不能单独归功于“失败内部精化”；GATE≈DEC也不能证明内部机制相同。PART对DEC提供相同组件下归一化方式的直接比较，但总体更新尺度也由该方式影响。

3×5运行矩阵已给在`manifests/RUN_MATRIX.json`。这里是一个公共起点下的15条路径，不是15种独立基础模型，也不是旧F2的5个准备状态。

### 6.5 loss与概率合同

生成一整个16×8批次时权重冻结；完成评分和最终优势后才更新一次。reward和reference不参与反向。

\[
 \rho_{qit}=\exp(\ell_\theta-\ell_{old}),\quad
 d_{qit}=\ell_{ref}-\ell_\theta,\quad k_{qit}=\operatorname{expm1}(d_{qit})-d_{qit},
\]

\[
 L=\frac1{128}\sum_{q,i}\frac1{T_{qi}}\sum_{t=1}^{T_{qi}}
 [-\min(\rho_{qit}\widehat A_{qi},\operatorname{clip}(\rho_{qit},0.8,1.2)\widehat A_{qi})+0.02k_{qit}].
\]

按序列等权、再按其completion token平均；包含实际EOS/停止token，不包含prompt、图像token或padding。不得只训练answer字段。对GATE/DEC直接接受已算好的最终优势，不在trainer默认函数里重算或再normalise。

old logprob来自真实raw采样；同前缀teacher-forcing核对。logprob/exp至少FP32；不得用clip logratio掩盖溢出。单更新的理想初始ratio为1，clipping可能基本不活跃，不夸大其作用。[R2]

KL为采样token项，不是完整序列KL精确积分，也不是能力保持保证。policy优势为零时，KL或已有Adam动量仍可能更新参数。

## 7. 必要工程与公共桥接：不是额外调参阶段

### 7.1 CPU先验收

运行本包tests和manifest核查；实现GPU层后补：128序列loss与一次向量化toy梯度一致；五种优势全部进入同一loss路径；GDPO的batch轴不是microbatch；token masking正确；reference切换不改变optimizer对象；上游非法JSON不得通过执行器eval执行任意代码。

**禁止运行模型生成的Python、SQL或shell。**本实验只解释固定AST和JSON数值，不调用任意`eval`。

### 7.2 格式检查和一次公共桥接

对FORMAT32题、K8共256回答检查字段可评分覆盖，**不以正确率决定桥接**。共同覆盖定义：JSON与两字段可评分、实体entry类型合法；实体选错或值算错属于能力，不是格式失败。

- 覆盖≥95%：不做格式SFT。
- 覆盖<95%：先排除截断、输入模板、parser和图像路由错误；这些属于技术修复，不是训练理由。
- 真正新协议遵从不足：允许一次BRIDGE的16步共同SFT，B8，128个gold completion恰一次，lr1e-5，与科学模型同LoRA范围；所有标签来自程序。
- 然后在独立FORMAT_CONFIRM32题×8上检查同一覆盖条件，并在原FORMAT32题×8上重测一次以提供桥接前后同题读数；仍不足则报协议阻塞，不继续加桥接或修改训练格式。

桥接用到证据和答案真值，**不是纯格式无语义监督**。记录其成本和能力变化；桥接后的common start另命名，所有臂同权使用。初始格式通过则不因奖励稀疏而桥接。

### 7.3 实际GPU连续/恢复验收

只用ENGINE池，重置到公共起点。固定4逻辑步，技术模式按[DEC,GATE,DEC,GATE]执行：一次连续4步，对照新进程2步保存退出＋再2步。合计8物理更新、1,024条真实生成。用于同时走过全批组件normalizer与门控路径，不属于科学臂。

在同硬件和已核验确定性后端下，参数、Adam矩、RNG、槽位与下一批生成逐位一致。old/teacher-forcing同token平均绝对logprob差≤0.005 nat、最大≤0.05 nat。该数值是技术容差，不按结果放宽。

若自然组非恒定而policy梯度始终为零，报`GRADIENT_MISMATCH`修复。若所有组确实恒定，保留自然记录，允许一次隔离非零surrogate压力测试：同路径用已注册交替±1的序列系数，4对2+2，另1,024生成。它只认证kernel与恢复，不认证自然GRPO有学习收益。

科学训练不继承这些工程adapter。无非有限数、数据/概率/恢复冲突才放行。通过后直接执行15条科学路径，不再等一轮研究讨论。

### 7.4 什么可以修、什么不能修

允许修：实现错误、渲染裁切、数据身份损坏、错误的dtype/概率/恢复、漏记录。

不允许按模型行为修改：AST、数值域、语言模板、H、奖励权重、种子、root、正确率门槛、主要终点。监测没有发现差异，只能报告支持情况；不能把它当成自动加难或改配方的理由。

若训练已开始才发现评分错误，停止新更新、保留污染路径、修复后所有受影响臂按同规则重启。不能只重跑表现不佳的臂。

## 8. 语义测量：必须保留到轨迹级

### 8.1 固定MONITOR测量

公共起点和15个96步终点都在MONITOR512题上K8、T1/top_p1，独立上下文。完全同协议，语义表按根→变体/图→题族加权。

输出：A/E/P/J和p_read分布、字段覆盖、共同可评分事件、近失数值误差、错误位置、相关/无关变换读数。自生成completion的NLL可直接由已保存的真实sampling logprob计算；不为本轮奖励比较额外做全MONITOR的gold teacher-forcing。若提供字段NLL，字段token边界须可审计；解析失败记缺失。没有支持的条件比例为undefined并报分母，不补0。

### 8.2 奖励与优势接口测量

对同一批监测rollout，将5种反馈全部只读重评分，不为每种reward重新生成。DEC按固定的监测16提示块组成整个batch，不能随意改变批次边界。

保存：

- 每条轨迹原始组件 `(A,J,E,p_read,E*p_read)`；
- 组件组均值、总体std、协方差；
- 各奖励的组非恒定指示与GATE分支；
- DEC组件标准化、组合前后尺度和最终优势；
- 各真值事件的正/负优势总量 `W+ / W-`；
- 以A或J为粗奖励分组时，细优势在粗同分集合内部的方差；
- 实际训练最终优势、token长度、有效token、gradient/KL和参数变化。

非恒定组比例只是区分机会，不是梯度幅度或学习收益；连续p_read不能套二元`1−p^8−(1−p)^8`。增量组率为零仍可有同分内部信用变化。优势按事件汇总也不是参数梯度。[S2]

### 8.3 五种诊断视图，只测不训

MONITOR的v0共有64个图表问题；对公共起点及15终点，分别K8：

1. `keys_hint`：只列程序要求的实体键，不给值。
2. `gold_values`：原图＋所需真值读数，原查询不变。
3. `text_values`：无图，完整Alpha/Beta真值表＋同查询。
4. `neutral_hint`：原图＋不含实体/数值答案的中性文字；使用固定tokenizer重复截取中性模板，使附加token数匹配本题gold_values提示；记录差≤1 token。
5. `blank_image`：相同画布白图＋原问题，不提供数值；图像通道仍存在。

所有视图独立上下文，提示输入必须单列`information_granted`。真值视图不是免费信息，不与原图成绩混报，不进入本轮RL loss。视图差是信息条件下的行为差，不认证内部“纯感知/纯计算”。

诊断包括：正确证据下任务执行失败是否持续；给值之后是否仍无正确支持；无关提示与真值提示的差；空白图与真实图的差；这些现象为下一轮决定是否需要支持训练提供依据。**不得看见某种瓶颈后只给某一个奖励臂加文本题。**

## 10. 统计与可识别的结论

### 10.1 不伪增样本量

- 每个奖励3条训练重复，一个公共基座起点；不是3种独立基础模型。
- TEST_ID有128根，每族32根，整根带2图×8变体×K×全部臂/种子。
- 先题内K平均，再根内16项平均，再四族等权，再3种子等权。

### 10.2 固定路径条件下的题根区间

5000次按四族分层的整根bootstrap，seed812901。每个副本同一根携带所有模型、协议、种子及变体。输出5个主对照95%点区间和99% Bonferroni区间（5项家族）。

这些区间反映固定15条路径下的题根测量不确定性，**不是任意训练种子或模型总体置信区间**。三个seed的各自点效应、平均值、范围完整列出。可附t区间，但3重复很弱，不由它宣称稳定安全或等价。

每个shift分开按4族bootstrap；ChartQA按图像ID簇重采样。禁止把40万个回答当独立样本。

### 10.3 有意义改善与失败口径

2pp作为本次事前报告的实际关注量级，不是科学PASS门槛，不保证该样本量具备2pp检测功效。主问题同时看：效应大小、seed方向、区间、无证据协议与shift结果、成本。

- J提高而普通A下降：报告权衡，不只报J。
- 证据协议改善、普通问答无变化：仅有该协议内收益，不能声称无辅助迁移。
- PART或J与GATE相当：简单反馈可能足够；不人为删除强基线。
- GATE≈DEC：不能唯一归因为归一化；只报告当前总体无清晰差异。
- 组优势不同但J不改善：有信号变化，无实证能力收益。
- 正确证据下答案仍全错：当前字段反馈不足；不能据此认定无法学习，也不能本轮私加SFT。
- 观测支持很少或区间宽：证据受限；结束已注册矩阵，不无限延长。
