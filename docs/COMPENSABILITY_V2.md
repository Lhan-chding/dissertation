# Compensability v2

The primary evidence chain is:

```text
natural error
  -> c_sel
  -> RL error selection
  -> natural mediator fork
  -> c_fork
  -> natural-versus-synthetic transport gap
  -> crossed-risk compensation
  -> error-mechanism OOD
```

`c_sel`, `c_fork`, and `c_syn` are distinct estimands and distinct record
types. Synthetic injection is an off-support stress test unless it passes the
registered transport audit.

Perception/reasoning separation is operational rather than anatomical:

```text
candidate interface family
  -> naturalness and replay fidelity
  -> visual sufficiency and no-image-bypass checks
  -> residual reasoning and stability
  -> admissible interface band
  -> partial-identification certificate
```

Freezing the visual tower freezes sensory acquisition parameters. It does not
freeze visual readout by the projector/language model and does not prevent
downstream reasoning from learning to compensate.
