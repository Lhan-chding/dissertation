# C 的 TOPK 探针结果与下一步判断

## 结论

本次固定1536回答、192组G8的TOPK探针已完整结束，0条技术失败，没有训练更新。**TOPK已出现可用于SELECT与SHUF区分的组内选择分歧：10组、8个不同world。** 冻结r5和事先仅用旧开发回答修订的r6得到同样10组；新数据设计确实提供了原C TOPK缺少的机会，并非靠r6重标制造正结果。

这个结论依赖已明确提出的F′资格修订：从合格失败条件移除“证据充分”，保留J=0、协议有效、完成、任务有定义，并要求组内至少2条P/S已知、候选失败的已知覆盖至少75%。若坚持原F，仍然没有活跃组，不能直接启动原冻结C。新设计的C可以推进到有界训练验证；当前数据没有证明SELECT训练优于J/EVID/SHUF，也不支持直接宣布完整C矩阵可放行。

## 信号组的AI文本复核

对这10组的全部68条候选失败做了AI审阅，输入只含回答原文与world，隐藏题目目标、程序标签和汇总。两位AI审阅者分别审34条，从原文抽取实际采用集合与排序列并核对evidence；之后才用私有映射对照目标，不使用最终答案反推选择。

60条程序已知S全部一致（27 PASS、33 FAIL），8条程序UNKNOWN由AI抽取得到6 PASS、2 FAIL；P判断无差异。全部10组仍同时包含P=PASS且S一对一错的回答，支持这些分歧确实存在。8条新增AI可知没有回填程序主表，也没有用于修改本轮r6。该审阅明确标为AI_REVIEW，仅覆盖信号组，既不是人类审核，也不是全1536回答上的独立准确率估计。

## 保留的负面结果与限制

- 新探针S已知809/1536，仍有727条UNKNOWN；候选失败仅622/1074可用。旧27句式修复并不等于新分布上的测量覆盖已解决。
- 原生J只有287/1536（18.68%），最终数值正确1147/1536（74.67%），充分性306/1536（19.92%）。未完成及格式不符回答仍计入固定分母，没有技术性补抽。
- 8类别两cell的J仅7.03%和9.90%；6类别为38.02%和19.79%。增加类别提供了部分选择机会，也大幅增加证据不足等问题，不是单纯更好的数据。
- 主口径SELECT正残差覆盖33条回答：全部证据不足，31条数值已正确。当前奖励相当一部分在“数值正确但缺证书”的失败中起作用，不能称为主要修复最终答案错误；也不应把E UNKNOWN概括成算术错误。
- 固定三个父模型的32个world没有新的训练种子重复；本探针属于开发测量，不访问B_CONFIRM，不使用旧确认集调参，不支持泛化或显著性结论。
