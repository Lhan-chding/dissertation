# C 新题组与局部选择信用：固定小规模验证

状态：方法与预算预注册；新模型调用必须等离线重放、CPU 梯度检查及代码审查通过。此计划是独立探索性试验，不改写旧 F′ 结果或原 C 门控。

## 1. 授权与问题

2026-10-24 用户授权把新题组、“扩大可靠选择比较范围＋选择段局部信用”一起实现，并在离线重放和 CPU 梯度检查通过后运行 J、EVID、SELECT、SHUF 小规模对照。

目标是检验：在可以可靠观察选择、并提供组内选择机会的任务上，选择辅助信用是否比相同数据和输出协议的结果奖励、证据奖励及条件打乱奖励改善最终答案。新题与方法同时变化，因此本轮四臂比较可以评价当前设置内的选择信用，却不能分别估计“换题”与“换信用位置”的因果贡献。不能拿旧 F′ 测试涨跌选题、调权重或追加步数。

## 2. 新题与数据隔离

六类题：BINDING（排序列与取值列交叉）、IMPACT（选择错误的下游影响与答案碰撞）、TIES（明确的印刷顺序破同值规则）、SIGNED（有符号差及算术分离）、INTERVAL（端点和正差条件）、K_DIRECTION（不同 k 与升降方向）。只使用已有可执行 TOPK/INTERVAL 查询语法，新增数据采用字段白名单；不把未实现的筛选字段塞进旧 TOPK。

每类训练 8 个原始题族，每题族 4 个变体，共 48 题族、192 题；每类评测 16 题族、每题族 4 变体，共 96 题族、384 题。IMPACT 的四个图共享 root_id，其余变体共享图或原始题族。所有派生变体留在同一 split。训练、评测采用新固定种子；公开设计例题以及旧 F′/探针题不进入本轮新题评测。精确内存比较检查事实表重合，不做文件哈希扫描，不按模型表现筛题或重抽种子。双独立 oracle 必须一致，碰撞与无效模型回答保留。

输入仍为真实图像和题目，不把隐藏事实表、正确集合或 oracle 答案提供给模型。新题采用同一条额外输出说明：原生 JSON 的 work 字符串依次写 SELECT 对象和 COMPUTE 对象；证据、work、answer 的外层协议保持 v2。SELECT 声明选择规则及集合；COMPUTE 声明实际计算对象、取值规则、聚合及操作数。所有四臂及父模型的新题端点评测用完全相同提示。旧 TEST_ID 和 ChartQA 保持原提示，以检查保持与格式迁移。

## 3. 冻结测量与信用

P：提交的非空图表事实是否都真实；不等于完整感知或充分证据。S：可解析且无冲突的选择规则与最终集合是否符合题意。SELECT 与 COMPUTE 对象集合冲突时 S=UNKNOWN；缺失或不支持的格式同样 UNKNOWN。算错、取值错误和聚合错误另外报告，不能仅因答案错就认定选错；也不能凭正确答案反推选择。INTERVAL 声明 start/end 用类别名，对应题目索引；等价的集合排列不算错。

共同候选集：原生 presentation 合格、生成完整、题目有定义，允许 J=0 和 J=1；不要求证据充分。共同已知集 K 要求 P、S 均已知，至少 2 条，且占候选集至少 75%。不满足则两个辅助通道全部零；UNKNOWN 不回填。所有臂的反事实计算使用同一资格规则，不把零信用回答删出训练分母。

以 0/1 编码 P 和 S，K 内 e_i=P_i−mean_K(P)，s_i=P_i S_i−mean_K(P S)，K 外为零。两个通道的系数均固定 λ=0.25；不除以稀有残差标准差，不对合并信用再次白化。J 仍是原生每个 G8 组标准化二值结果优势。

- J：原生全回答 J 目标。
- EVID：J ＋ 证据段局部 e 信用。
- SELECT：EVID ＋ 选择声明段局部 s 信用。
- SHUF：与 SELECT 相同，只把 S 在同组、同 J、同 P 的已知层内一次均匀置换；允许置换不变，不反复抽到发生变化。

SHUF 保存选择质量与结果/感知的边际关联。若层内 S 没有变化，SHUF 可能等同 SELECT；这是识别能力的限制，必须报告，不能强制打乱制造差异。

## 4. 精确训练目标与 token 边界

每条回答的损失为 L_J（全生成序列 token 均值、KL 一次）＋λ_P L_P（仅 evidence JSON 值内 token 均值）＋λ_S L_S（仅 SELECT 声明对象内 token 均值）。系数实际传入为 0.25e/0.25s，因此不能在 objective 再乘一次。每个辅助通道按自身有效 token 数归一化，避免较短选择声明被整条回答长度稀释；同时可能强化短段的逐 token 梯度，故报告有效长度和梯度诊断，不宣称参数更新被语义模块隔离。

辅助策略项采用与原生相同 detached train-old ratio、cap=2 TIS、clip=0.2。KL=0.02 仅在原生全序列通道计算一次；没有辅助 KL。每个更新仍为 16 组×8 回答，128 条序列等权。信用、采样概率、参考概率和 mask 均脱离梯度。学习率、KL 与温度不因观测信号稀疏而调整。

mask 来自原始实际生成 token 的精确解码前缀与原始响应字符跨度；不重新分词猜测边界。跨段 token、prefill、COMPUTE、answer 和生成后缀不获选择辅助信用。无法精确对齐则该辅助通道弃权并保存原因；原生 J 目标保留。梯度测试必须验证辅助差分梯度在段外为零（这不等于共享参数对其他行为没有影响）。

父模型：SRF2_J6_s71001、s71002、s71003；每父模型每臂只有一条新训练路径。3 父模型×4 臂×12 步=144 次优化器更新；每步 16×G8，共 18,432 训练回答。每条路径的 192 训练题恰好使用一次，顺序及 draw seeds 在各臂共享；回答仍各自 on-policy。

AdamW lr=1e-5、betas=(0.9,0.999)、eps=1e-8、weight_decay=0、constant scheduler、grad clip=1；固定初始父模型参考。温度1、top_p1、top_k0、max_new_tokens1024。无按结果早停、增加预算、重抽答案或新增臂；技术中断只按已提交 checkpoint/RNG/优化器和相同任务身份续接。

## 7. 评测与报告口径

主比较：SELECT−SHUF 的新题最终数值答案正确率。先平均同题 draws，再平均同原始题族四个变体，再每家族内等权题族、六家族等权、三个父模型等权。配对重采样 root_id（包括 IMPACT 的不同图），2000 次、95% 条件区间；所有臂/父模型共享重采样抽样。次比较 SELECT−J/EVID/PARENT，另报原生 J、证据真/充分、S 已知覆盖、已知内通过率与全体通过率。

必须列每家族、每父模型、所有负向差异及旧 TEST_ID/ChartQA 两套既有评分。无效回答仍在固定分母。机制报告区分：候选/已知/有效组、唯一题/题族、真实 S 混合、同 J/P 可置换混合、实际置换改变数、残差大小、局部 mask 长度/弃权与每通道损失。辅助奖励变大或格式合规提高不能替代最终答案和保持性能。

三个父模型块不是本轮独立训练种子重复；条件题族区间不包含训练随机性。旧 C 人工门控不因本次 AI 开发检查自动打开；本试验属于用户独立授权的小规模研究。只能据本轮完整固定分母报告探索性证据，不能宣布普遍推理能力或语义机制已证实。
