# 04 过程验证器和人工核验

## 1. 输出对象
每条回答输出原生 score/J、协议合法性、finish、真值与充分性原字段，以及 P/S/O/E 四维 PASS/FAIL/UNKNOWN。每个非UNKNOWN判断必须包含 source spans、observed claim、oracle target、rule_id、parser_version、ambiguous_candidates 和 reason。
四维是外显回答的任务行为，不代表已完整识别模型隐藏推理。

## 2. P：读数真实性
核对非空证据列表每条 (series,category,value) 与 world。全量列出事实真实性单独记，不用 `certificate` 总门控代替 truth。空列表不能凭全称逻辑得到PASS。任务只需局部证据时，正确与充分是两个字段；充分性继续使用native scorer。与额外无关错误证据有关的惩罚沿用原truth定义并明确记录，不自行更改J。

## 3. S：最终采用的对象集合
优先使用明确类别/序列声明与有数据依赖的最终表达式。只有数值操作数时，映射必须唯一；有重复数值、缺失月份、矛盾分支或不能判断采用了哪条过程则UNKNOWN。
“全文出现的所有对象”不是选择集合。“先算三个月，发现不对，再只用两个月”的最终集合不能判成三个。
候选答案匹配只产生候选假说，不能直接成为S标签。S=FAIL需要可验证的最终采用集合与目标不同；仅没有写出集合是UNKNOWN。

## 4. O与E
O核对运算类型、对象及顺序；具有代数等价的不同写法应视为等价。E逐等式复算并检查最终work结论与answer一致；对于中途已明确撤回的错误式，单独记录“曾有错误后修正”，不把最终执行自动判错。
原生代码字符串、工具调用文本不执行；算术使用白名单解析器。未支持语法返回UNKNOWN。计算自洽可以PASS而P/S失败，不能将E的PASS解读为任务完成。
本轮C只使用P/S。O/E用于机制描述和风险分析，不因为多解析了它们就自动加奖励。

## 5. 必须有的负例回归集
至少覆盖：相同答案不同过程；同数值对应多个类别；一个减法操作数对重复出现于多个月份；算式右端错误；先错误后撤回；分母3出现在无关句子；没有最终选择；输出被截断；work空；JSON字符串含花括号/转义引号；重复键；答案数字正确但协议invalid；NULL/undefined；小数/负号/分数；单位误用。
关键受控例：三个月份的A/B完全相同，work只有“10-1=999，Count=3”。不能由一次错误等式推断已经正确验证了三个不同月份。
本包 parsing.py 只是安全抽取/算术参考，不是通用自然语言过程解析器；生产S仍需Codex开发和验证。

## 6. 人工核验及资格门禁
parser开发可用现有原文和B开发数据；冻结parser后抽独立盲核200条：120条按题族×block×J/合法性×常见/稀有层的代表样本，80条从将实际获得正额外信用的候选中按world分层抽。样本不得重复；记录抽样概率，代表部分和富集部分分别报告，不能把富集混淆矩阵当自然总体比例。
标注者看图、query、原回答和gold程序，不看arm/候选奖励/自动标签。至少40条由第二名核验者复核并裁决；若没有第二人，明确单审，不编造一致率。C最低要求有真实人工审核记录；脚本或LLM代标不得填 HUMAN。

对于P和S的“会被用作正信用”的判定，各需至少80个独立world的经人确认可判定实例；同一world多条获正信用回答归为一个审核单位，只要其中一项误判，该world就计为错误，且准确数/n的双侧95% Wilson下界≥.95；以上Wilson是操作性保守门槛，不是对整个模型群体的严格覆盖保证。200条无法满足时，允许事前预留的最多100条补充，按相同富集方案抽，不按错误挑样。该门槛是本包提出的审慎启用标准，不是已有研究给出的通用常数。
存在主规则误判时，不得通过删错样本达到门槛。需要修parser，则版本改变，旧盲核转为开发，不能复用为独立验证；本版本C保持BLOCK，另发布测量修订。
人工来源未知或标签数不足 → `MEASUREMENT_NOT_READY`，不等于“语义信息无用”。A可照常运行。

## 7. 覆盖报告
按family×block×J组型×训练时间窗分别报告P/S/O/E覆盖、UNKNOWN、规则冲突、成功/失败、额外信用可用率。分母包括全部回答；另报合法且完成的条件分母。不能把UNKNOWN丢掉后声称所有失败同质。
训练阶段监测已知与未知比例、格式/长度相关性；parser保持冻结。C运行期间发现确定标签实现bug，应技术阻断四臂该repeat并保留日志，不据表现好坏只停止某一臂。
