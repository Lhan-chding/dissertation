# 11 信用项的数学核对与失败模式

## 1. 分数增加不一定增加信息
设J二元，同一组所有失败回答的局部标记都是常数c；R=J+λc(1-J)=λc+(1-λc)J。只要1-λc>0，且忽略数值epsilon，组中心化/标准差后的优势与J相同。恒定组仍零，不能靠“加了一项”宣称改变训练。

## 2. 小λ不一定意味着小影响
全零J组里，R=λS，λ>0时组标准化满足 A(λS)=A(S)。G8一正七零给+√7与−1/√7，不随λ缩小。epsilon足够大时该等价不精确，所以必须同时核对真实代码。

## 3. C为什么固定β=.25
额外分数s在[0,1]，失败层中心化d在[-1,1]，所以|βd|≤.25，且全组sum(d)=0。EVID的范围更小[0,.5]。
在标准二元G8、总体标准差归一化、忽略epsilon时，混合组里失败回答的绝对负优势最小为1/√7≈.378。β=.25小于这一值，因此这套理想计算下，额外项不会把混合组中失败回答直接变成正优势；它会改变失败之间的相对权重。全零组则允许已验证的相对差异产生有限的正负信用。
这个性质仅限于上述标准化下的advantage；epsilon/whitening不同需用真实代码穷举k=1..7验证。它不保证参数更新无冲突，也不保证最终答案率保持，不能叫“安全RL保证”。

## 4. 对照识别
SELECT−EVID的额外差为β/2·center_F(P*S)。共同P项、资格掩码、基本J、题目日程、G、学习率、优化器完全一致。
SELECT_SHUF只在固定P层打乱S，保留每组残差多重集。因此SELECT−SHUF考察新增选择标签与回答的对应关系，而不是单纯是否增加了更新方差。
即便SELECT优于这两个对照，也只支持该特定选择信号的用处，不自动证明依赖乘积P*S优于所有其他结构；进一步证明结构最优需另一轮专门消融。

## 5. 整体未知门控的代价
F中任一P/S未知，额外项整层归零。这减少把“更易被解析的回答”系统性当作好回答的风险，但也牺牲覆盖、可能使复杂失败无法学习。它不是不偏估计，必须报告abstention与长度/难度/成功率的关系。
不能为增加激活率而在训练中临时改变解析器，不能把“模型变得更像可解析模板”当最终成功。独立原生答案评价和自然work交叉检查负责暴露这种问题。

## 6. 负结果的细分
标签不能可靠观察：测量问题；标签可靠但优势不变：使用方式缺少信息增量；优势改变但新题不改善：当前信用设计无清晰收益；新题改善但旧任务退化：收益/干扰权衡未满足；只在已知v7改善：病例级修复。
这些都比一句“语义信息无用”更有研究信息。最终写作只能按实际证据等级陈述。
