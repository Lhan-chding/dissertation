# 03 数据构造、样本数与隔离

## 1. 四种用途绝不混用
旧 TRAIN_RL：A 训练与冻结初值；C 保持曝光也只能从这里抽。
旧 TEST_ID/COMPOSITION/ARITY/ChartQA：已参与设计的回归面板，仍可比较，但不声称设计独立。
新 DEV：测量开发、门禁与过程监测；可看结果，但不能调主方法到最好。
新 CONFIRM：预先生成清单、封存回答及分数，最终冻结后一次性打开；不存在“先跑父模型看难不难，再叫确认集”。
world_id 与底层事实表 canonical hash 两层防重；同世界的所有题目、图像渲染、措辞变体必须在同 split。不能把同图的一个问题放训练、另一个放测试。

## 2. B0 冻结父模型普查
每父模型：32 变体×4 不同训练根×8 draw=1,024；v7 另加8不同根×32 draw=256；总1,280。三模型3,840条。
若 v7 总共只有8训练根，额外8根可包含基础4根，但 draw seed 全新，记录独立根数8而不是12。初值使用全部新回答的逐回答 J 均值；同时存逐根均值、n、根数与区间，不把32draw当32个独立世界。
不复用四臂步2–4；即使第1步文本重复，也只计一次。生成阶段不更新参数。

## 3. B2 小型受控面板（保持原96+64世界规模）
96 个诊断 world：选择关系32、运算组合32、表达/视觉迁移32；每world两道配对题。
其中每类24开发+8确认，即72开发对+24确认对。另64代表性world单题，56开发+8确认。
因此 DEV=128world/200prompt；CONFIRM=32world/56prompt。
三父模型×8draw：开发4,800条；封存确认1,344条（直到最终阶段才生成/开放）。合计6,144不是全都可用于设计。
选择关系32world：INTERVAL左右端点16；TOPK选择序列/聚合对象16。其他目的类也应均衡覆盖这两种关系，THRESHOLD/CROSS 可以占辅助位置但不替换这两项。

## 4. 受控对规则
每对清单必须写 changed_fields、invariant_fields、expected_relation、两个独立程序 gold、definition_status、target_sets、relation_id。
选择对：图像与数字不变，只改包含/排除端点，或按 Alpha/Beta 排序。
运算对：选定对象不变，只改 sum/mean、聚合哪个序列或生成器已支持的非等价组合。
表达/视觉对：语义不变，改措辞或渲染。不要同时改文字、类别数、算子来声称单因素诊断。
代表性面板不筛数值碰撞；诊断面板只排除“目标程序与本次要区分的错误程序”值相等，不要求126个候选彼此全部不同——有些程序代数恒等，无法也不该强制区分。
生成器直接计算预期关系；仅“两个答案不同”不算关系理解正确。相同答案也可能是合法语义结果。
使用 Fraction 精确运算；原验证器有容差时同时保留精确值与原评分口径。空集合、并列排序、零分母按原合同处理，不能凭方便丢弃。C 的主训练选 definition_status=DEFINED 的任务；B代表性保留UNDEFINED并单报。

## 5. C 独立训练/开发/确认世界（本包新增）
核心六个cell：
I-L：INTERVAL左端点包含/排除；I-R：右端点；I-B：两端条件组合。
T-S：TOPK按哪个序列选；T-Q：固定选择后聚合哪个数量；T-C：选择序列与聚合数量的组合。
所有cell含两道受控题，字段定义必须对应 native query/AST；不支持的算子不得临时猜实现，先做程序gold单元测试。

| split | 世界数 | 每cell世界 | prompt数 | 用途 |
|---|---:|---:|---:|---|
| C_TRAIN |384|64|768|唯一新增训练池 |
| C_DEV |96|16|192|门禁/固定中间检查，非最终确认 |
| C_CONFIRM_ID |120|20|240|同结构新世界 |
| C_CONFIRM_TRANSFER |120|20|240|训练未用的表述/外观/规模/组合 |

C_TRAIN 每cell半数4类别、半数6类别；TOPK分别k=2/k=3；INTERVAL剩余集合至少2项。数字采样范围与合法图表风格继承旧生成器的冻结支持范围，不能从测试结果调整。
TRANSFER每cell分四子层，每层5world：新措辞、另一冻结渲染样式、6类别/较长区间的未训练配置、生成器已验证但 C_TRAIN 未使用的组合模板。若4/6类别训练均有，规模迁移必须明确是“更长有效区间/不同k和类别组合”，不能把同样配置标未见。最终 manifest 自动比较训练/测试属性并断言对应held-out字段真的未出现；组合模板不具备合法且可留出支持时，标 `TRANSFER_COMPOSITION_UNAVAILABLE` 并在F1前替换为预先声明的措辞+渲染联合迁移，不宣称新组合泛化。
所有新世界使用与 B2、旧训练/测试互异的事实表；未来的测试生成器种子独立。

## 6. C 的固定曝光（不会使用 S 调整采样）
每更新16题×G8。12新题：六cell各2个不同world，每world抽一道分支。每repeat、每cell对64world做独立随机排列，32步正好各见一次；分支由预登记稳定随机键确定，repeat2使用同world的另一分支。四条臂共享同repeat日程，三个block也共享题目日程但rollout seed按block区分。
其余4题：旧TRAIN_RL的CROSS/INTERVAL/THRESHOLD/TOPK各1，变体按8步循环均匀覆盖，题根随机。不得使用旧TEST_ID作保持训练。
这固定了训练曝光和group size，避免把语义学习效果与难题多采混为一谈。生成的回答必须是各臂当前模型自己的on-policy回答，不在更新后重用另一个臂的文本。

## 7. C训练池先导探针
训练开始前，从每cell固定抽4world（共24world），两道题均采8draw×3父模型，共1,152条。这些是训练池探针，可用于门禁；与B2/C_DEV共同检查信号是否能转移到实际训练分布。不得根据probe结果替换world或选易成功模板。

## 8. 隔离执行
目录 DEV / CONFIRM 分开；主训练适配器拒绝加载 split=CONFIRM 的 qid。审核、阈值、parser版本选择日志只允许 DEV/历史/训练探针。
确认集只评固定终点。若C被阻断，A/B的最终报告可开放B确认；该确认集之后自动转为“已见回归”，不能再用于新C版本的独立确认。
