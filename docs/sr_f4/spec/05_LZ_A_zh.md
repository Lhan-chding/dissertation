A0=J_UNIFORM_NEW_REPEAT；A1=LZ。每block一新repeat，64次成功更新×128回答。A0在32变体均匀有放回，变体内部根均匀，16组G8。若这与旧采样器不同，旧RL对比只作历史参考，不称“只换seed”。
A1：每变体EMA初始化为B0冻结父模型回答的J均值。step开始冻结状态和层级；step结束把该变体所有回答先合并再更新一次：p_new=.75*p_old+.25*mean(J)。没有观察不更新，不因G32而更新四次。
mastered进入≥.95，保持≥.90；starved进入<.125，保持<.25；其余learning。退出一个层级后可按当前p直接进入另一层；边界测试见参考代码。
