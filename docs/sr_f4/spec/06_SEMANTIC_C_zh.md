# 06 Track B3 → C：直接检验选择语义的学习价值

## 1. 为什么不只把J改成J+λS
对非恒定组，正仿射变换在理想组标准化下给同一个优势。对全零组，λS若出现差异，λ可能被标准差完全抵消：G8一正七零，即使λ=.001，正优势仍约√7。
因此 B3 同时报告原scalar候选的这一性质，正式C改用“保留A_J，额外信用单独有界”的简单实现。它是本包新增设计，不是Claude已有实证；也不声称解决所有RL信用问题。

## 2. B3必做重放
历史RL全部3,072组（按block、step窗口分开）、B0父模型、B2 DEV及C训练池先导。调用生产native advantage代码重放：
(1) J；(2) J+λ P(1-J)；(3) J+λ P*S(1-J)，λ∈{.01,.1,.25}，仅离线；(4) 以下C的四臂。
同时保存certificate与certificate_truth分解，避免72组差异误归因；scalar候选有UNKNOWN时整失败层abstain，不填假标签。
输出每组原奖励、候选奖励、A_J、A*、零优势变非零、符号翻转、失败排序变化、L1/L∞变化、score与长度/格式关系、有效world数。不得只输出漂亮案例。每种shuffle用10个固定随机种子做离线分布，不挑最好/最差；训练只用预登记独立流。

## 3. 正式C的唯一公式
P_i∈{0,1}：原生读数真实性（nonempty evidence）；S_i∈{0,1}：已验证的最终选择关系。
对每题的G8组定义F：J=0、protocol_valid、finish、certificate_sufficient=True、task_defined=True的回答。F至少2条，且F内每条P/S都已知，否则该组全部额外项为0；J照常。
四臂的共同资格计算必须完全相同，不能EVID用更多回答而SELECT少用。

J：s_i不用，d_i=0。
EVID：s_i=.5P_i。
SELECT：s_i=.5P_i+.5P_iS_i。
SELECT_SHUF：在F内固定P的层中随机置换S，计算同样s。
F内：d_i=s_i-mean_F(s)；F外d_i=0。
最终policy advantage：A_i*=A_i^J+βd_i，β=.25，**不再标准化或白化**。成功回答、非法/截断/未定义回答的额外项为0，原生A_J不被删除。

EVID与SELECT的证据项系数完全相同；SELECT增加的就是P*S项。SHUF只破坏新增S与回答的对应关系，保留每组score/residual的多重集、均值、范数、P与J关系。允许随机置换偶然不改变标签，不强制选最大破坏排列。
额外项绝对值≤.25，组内总和0；不是梯度范数或真实更新安全保证。TIS、ratio clip、KL和原loss reduction照旧，记录最终进入loss的值。

## 4. 训练矩阵与曝光
3 parents × 2 repeats × 4 arms =24条路径；32次更新、G8固定、每次16题128回答。配置和生成条件从旧RL继承，所有臂一致。
四臂从各自父模型重新开始，不借用A终点，不带教师轨迹，不使用现成正确输出做CE。P/S来自模型当下生成的外显过程与程序验证；oracle只用于评分，不附加给推理prompt。
固定日程12新题+4旧TRAIN_RL保持题；每臂可见图像问题完全相同，但on-policy答案应各自生成。每条路径4,096训练回答，24条98,304。

## 5. C_GATE（在任何C训练之前计算）
生产J二元、原生优势一致性、标签依据、数据隔离、采样器测试均通过；人工审核满足04规范；硬负例误正数0。
在实际C训练池探针上，SELECT相对EVID产生非零优势增量的组：INTERVAL和TOPK各至少24组且各覆盖≥8个独立world；每block至少8组。用绝对差>1e-8识别，不按模型终点准确率选阈值。
这是一套事前指定的最小可观察性/可靠性标准，不是科学定律，也不是“低于阈值则语义无用”。不能把B2人工挑出的高差异样本替代实际训练池探针。
全满足 → RUN_C，24路径全部运行。否则BLOCK_C，交付每项缺口与完整数据；不做临时新奖励、不降阈值、不选择性跑一个block求正结果。

## 6. 短程实验的解释边界
即便SELECT最好，本轮最多支持“在这些任务、三个父模型、两重复与固定β下，新增可验证选择信息有增量”。不声称最优语义表示、不声称完整四维奖励已验证、不声称强化学习全能力提高。
SELECT>J但不>EVID：可能已有证据信息足够；SELECT>J但不>SHUF：不能排除额外更新扰动/信号规模的解释。
SELECT提高过程标签、不提高独立答案：不算主要假设成功。
SELECT只在已有v7改善、不在新确认改善：只报已知病例修复。
BLOCK_C是测量/机会不足，不把本课题收缩为LZ，也不在本包内编造尚未定型的语义动作算法。
