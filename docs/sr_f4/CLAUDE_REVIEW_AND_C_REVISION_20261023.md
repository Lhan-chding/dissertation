## 接受与纠正

接受的重点：v1 对自由文本的选择过程覆盖不足，必须修测量；需要实查局部过程与最终答案的关系；主报告应显式展示旧 TEST_ID INTERVAL v7 的逐块结果。

不能直接采纳的部分：

| 参考材料主张/实现 | 核对结果 |
|---|---|
| INTERVAL 所有 `a-b` 数对取并集即可判 S | 会把暂算/撤回项当最终采用，同一数对对应多个类别时全部纳入，违反现有硬负例。 |
| 聚合子句全部整数映射到类别，优先最大集合/符合 k 的集合 | 包含结果、计数、分母；例如 `2+3=5` 不能把值为 5 的第三类也选入。不得用目标 k 挑解释。 |
| 任意 empty/not satisfy 即空集 | 会误读 not empty、单个类别不满足、早期被撤回的说法。 |
| 原型 98%–99% 可判率证明仪器可靠 | 这是未经独立复核的覆盖率，不能当作准确率，也不能直接进入奖励。 |
| O/E 没实现，E 从不给 PASS | v1 有显式 O/E/PASS 路径，缺的是常见自由文本覆盖；这仍是实质性测量不足，但不能称代码不存在。 |
| P 等于 certificate_truth | P 还要求非空证据，处理非法/未完成输出，两者不是完全相同。 |
| 23/3072 混合 S 组就是正式 C 的可用信号 | 该统计忽略 UNKNOWN、格式、完成、充分性、定义性及 P。正式 C 是共同失败层内的有界残差，须用原生 advantage 重放。 |
| S 与 J 是同一事件、题组根本不可能产生价值 | 超出证据。附件也报告 393 条 J=0、数值正确、S=PASS。现有探针机会不足不等于整个训练分布没有机会。 |
| 没有全零组就没有新增选择信号 | 混合组内的多个失败回答也可能产生新增信用；全零组不是必要条件。 |
| 150 条、Wilson .90、模型第二审等同原门控 | 原要求是独立 world、.95、人类来源；这是协议变化，不能静默替换原结果。 |
| 96 个变体格的差值 SD 证明训练随机性小于评测噪声 | 共享训练模型且日程可能不同，不能作为 96 个独立训练重复或分解两种方差。 |
| 旧 v7 阈值意味着正式 E1 成功、一次均匀重复证明学不会 | 最终规范将旧阈值降为工程观察；可报告大幅描述性提升，不能作这些外推。 |

附件含 `eval`、动态 `exec`、缺失外部依赖和硬编码路径。未直接执行附件，也未复制这些执行路径。

用户已明确让 AI 完成审核；修订流程按 `AI_REVIEW` 执行，不再等待用户手工填写这批开发审核。120 条来自现有 C_TRAIN_PROBE，按题族×block×J 各抽 10 条，固定随机种子 20261023；三个 reviewer 各主审 40 条，并各交叉复核另组 14 条，共 42 条双审。审核输入隐藏自动标签、J、arm 和原始 ID，只提供匿名 ID、题目、world 表、原文和完成信息。

## 最终开发重放与 AI 审核结果

最终实现对 1,152 条既有 C 探针重标，使用原生 advantage 和冻结资格重放，无新模型回答：

| 题族 | v1 S已知 | v2-dev S已知 | v2 PASS / FAIL / UNKNOWN |
|---|---:|---:|---|
| INTERVAL | 11/576（1.91%） | 75/576（13.02%） | 67 / 8 / 501 |
| TOPK | 4/576（0.69%） | 333/576（57.81%） | 332 / 1 / 243 |
| 合计 | 15/1152（1.30%） | 408/1152（35.42%） | 399 / 9 / 744 |

这是有限语法版本的真实覆盖率，远未达到通用过程解析。INTERVAL 大量回答使用缩写、复合叙述、多个等式阶段、不同括号/分数格式及未支持的最终集合说明；这些仍保留 UNKNOWN。不能拿附件高覆盖原型替换这些保守标签来宣称达标。新版本对 protocol-invalid 的 S 也保守弃判，P/O/E 和原生资格字段沿用 v1。

重放仍为 SELECT−EVID 改变 **0/144 组**：134 组资格层不足两条，另 10 组仍含 UNKNOWN。旧版状态未变；这不是新增 C 训练效果评估。开发期间三个中间重放目录保留，不选择覆盖最好的一次作为最终结果，最终目录为 `V2_DEV_FINAL`。

AI 主审 120/120 已完成，42 条双审。双审唯一有分歧的样本 AI-DEV-014，原文 JSON 字符串含未转义换行，复查后 P/S 均 UNKNOWN；两份原判断及 AI 裁决记录均保留。最终 v2 对审核样本给出 38 条已知 S（32 PASS、6 FAIL），与 AI 判断一致；另 74 条程序 UNKNOWN 而 AI 可判，8 条双方 UNKNOWN。这只是开发材料上一致性，样本小、分层抽样且审核者同属 AI 系统，不能宣称 100% 真实精度或总体 Wilson 通过。

P 有一条程序 UNKNOWN、AI FAIL 的定义边界：回答声称图中不存在的 December=0。AI 将其视为虚假事实，原生解析将不可映射类别视为 UNKNOWN；如实保留，不修改原生 P 来抹平差异。

110 项相关 CPU 测试通过，Ruff 和 scoped diff 检查通过；最后一次 pytest 只有缓存目录写权限警告，不影响测试执行。没有额外 GPU 烟测、哈希扫描或新实验。
