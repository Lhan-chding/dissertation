# C 重新设计稿的核查、离线实现与推进依据

日期：2026-10-23。参考文件：用户提供的《C 的重新设计：测得出、有机会、学了有用（给 Codex 的设计稿）》。

本文区分已经核查的事实、已经实现的开发代码，以及仍需明确的新实验方案。附件是设计参考，不是新增数据、模型调用和 GPU 预算的自动执行授权。用户已经授权由 AI 承担审核；后续不要求用户手填旧开发表，但 AI 审核必须如实记录为 AI，不能追改历史记录为 HUMAN。

## 1. 结论

设计稿提出的方向有价值：先让选择行为可测，再确认同一失败组内存在可分配的选择信用，最后检验训练收益。特别是用 **SELECT 与 SELECT_SHUF 是否可区分** 来定义信号，优于旧的 SELECT−EVID 非零条件。

但设计稿不能原样执行。其中混淆了总残差与选择增量的上界，把小组内随机打乱的自然不变概率当作失败，并把未经验证的信用比例阈值写成了训练功效依据。测量部分也存在利用题目修正回答、混淆答案错误与计算错误、把相关开发夹具当自然精度验证等问题。

本轮先落实两个可以直接检查的改动：独立的资格与信号离线重放，以及保留旧判定器的程序解析开发版本。旧生产训练、原 credit.py、旧门控和 A/B 结果保持原状态。C 的后续目标仍是建立并检验有效的语义干预，不把 LZ 完成视为 C 完成。

## 3. 资格放宽的作用：有动机，但不是旧实现错误

原资格要求：J=0、格式有效、生成完成、题目有定义、证据充分；其中任何 P/S 未知会让整个资格层弃用。

设计稿的 F′ 去除“证据充分”，再只让 P/S 已知的回答参加，并要求已知比例至少 75%、已知回答至少两条。这会允许“数值回答正确但证据不完整”的失败获得局部信用，改变的是新实验研究对象。

新增 `src/sr_f4/credit_design_replay.py` 同时输出四种口径，避免把两个改动混在一起：

1. `F_FROZEN`：原 F，调用未修改的参考 credit 实现。
2. `F_KNOWN_75`：仍要求证据充分，只改已知子集与覆盖守卫。
3. `F_PRIME_STRICT`：去除充分性，仍遇未知就整层弃用。
4. `F_PRIME_KNOWN_75`：设计稿提出的两个改动同时应用。

所有重放都保留二元 J、原生总体标准差加 epsilon 的 A_J、beta=0.25、组内居中、不重新标准化。它们是同一批既有回答上的反事实计算，没有改变已经跑过的训练。

### v2 标签下的实测结果

`N_act` 表示资格与覆盖条件满足，**不保证残差非零**。`N_sig` 表示在该已知层内，至少两条 P=PASS，且 S 同时存在 PASS 和 FAIL。

| 来源 | 原 F：N_act / N_sig | 仅已知子集：N_act / N_sig | 仅去充分性：N_act / N_sig | F′+已知子集：N_act / N_sig |
|---|---:|---:|---:|---:|
| C 探针 | 0 / 0 | 1 / 0 | 5 / 0 | 9 / 0 |
| B0 | 0 / 0 | 1 / 0 | 0 / 0 | 6 / 0 |
| B2_DEV | 0 / 0 | 0 / 0 | 10 / 1 | 17 / 1 |

这不是“放宽规则没有用”：C 的候选失败从 52 条增至 243 条；测量已知的合格回答从 10 条增至 85 条。但进入资格层并不等于有组内选择差异。B2_DEV 的一个真实信号说明，原充分性过滤确实会挡住有意义的对照。

更具体地，在 C 的 F′ 内，v2 已知且 P=PASS 的 INTERVAL回答为8条 S=FAIL、0条 S=PASS；TOPK为76条 S=PASS、1条 S=FAIL。即便数据总体上两种 S 都存在，也必须在同一个满足覆盖守卫的组里形成差异，才是当前公式能用的信号。其余大量未知仍妨碍判断真实机会，不应据此直接宣布任务没有选择分歧。

### 一个可直接检查的真实组

组：`B2_DEV-b1/s000/g00028`，world：`SRF4_B_DEV_T_S_014`，TOPK、T-S、b1。

任务按 Alpha 选前两项，再求所选 Beta 之和。Alpha 为 January=47、February=64、March=38、April=45；正确集合为 January/February，正确和为 156。

- d00 选择 February/April，回答 159。所报事实为真，P=PASS；选择错误，S=FAIL；证据不完整，J=0。
- d05 选择 February/January，回答 156。所报事实为真，P=PASS；选择正确，S=PASS；缺少 Alpha/March 的证据，J=0。
- 其余六条 J=1，不进入失败信用层。

原 F 排除这两条。F′ 纳入后，SELECT 给它们分别 −0.0625、+0.0625 的残差；EVID 两条同分、残差为零；SHUF 有一半概率交换它们。这里确实存在局部选择内容，而不只是 P 的变化。

这一例不能替代正式训练证据。在 v2 下，B2_DEV TOPK 是 1/258 个信号组；其全题族数据合计是 1/600。与该来源原生 A_J 的总 L1 相比，SELECT−SHUF 精确期望 L1 比例约 0.00866%；这是既有样本描述，不能直接推断训练有效或无效。

## 4. 必须纠正的数学说明

### 4.1 新信号定义可采纳

若 P=PASS 的所有失败回答 S 都为 PASS，即使组里还有 P=FAIL，SELECT−EVID 也可能非零；但同 P 层内打乱 S 不会改变任何结果。因此，旧指标可能把重复使用 P 的增量称为选择信号。

新 N_sig 对固定回答组是准确的：它表示**存在一种合法置换能改变 SELECT 向量**。旧 SELECT−EVID 指标仍并列保留用于解释历史结果，不重写旧门控。

### 4.2 90% 打乱改变率不适合作为统一门槛

P=PASS 层有 n 条回答，其中 k 条 S=PASS，均匀随机置换改变残差向量的概率为：

`Pr(change) = 1 − 1 / C(n,k)`。

| n,k | 改变概率 |
|---|---:|
| 2,1 | 50% |
| 3,1 | 66.7% |
| 4,2 | 83.3% |
| 5,2 | 90% |

两条一正一负已经有真实对照，不能因为没有 90% 而判为无效。强制重抽直到改变则修改了对照分布。本次输出精确概率和原十个离线种子的实际变化数，不筛种子。

beta=0.25 时，还能直接计算：

`E[||residual_SELECT − residual_SHUF||₁] = 0.25 × k(n−k)/n`。

### 4.3 总 SELECT 残差不以 0.125 为统一上界

m 个合格已知失败里：

- SELECT 总残差绝对值上界：`0.25 × (m−1)/m`；G8 最多 0.21875。
- SELECT−EVID 的 S 增量绝对值上界：`0.125 × (m−1)/m`；G8 最多 0.109375。
- 固定资格层、只改变一个已知 S 标签，会通过居中同时改变其他行的信用；UNKNOWN 变已知还可能打开整组守卫。

反例：八条失败依次为 `(P,S)=(1,1),(1,0),(0,0)×6`，SELECT 残差为 `[0.203125,0.078125,−0.046875×6]`。第二条 S=FAIL 仍从 P 通道取得正的总残差。因此“正残差只给 S=PASS”与沿用公式不相容。若要限制，只能另行修改干预定义，不能把它称为原公式。

### 4.4 R 不是训练功效证明

本次分别输出 EVID、SELECT 总量、SELECT−EVID、SELECT−SHUF 固定种子均值及精确期望的 L1/原生 A_J L1。存在“总 R 超过 10%，但 SELECT 与 SHUF 完全一致”的组；只看总 R 会误判主对照强度。

全 J=0 时原生 A_J 全零，分母为零，但新残差可能非零。工具将 R 写为 null，并另外保留零基线组的新增信号，既不写成无限大，也不把它抹掉。

“R<3% 不可能超过噪声”“1–3% 自动加到 64 步”没有得到功效计算支持。A 每块每臂只有一个新训练重复；不能把跨块差异或回答 bootstrap 当成训练重复标准差。32/64 步、阈值及预算需要独立设计，不从这个描述性比值自动推出。

## 5. UNKNOWN、缺失偏差与激励

原稿称“整层弃用无偏”“已知子集的偏差只能平移零点”，都过强。未知很可能与更正、复杂计算、错误类型相关；整组弃用会选择组，已知子集也会改变组内中心、正负信用及跨组贡献。

四臂可以共用资格函数与题目日程；各自 on-policy 的实际回答不同，所以 F_known 集合、覆盖率和失败成分不会必然一致。应该按臂报告这些差异，不应强行对齐。

对于固定 G8 混合 J 组，失败基础优势的最小绝对值约 0.378，超过最大正残差，因而这里不会把失败最终优势翻成正。但这不能证明长期策略一定不会偏好少报证据；全失败组、token 梯度、输出分布变化等仍有影响。证据充分性应作为保留指标持续报告。

## 6. 测量 v3 应如何修改

采用以下边界：

1. **先抽取回答实际采用的系列与集合，再对照任务。** 不用 query 的正确 aggregate_series 帮含糊操作数选解释，否则可能把错误系列计算修成正确选择。
2. 保留 v2 对显式错误 ranking series 的判断。新稿只用集合相等，可能把“用了错系列但集合碰巧相同”的 FAIL 改为 PASS，这是口径变化；未来可拆出 S_set 和规则一致性，但不能悄悄覆盖。
3. E 只判断可观察计算的执行一致性。选错但算对可以 E=PASS；答案错且无运算过程可以 E=UNKNOWN；不是见答案错就 E=FAIL。
4. 更正要有明确作用范围，不能因为前面出现过一次“Wait”就允许后续所有矛盾。任意交换句子次序不是保义扰动。
5. 若所有文本支持的候选集合都错误，可以记录“标签可判 FAIL、采用集合仍不唯一”；不能声称恢复了唯一集合。候选枚举不能用 gold、目标 k 或正确答案删选。
6. 名称缩写、逐项差值、sum→mean 中间计算链是已在真实开发回答里发现的解析缺口，优先于直接把 UNKNOWN 交给一个模型下结论。

### 双模型抽取目前还不是“三源认证”

原稿“G 已知不调用模型、G 未知才调用 M1/M2”和“每个 known 必须至少两源一致”互相冲突：前一种 G 已知时只有一票。应明确选择分层混合判定，或者承担每条已知至少二次来源确认的费用。

模型接口应输入回答原文、匿名 ID、名称词表与冻结别名，不提供 query/gold/J/臂；完整题目对 INTERVAL 已足以泄露正确集合，也不宜作为盲抽取输入。输出采用声明、系列角色、计算依赖与原文跨度。程序检查的是来源链，不是“这些词曾在 work 出现”。

两个来源应对采用结构一致，不是仅 PASS/FAIL 一致。不同厂商也不保证错误独立；现有共享平台的三个 AI reviewer 不能包装成两家供应商。本轮没有发起收费抽取调用，也没有声称实现了两族共识。

## 7. 审核与统计口径

- 已有 120 条 AI 审核和其中 42 条重复审核是开发材料；输入含 world/query，不能追称为盲抽取验证。
- 60 条开发回答衍生的 200 个受控夹具适合检查规则，不代表 200 个独立自然回答。不能凭这些夹具宣称自然精度达到 95%。
- “假 PASS 率”须写清分母是 predicted PASS 还是真实 non-PASS；两者不同。相关变体也不能直接套独立伯努利的 Wilson 区间。
- AI 继续承担开发审核，清楚保留来源与分歧。训练前的可靠性应针对独立锁定材料、实际正信用回答及整组残差，而不只看解析成功率。
- SELECT−SHUF 可作为主比较。value 和 J 是共同必须通过，还是任一通过即可，需要先写清；后者涉及多重比较。
- world 配对区间仍是给定训练模型下的不确定性；4/6 路径方向一致是描述条件，不能替代训练重复的推断。
- SELECT≈SHUF 不能由“不显著”直接得到；更不能据此证明只有方差起作用。需要事前等效界限，并保留机制解释的不确定性。
- “失败回答中 S=PASS 比例”条件于 J=0，模型修复一部分失败后分母和组成会变。应同时报告全体 S、UNKNOWN、J×S 联合分布。

## 8. D3、LZ 与下一步决策

LZ 可以保留为外部强基线，C 四臂保持同一题目日程，便于判断奖励内容。v7 的 LZ 提升并未单独隔离扩组、自适应曝光等因素，不能写成“扩组机制已证明有效”。

D3 可以作为下一阶段设计候选，但不因旧 C 被阻断就自动启动：

- 去充分性、改 UNKNOWN 处理、改题族、改曝光或改步数是不同设计因素，应分别列出。
- 依据父模型失败率剔除 cell，即使规则提前登记，也是依赖模型表现的筛选；须明确目标分布与外推范围。
- S=FAIL 而 J=1 的数值巧合是合法现象，不天然属于标签污染；若过滤，必须说明改变了什么任务分布。
- 优先完成已有回答测量与信号诊断，再决定是扩展真实可观察的抽取、独立验证，还是设计新数据。不能用观察到的确认集效果挑阈值。
- 设计稿所列 GPU 小时和外部调用量均未通过本轮测速确认，不能当作执行承诺。
