# C：F′小规模训练验证，输出前冻结方案

## 授权与问题

用户于2026-10-23授权按F′继续小规模C训练，比较SELECT、J、EVID和SHUF的实际收益。此方案是新的有界开发实验，不改写已完成A/B结果或旧C门控。此前盲核由AI完成，按用户授权使用，不能记作真人审核。旧探针的10个选择分歧组/8个world只说明有训练信号机会，不证明训练有效；b0没有分歧仍完整保留。

## 固定预算

三个原父模型SRF2_J6_s71001/71002/71003，对应b0/b1/b2；每个父模型各跑J、EVID、SELECT、SELECT_SHUF四臂。各路径仅16次优化器更新，每次16组×8回答=128回答，共12路径、192次更新、24,576条训练回答。不加步数，不筛除弱父模型，不按中途结果追加种子或任务。

|用途|固定题目与抽样|总回答数|
|---|---|---:|
|训练|64个新world，4格各16；每world两条相反列查询；每步每格4组；各格32题固定打乱后遍历两轮|24,576|
|新TOPK测试|128个独立新world，4格各32；256题×4回答×15个端点|15,360|
|旧任务保持|TEST_ID四族×八variant，每层抽2个world的bar/line题对；128题×4回答×15端点|7,680|
|ChartQA保持|固定250题，b0父模型和四训练臂各1回答|1,250|
|评测合计|3父模型+12训练终点|24,290|
|全部生成预算||48,866|

4格是T6/T8×SEPARATED/BOUNDARY。BOUNDARY内near/tied各半，largest/smallest及sum/mean均衡，两个查询交换选择列与取值列。仅按预先定义的数值构造生成，不挑选父模型容易出错的题，不排除错误选择碰巧答案相同的world；碰撞记录为诊断。训练/新测试/旧开发探针world内容必须不同，若固定构造碰撞即报错，不反复抽样寻找有利题。

训练生成种子2026102307，独立测试2026102308，旧TEST_ID抽题2026102309，ChartQA抽题2026102310。各臂共享每个父模型的题目暴露、顺序和逐回答种子，但在各自当前策略下独立生成。评测逐题种子各臂配对。完整题表、逐步计划、逐回答种子和端点任务表在首条模型调用前写入运行根目录。

## F′与训练口径

冻结程序判定器`srf4-observable-v3-programmatic-dev-r6`。每组候选回答要求原生J=0、协议有效、完成生成、任务定义明确；取消“证据已足以证明最终答案”的资格条件。要求候选至少2条，P/S均已知的候选至少2条，且占候选至少75%。只在这些已知回答上求均值；其余回答包括UNKNOWN残差为0。不得用AI标签回填程序UNKNOWN。

设p=1[P=PASS]，s=1[S=PASS]。EVID得分为p/2，SELECT为p(1+s)/2；各自对同组资格子集中心化再乘β=0.25。J残差为0。SELECT_SHUF在P相同的资格子集内，用预定种子均匀打乱S一次，随后同SELECT计算；允许打乱后不变，不重抽直到改变。

最终优势=原生组标准化A_J+上述残差；不二次标准化，不把零A_J组删除，不更改原生J判定。四臂使用完全相同的资格规则。保存逐回答P/S、候选集合、已知覆盖、残差、最终优势、SHUF实际排列与种子。

保留原生优化器、策略目标和底模/LoRA结构：AdamW lr=1e-5，betas=(0.9,0.999)，eps=1e-8，weight_decay=0，恒定学习率、梯度范数上限1，策略clip=0.2，TIS cap=2，KL系数0.02，对照为各自固定初始父模型。每条路径从新优化器状态启动，每步保存策略、优化器和RNG，可从最后已提交步恢复。G=8、温度1、top_p=1、top_k=0、最大生成1024token、原V2结构化提示；ChartQA使用原短答案提示。

## 评测与结论口径

主比较为新TOPK测试的答案正确率SELECT−SELECT_SHUF；原生J、SELECT−J和SELECT−EVID是主要补充比较。每个父模型、每格、旧任务各族/variant、ChartQA均报告完整分母和退化，另列父模型差值。UNKNOWN率、P/S已知覆盖与已知条件正确率分开，不能把coverage上升当成能力上升。模型输出无效/截断保留在分母中；技术缺失单独列出，不能冒充完成。

各world内先平均其题目和回答，各父模型等权。2000次配对world bootstrap，种子2026102311，报告95%条件描述性区间；同一world的题目、父模型和臂保持配对。不把回答当独立训练重复。三个父模型块不等于每臂多次独立训练种子；这些区间不能替代训练重复，也不是多重比较校正后的验证性显著性证明。本轮没有按显著性提前停止、成功阈值或自动扩大训练规则。

训练机制另报告实际on-policy组的候选/资格/选择分歧、零原生优势新增信号、SELECT相对EVID和SHUF的残差强度，以及各臂训练后是否获得真实答案和原生J收益。不能仅靠训练奖励增长声称C有效。
