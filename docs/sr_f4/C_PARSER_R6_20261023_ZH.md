## C 下一步的判断方式

先看P=PASS的合格失败回答在同一组内是否同时出现S=PASS与S=FAIL，再看这些分歧覆盖多少独立world和父模型块，以及SELECT−SHUF相对原生优势的量级。只出现更多失败、较低正确率或更高S覆盖，不等于出现了可用于C的选择信号。

原F与F′、r5与r6、四个cell及三个父模型都并列保留。r6若恢复了信号，应说明其中多少由测量覆盖变化带来。新探针没有预先登记“超过某个N_sig自动启动训练”的阈值；结果用于决定是否具备设计有界C训练验证的依据，不能直接宣称训练有效或启动完整矩阵。
