## 恢复连接后的唯一下一步

先只读核验冻结哈希、精确登记 allocation/提交目录和调度队列，确认没有未知的提交。
随后沿既定冻结执行基座格式检查。只有协议遵从的格式问题才可触发一次16步桥接；
独立 FORMAT_CHECK 仅一次，失败即停止。通过后完成测量和必要的隔离 ENGINE 测试。

最终仍须输出真实审计表、完整成本、失败记录及 `authorized=false` 的 DEV 冻结草案，
然后 `STOP_FOR_REVIEW`。当前没有 MM-DEV、MM-LOCK、MM-CAL、在线控制器或新符号训练权限。
