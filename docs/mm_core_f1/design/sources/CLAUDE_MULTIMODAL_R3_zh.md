## 2. 对GPT五个选择的逐项回应

按“接受／反对 → 最小修改 → 额外成本 → 改变的科学结论”。

### 2.1 数学与信息口径：接受

**最小修改**：撤回“共享偏移在max−min下不相消”；在预登记里把“哪些运算对共同偏移不可见”写成由w零空间决定的表（sum可见；有序差、range不可见），并限定全向量共享与同一单位。接受“事件表与逐坐标边际不决定跨坐标结构”的构造反例作为BGeo存在非冗余可能的数学依据。

**额外成本**：零。

**改变的结论**：对“共享偏移在哪些层隐藏补偿”的预期从两层改为一层（只有sum可见）；这降低了用运算分层间接推断偏移的空间，使跨坐标形状更可能携带表外信息。

### 2.2 动作：接受

**最小修改**：采用V×D四格与单轴配额；视觉轴只用可分辨的干扰、图例布局与拥挤度，固定分辨率契约与数值网格；数值轴只在原运算模板内用进位/借位配置与位数分布；两轴都作为B0与BGeo的共同结构特征。撤回“运算动作必然没有联合信息价值”的表述，改为“本轮不并行运行aS/aD/aM是预算选择”。

**额外成本**：四格数据生成与元数据核验；评价分层增加带来的精度成本另计。

**改变的结论**：先导回答的是“何时该加视觉复杂数据、何时该加数值复杂数据”，不再宣称纯感知/纯计算干预。

### 2.3 主要信息对比：接受

**改变的结论**：先导若在32步不可辨，结论是“该时长与预算下证据不足”，不是“状态不需要适应”；是否另起MM-CAL由预算和此结果决定，且MM-CAL数据永久记为开发数据。

## 3. 仍存在的分歧与我的补充

本轮没有实质分歧；下面是一项不增加训练的候选特征，以及两处把GPT的要求落成具体规则的建议。

### 3.1 候选特征：同根跨运算的读数稳定性

GPT 2.4节指出，从一条difference回答的读数反算sum，只是反事实算术；共享偏移要作为跨运算可复用的状态摘要，必须在各运算探针上验证稳定性。我把这一要求本身变成一个可测量：

对同一图表根q，取两条只在指定运算上不同的探针（例如sum与有序差），读数字段均可解析时定义

```latex
\rho_{\text{stab}}(q)=\mathbf 1[\,r_q^{(\text{op}_1)}=r_q^{(\text{op}_2)}\,],\qquad
\bar\rho_{\text{stab}}=\text{按根等权平均}
```

另报软版本 ‖r^{(op₁)}−r^{(op₂)}‖∞/δ\_q 的分布。

| 性质 | 说明 |
| --- | --- |
| 它测什么 | 报告读数是否随问题中的运算而变；低稳定性意味着读数被答案条件化，而非先读后算 |
| 可否由单题表推出 | 不能：任何单题的P/C/A或逐坐标误差都不涉及两条提示之间的关系 |
| 与主线的关系 | 若读数不稳定，共享偏移等几何量不能跨运算复用，BGeo应按运算分别计算；若稳定，几何量可作跨层共用的低维状态 |
| 成本 | 探针面板中每根至少含两种运算（已按根成组切分，只需设计上保证）；无训练 |
| 预期（不作判据） | 答案奖励准备的状态稳定性低于答案＋读数奖励准备的状态；a0续训降低稳定性 |

建议把它登记为BGeo的第二个标量（与S并列），只在MM-DEV的探针上计算；它是否有预测增量，与S一样由嵌套比较决定。

### 3.2 共用决策函数的具体形式

GPT 11.1要求两个策略共用决策函数、只在输入摘要上嵌套。建议写死为：

- 响应模型：对每个能力层r与动作a，用带状态×动作乘积项的岭回归预测ΔA\_{s,r}(a:a0)与ΔP\_{s,r}(a:a0)；BNum与BGeo只换状态特征集，正则网格、交叉验证与目标相同。
- 决策：Û\_s(a)=Σw\_rΔÂ−λΣv\_r\[−ΔP̂\]₊，在满足保守可行性 ΔP̂−κσ̂≥−ε 的动作中取最大；无可行动作则输出“不训练”。
- “b高选aP、d高选aC”这类手写规则只作BJ可实现的参照规则，不作几何的检验。

### 3.3 不做MM-CAL的理由

先导本身就是对时长与噪声的第一次校准；再加一个带独立数据身份的校准训练块，会把预算分成两份都不够的部分。接受“32步下证据不足”作为合法结论，比花钱买一个不进入正式验证的校准更划算。若用户预算允许第二块，我倾向把它用于MM-LOCK的新准备来源，而不是MM-CAL。
