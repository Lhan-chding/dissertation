# NTU dissertation：核心研究锚点

版本：2026-10-08；来源：用户本轮明确要求与决定。

## 不随局部实验改变的研究问题

把强化学习／后训练看作对模型可验证语义行为分布的干预。研究不同数据、曝光与奖励如何改变真正正确、补偿性正确及其他错误行为；检验这些训练前行为信息能否在强基线之外预测多能力训练响应，并支持带能力保持约束的训练决策。最终回到多模态感知／推理与 RL，而不是以符号修复的某个位置规律作为终点。

**测量 → 预测 → 决策 → 多模态 RL 验证。**

μ：可观测语义行为分布或摘要，不是已证明充分的内部状态。
J：有限发现预算下获得的可验证正确监督支持。
ν：实际训练曝光；不能把总曝光当作完整优化历史。
训练动作的价值：给定起点、替代动作、有限训练长度与成本时，多能力收益与损害的条件净效应。

## 对下一轮讨论的约束

不以“生成—验证—自训练”“状态驱动选样”“短分叉预测价值”本身作为新颖性。
不把相关回答、相邻检查点或相同父模型的派生状态当成独立模型总体。
不让局部机制研究或不断增加保护组合替代预测与决策主线。
不保证细粒度语义状态一定有用；负结果应改变方法假设，而不是改变统计口径。

每个新实验必须说明：它检验测量、预测、决策还是外推？结果如何改变下一步选择？最小充分证据和停止条件是什么？
