# 最终决定摘要

## 主线不变

可验证语义测量 → 训练响应预测 → 能力收益／干扰约束下的选择 → 多模态 RL。SER-J23 不恢复，不新增符号科学训练。几何信息只是候选状态摘要，不需要它必然胜出才能保留研究问题。

## 本轮执行到哪里

执行 MM-AUDIT；格式确有问题时允许一次公共短 SFT；没有匹配的真实多模态恢复回执时运行最短必要 ENGINE 测试。输出审计与 MM-DEV 冻结补充表后停止。所有条件通过也不自动授权 MM-DEV。

## 最后三个待定点

**跨运算稳定性：**保留审计，但加同提示重复采样对照。K=4 下不能把随机不一致都归到提示影响；稳定读错也不是视觉忠实。主 BGeo-S 先只检验跨坐标形状，相比 BNum；跨提示摘要以后要有单独、对称的对照。

**预测器：**保留低维岭回归＋状态×动作交互作为候选族。本次不拟合，不把五个开发起点当作180个独立状态；不将回归残差的κσ包装为已经校准的安全保证。

**两次冻结：**同意。当前审计工程一次冻结；MM-DEV在实测资产、数据可构造性、协议和成本返回后，独立确认补充表。

## 当下量级

完整审计原型：96题格式开发＋96题独立格式检查＋384题测量；各题K=4。默认含ENGINE时，无桥接最多2480条、有桥接最多2864条正常生成（含48条技术预留）；所有重做另受4096尝试总上限。桥接16更新、ENGINE默认8物理更新；累计工程更新硬上限64。默认单卡，累计分配GPU小时上限8。这些是预算约束，不是已测成本。

## 后续骨架保留，但没有本轮执行权限

Hp=32、H=32；公共起点＋两配方各两seed共5状态；每状态3动作×2未来seed，共30响应与4准备，合计1088逻辑更新。续训只改变V×D配额，同算法、同奖励、同协议、fresh optimizer、起点内共享冻结reference。正式预测／决策验证需要新的准备来源。

## 保护与不训练

相对a0的差用于动作比较；相对训练起点的变化用于“原有能力不退化”。不训练的绝对变化为0；它不是相对a0也为0。权重、保护阈值与费用在响应揭晓前独立冻结，不靠调效用制造最优动作翻转。
