# 实施与验证记录

本轮增加独立 frozen/raw-only 模块，不修改旧训练脚本与旧评价契约。公开编译器仅接受观察、关系、运算和原提示；truth、污染坐标、DPE 与程序预测由独立审计表供 CPU 评分使用。反向输出先以固定逆排列还原 a,b,c,d，再执行原下游运算；严格整个JSON解析，不截取、不修复、不择优解释。

B1 保留原关系和显示关系两套读数，I 上主 C 为0，域外四整数保留代数与程序匹配。PTLC 使用 Fraction；风险由每题 old/new V1/V2 完整向量决定。D48 首叶风险有5题，其中 V1 改变2题、V2改变3题；U22首叶风险2题，两种变体均改变。B1 DPE 0→1为 D48 6题、U22 2题。这些是登记程序预测，不是新增模型效果。

输入位置与输出位置使用 L00/L01/L10/L11 完整有标签2×2；命名格式效应单列。O0/B0的35个相同提示复用证据，后验变量共享、别名自身差值与方差为0。控制与D/U分母分离。统计提供单题精确二项区间、固定面板Beta条件后验及先验敏感性、场景配对bootstrap；B1原新向量偏好差使用同一单元内三分类协方差。

六个旧checkpoint由COMMIT定位，CPU可读性与身份验证通过，真实加载时再校验文件/完整CPU状态哈希、基座快照、LoRA参数/形状/dtype、buffers、位置状态、原环境、EOS与原uncached-prefix路径。无优化器实例，不恢复Adam到GPU，不在加载后重置LoRA。冻结参数、eval/no_grad，保存模型状态突变及原始技术错误，禁止额外似然重评分。

恢复以每8条COMMIT为准。每条原始结果先写独立pending receipt，评分失败不重新采样。生成器只接收system/user。技术故障有有限重试；配置、检查点或冻结状态违例立即停止。五GPU lease与固定五条Slurm队列约束并行上限。一个检查点失败不删除其他独立实验臂。
