# SSVC 下一轮实施规范：任务结构 × 语义状态 × 协议干预

**版本：2026-10-05。依据：截至2026-10-04的四条开发原件及GPT–Claude第六轮讨论。**  
**本轮性质：真实Qwen3.5-9B的冻结检查点推理实验；不新增RL训练，不拟合选择器。**

## 0. 首先明确本轮要完成什么

本轮需要回答三个问题，而不是再次完整扫描奖励配方：

1. **结构问题**：保持修复问题的真实解不变，只改变输出顺序或关系表达，成功概率与具体错误是否按登记的结构预测改变？
2. **状态问题**：相同题目、相同干预，在早晚源检查点和两种已有奖励训练端点上，效果是否不同？
3. **建模问题**：前缀锚定、完整程序匹配、照抄、局部关系遵循等读数，哪些确实提供有用的行为描述；哪些只是重叠或重复信息？

最小完整证据链是：**固定数学任务 → 明确修改一个实验因素 → 统一解析与评价 → 比较完整响应与不确定性**。完成本轮后，再决定是否需要新的训练或状态路由。协议改善不能直接称为原协议能力提高，交互存在不能直接称为控制器有收益。

本文件中：
- **已有依据**来自`sources/ROUND6_DISCUSSION_zh.md`及随附来源；这些是历史分析，不是本轮新增结果。
- **本轮设计**是现在拟定的执行约定。
- **未执行**包括新模型回答、跨协议效果、状态路由和任何新RL。

### 0.1 不能再混淆的三层假设

| 假设 | 可观察检验 | 当前地位 |
|---|---|---|
| H-anchor | 保留原观察中的早输出值、复制锚点的频率 | 历史开发数据有较强支持 |
| H-local/order | 顺序、显式单关系的可用性是否影响条件表现 | 本轮主要检验 |
| H-PTLC-exact | 完整输出是否等于严格PTLC V1/V2程序结果 | 历史仅部分子集吻合；不能当已识别内部算法 |

不允许用H-anchor的成功替代H-PTLC-exact的失败，也不因完整PTLC不吻合而直接否定所有顺序影响。

### 0.2 当前不做的工作

不新跑88分支，不新增源训练，不补训练缺失端点，不训练高维/低维响应预测器，不拟合奖励选择器，不加载新模型，不要求对整个概率分布进行高精度似然积分，不进行大规模超参数搜索。草稿、定位提示、图像提示、温度扫描、全部24种输出顺序均不是默认执行项。

旧的“只读分析”已在此前完成；本方案新增的是**冻结推理**，不是训练。若服务器检查点缺失，记录该比较无法执行，其余独立模块照常推进，不能擅自重训替代。

## 3. 数学任务、状态表示与评价定义

### 3.1 任务

四个规范坐标始终为`a,b,c,d`。错误观察为`o`，恰好一个坐标与真值`x*`不同。可靠关系为`H x=b`，数值域为0..99，原任务保证单处修复唯一。

主问题采用既有`SYMBOLIC_FRESH`的cross_series与trend。图像信息在本轮主任务中不出现。因此结论是**VLM在该符号修复接口上的条件行为**，不能推广成视觉感知能力结论。

### 3.2 生成顺序与语义坐标严格分离

`output_order = sigma`是“第k个输出位置对应哪个规范坐标”。若反序数组为`[d,c,b,a]`，必须执行：

```python
canonical[sigma[k]] = emitted[k]
```

然后在规范顺序上执行世界匹配、下游运算和原始关系检查。`difference_pairs`始终为`(a+b)-(c+d)`，不能在反序数组上直接计算。不得在两种解释中选择更接近真值的一种。

### 3.3 主事件仍然互斥完备

- X：严格可解析、域内、规范世界完全正确。
- S：严格合法，世界不正确但固定下游答案正确。
- W：严格合法且下游答案错误。
- I：其余；包括JSON不合格、非整数、非四项、越界。

严格解析是整个字符串`json.loads`，拒绝解释文字、markdown围栏、两个数组、bool、float、截取修复等。原策略在length终止时若完整字符串仍为合格数组，按**原解析规则**判定，另记截断标志；不擅自将所有length都改成I。

### 3.4 观测概率不是潜在程序权重

定义公开行为特征`Phi_i(y)`，状态为其联合分布：

\[
\mu_{s,i,u}=\operatorname{Law}_{Y\sim\pi_s(\cdot\mid T_u(i))}\{\Phi_i(\operatorname{restore}_u(Y))\}.
\]

均值向量只是这个分布的摘要，不等于完整联合分布。不得把`E[Phi]`与`Law(Phi)`混写。

建议保存：

| 特征 | 定义与用途 |
|---|---|
| E | X/S/W/I主事件 |
| parse_four_ints / in_domain | 区分格式失败与越界数值 |
| copy | 规范输出等于原观察 |
| anchor mask / anchor_all | 由显示H和输出sigma计算无闭合关系的坐标；这些坐标是否保留观察值 |
| match_V1 / match_V2 | 规范四整数与程序结果完全相同，V1越界也可作诊断匹配 |
| match mask | 三个位分别为copy、V1、V2；0..7互斥原子，不重复加概率 |
| local relation flags | 每条显示关系由实际输出值是否满足；按其最后输出坐标归组 |
| C_orig / C_display | 原关系与显示关系的满足比例，I上主分数为0 |
| C_alg_orig / C_alg_display | 仅四整数可解析时检查代数关系，允许域外值；不作为原奖励 |
| F/B/M | 合法输出的污染位置修对、原正确坐标损坏数、总修改数；属于真值审计 |
| other | 未匹配copy/V1/V2的输出保留，不事后增加程序规则吸收 |

部分特征相互重叠，不能直接画成加总为1的互斥五类。可用`E × match_mask × edit_mask × relation_flags`的稀疏计数表；不要求拟合该联合分布或进行降维。

不可解析输出的详细结构字段为null，同时保存全体分母。分别报告`P(parse & anchor)`与`P(anchor|parse)`，避免丢弃非法回答后人为提高锚定率。

### 3.5 任务元信息与特权审计分离

无闭合关系锚点集合`A(H,sigma)`不需要污染位置。DPE₁需要知道污染位置j，仅作为离线分层。所有公开提示变换均不能读取truth、j、历史X次数、DPE标签或端点结果。

求解器在当前任务中通常已能得到整个答案；因此DPE不是无成本能力读数，也不进入本轮策略路由。角色、数值、图拓扑等公开结构可以记录；没有明确权限定义的“语义信息优势”不作结论。

## 4. PTLC和变换算法——逐题字面预测先于GPU

### 4.1 PTLC不再改规则

依sigma遍历坐标k，收集所有含k且其他非零系数变量都已输出的显示关系。用**实际已输出值**求出各候选值。无可用关系则照抄；值一致或出现严格多数时采用；否则照抄。

V1保留越界求值；V2仅在值超出0..99时回退原观察，后续计算使用回退后的真实输出。内部使用Fraction，不四舍五入，不截断。遇到非整数预测，导出为有理数、标记`integer_prediction=false`；它不可能与严格四整数完整匹配，不临时增加新的序列化规则。

运行日志须有每个位置的闭合关系、候选值、选值、冲突/越界原因。copy和truth只作为参照；truth不是可部署求解策略，也不给模型。

### 4.2 DPE₁

\[
\mathrm{DPE}_1(i,u)=\mathbf1[j\notin A(H_u,\sigma_u)].
\]

在单错且真值满足关系的条件下，程序级`PTLC成功 iff DPE₁`有归纳证明；这个命题不等于真实模型遵循PTLC。本包测试覆盖原元数据全排列，不新增模型实验。

### 4.3 B1

仅sum-star cross适用。由非零系数交集确定唯一中心c，按固定原输出顺序`a,b,c,d`取最早的叶f。保留`x_f+x_c=b_f`，其他行改为`x_k-x_f=b_k-b_f`。记录可逆行变换T，精确验证：

\[
H'=TH,\quad b'=Tb,\quad\operatorname{rank}(T)=3.
\]

B1固定使用原顺序选择f；本轮不组合B1与A1，避免在组合里偷换f。负右端常数原样保留。不改变真值、观察、污染位置、数值域和下游运算。显示式固定为`叶变量 - 参考叶变量 = 带符号常数`，不改写成前置负号的`-参考叶 + 叶`，避免不必要的新表达因素。

**部分关系满足比例不是行变换不变量。** X和全部关系同时成立保持不变，但`C_orig`与`C_display`的部分得分可不同；不能用变化后的C替换旧奖励指标。

### 4.4 B1风险集合

先生成每题原新V1/V2完整向量，再形成：预测不变、只V1变、只V2变、两者变，以及新预测合法/越界/非整数等标签。

对变体v，只有`T_v(old) != T_v(B1)`时，才评价“新错误质量是否增加”。必须在两个协议的样本上同时测量`Y=T_v(old)`和`Y=T_v(B1)`；主诊断之一是：

\[
[P_{B1}(Y=T_v(new))-P_{B1}(Y=T_v(old))]
-[P_{B0}(Y=T_v(new))-P_{B0}(Y=T_v(old))].
\]

这个统计量不要求每条回答匹配程序，只直接检验程序登记的偏好变化。原新输出相同的题该对比恒为0，不要求出现新损坏。V1新增向量越界时，要在原始四整数诊断里计数；它的主事件仍为I。

### 5.1 A1的契约

原模板中“The record order is [a,b,c,d]”描述规范记录和变量含义，保留；最后一句明确要求返回`[d,c,b,a]`。system只要求一个四整数数组，不含相反的坐标顺序。

不改变模型的自回归解码方向。我们改变的是**输出语义变量的排列**，不是让Qwen从右向左生成token。

### 5.2 为什么不能直接比较“反转输入”与O0？

无标签数组反转会改变哪个数属于哪个变量。因此L00-L11使用有标签列举，在同一格式内隔离输入位置与输出位置；L00−O0另外报告命名表示本身的效应。

只有L10−L00及L11−L01能主要回答输入列举顺序问题。不能把L10−O0直接叫纯阅读顺序效应。

### 5.3 系统指令与解析一致

任何核心协议仍要求一个JSON数组，不加草稿、不加解释，不引入新stop符号。生成结束后先按该协议固定sigma逆排列，再评分。若输出未遵守反序，不自动换另一种解读让它变对。

核心观测禁止将“确认协议遵从”当筛选条件；不遵从与数学错误都留在分母，执行对照单独帮助解释。

## 7. 执行对照，不设置不切实际的硬正确率门槛

### 7.1 Copy-order

12道D元数据题，只要求原样复制已给数值。正向/反向分别输出。观察四值互不相同，避免反序被重复值掩盖。记录顺序执行正确率、格式失败、默认正序输出等。

这是明确提供目标数值的执行测试，不是修复能力测试；不使用原X定义。

### 7.2 Duplicate repair

12道原duplicate任务，线索直接给出污染坐标的正确值。比较O0/A1。它检验较低计算需求下的顺序执行与修复结合，仍不能独立排除所有格式影响。

### 7.3 Clean relation

12道cross，把完整真值作为**公开的已正确观察**，明确告知不要修改任何值。比较B0/B1。它用于检查新的减法、负常数和表示是否导致无故修改，不是“偷偷修好原题”混入主面板。

### 7.4 如何解读

不规定“控制准确率<95%就丢掉主数据”。给出原新计数、区间与失败形态。

- 提示编译矛盾、参数未正确加载、解析器错误：技术失败，修复后新版本重跑受影响单元。
- 模型不擅长新输出顺序：是协议效果的一部分，同时限制“推理机制”解释；原始回答不得丢弃。
- 对照表现好：说明一些执行条件可行，不证明所有任务上的格式/算术难度已完全匹配。

## 8. 采样与样本量

### 8.1 固定生成设置

继承已验证Qwen3.5-9B检查点与tokenizer revision；BF16基座，LoRA dtype按原实际加载路径。`temperature=1, top_p=1, top_k=0, do_sample=true, max_new_tokens=64, enable_thinking=false`。不换量化、不切换attention实现、不打开grammar约束。`protocol.json`还保存了原`pure_generation_options(64)`的全部选项，包括repetition penalty、min_p、beam、cache、强制token等；不能只固定temperature后让其他选项继承不明默认值。

使用历史uncached-prefix生成路径。需要缓存加速时先另立技术比较；**不能只因两条路径产生相同贪心答案，就断言采样分布相同**。本轮没有大量似然比估计，禁止为每个回答再完整重评分。

### 8.2 固定样本数

- D48及执行对照：每检查点×题目×协议32次。
- U22：每检查点×题目×协议64次。
- 可先交付每单元前16条的进度，但最终仍按固定32/64完成；中途结果不用于停止、选臂或调阈值。

不采用“没显著就翻倍直到显著”。如固定样本仍无法分辨小效应，本轮报告未分辨；更高精度是另一个明确追加方案。

### 8.3 为什么这次不要求1个百分点或更小的逐题精度？

本轮首先检验结构探针是否产生可见的条件变化，不是给每一步训练做1个百分点非劣证书。独立Bernoulli最坏方差下，两协议均值差在m题、每题n次时，正态近似95%半宽约：

\[
1.96\sqrt{0.5/(mn)}.
\]

- m=24,n=32：约5.0个百分点；
- m=6,n=32：约10.0个百分点；
- m=2,n=64：约12.25个百分点；
- 同m,n的四端点交互半宽约为`1.96/sqrt(m*n)`，更宽。

这些是规划近似，不是实际区间或硬门禁，也未包含任务间异质性。少数B1区分题适合检验明确的较大变化，不适合声称细小精度或种群泛化。

`10个百分点`只作便于阅读的实际尺度参考，不作为“否则实验失败”、统计等效或能力判定阈值。

## 9. 指标、统计与解释

### 9.1 基本单位与权重

每个固定检查点、固定原题、固定协议是一组Bernoulli/多项观测。保留prompt身份。全体符号汇总时cross/trend各占1/2，家族内题目等权。U22与D48分开，不因采样量不同而让某池获得更大权重。

模型检查点不是独立回答；61001的四个检查点不是四个独立训练种子。主T1/T2只支持这些具体历史状态上的条件差异。REP是预定第二条源轨迹复核，不足以估计一般训练种子方差。

### 9.2 核心效应

对指标f：

\[
\Delta_s^f(i,u)=E[f\mid s,i,u]-E[f\mid s,i,u_0].
\]

A1以O0为基线；B1以B0为基线；BR以O0为基线。

T1：`Delta_S96 - Delta_S32`。  
T2：`Delta_DIRECT_128 - Delta_R4_128`。

分DPE的0→1、1→0、0→0、1→1四格报告。不存在的格子记N/A，不填0。对于A1，DPE正翻负可能表现差，是待测结果，不预先当必然。

L因子实验：

\[
\{J(L11)-J(L10)\}-\{J(L01)-J(L00)\}.
\]

同时报告四个原始水平、输入主效应、输出主效应，以及L00−O0和L01−A1的格式差异。

### 9.3 不确定性明确分三类

**a. 单题边际区间。** X等二元读数给Clopper–Pearson95%区间；0/32不是0概率，一侧95%上界约8.94%；0/64约4.57%。不同策略不合并后套一个二项分布。大量逐题区间不是同时保证。

**b. 固定面板测量不确定性。** 给未平滑经验点估计和plug-in MC SE。因0/n、n/n会让plug-in SE退化，主报告并列给独立`Beta(1/2,1/2)`条件后验的95%可信区间，20000次CPU抽样；`Beta(1,1)`作先验敏感性。明确这是给定独立Bernoulli模型的可信区间，不叫分布无关置信证书。涉及共享O0/B0别名时，必须复用同一后验变量，不能假装独立。

**c. 题目异质性。** 同一base_scene的所有协议和检查点一起重采样，按家族/预定结构分层，5000次paired-scene bootstrap，不再在同一复制内嵌套重复抽completion。报告为描述性场景bootstrap，不包含训练种子不确定性。全零/全一导致退化时，不能将退化区间解释成精确已知；并列看a/b。

D/U是小型、部分后见选择的面板；bootstrap不能把它变成新的独立随机任务总体。主结论以完整效应表和一致/不一致的题级证据为依据，不执行上千个p值后挑赢家。

### 9.4 一致的判断词汇

- **观察到条件改善/损害**：报告点差与区间，并明确面板/检查点。
- **与字面程序预测一致/不一致**：只针对事前登记的完整向量或方向。
- **未分辨**：范围仍同时容纳重要正负结果。
- **没有证据支持**不等于**证明完全不存在**。
- **格式因素限制解释**不等于删除该臂。

没有全体必须通过的安全阈值，不把“不显著”叫“等效”，不把不同protocol条件成功叫“原条件能力提高”。

### 9.5 本轮的决策价值边界

可计算：统一协议、按家族统一协议、结构标签分层后的响应表，以及后见逐题最优值（明确标为乐观描述，不作为算法）。

**不训练路由器。** 即使T1/T2交互成立，如果各状态仍由同一协议占优，就不需要状态路由。只有跨状态排序变化在新面板/另一个既有源状态上有支持，才讨论下一轮的前瞻规则。

DPE标签读取j，属于solver审计信息。将来采用它作路由时必须给予基线同样权限；不能把它当我方秘密特征。

## 13. 运行验收与停止边界

CPU契约测试通过后允许进入冻结推理。它们不能替代GPU实际集成。

必须阻塞的情况：错误检查点、提示变换不等价、规范逆排列有误、真值进入主提示、无法保留原始输出、同一key出现不同回答被静默覆盖、实际调用训练步骤。

所有计划完成或明确记录不可执行单元后，**停止在新的模型回答数据与分析报告**。不自动启动两条替代训练，不扩到5B/30B，不接入在线SSVC，不再跑完整奖励网格。

若条件干预有效，它只是为下一次有针对性的训练设计提供依据；最终仍须检验原协议、独立题目、同信息权限下的后训练收益。这条闭环保留，但本轮只负责把最不清楚的结构与状态响应测清楚。
