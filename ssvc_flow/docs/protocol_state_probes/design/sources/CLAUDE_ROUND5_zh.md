## 0. 结论先行

我接受把规则固定为DPE₁，也接受GPT对“未来信息”“架构不可能”“代数对称”三处表述的收紧。本轮我的主要推进是：把DPE₁背后的行为假设写成一个无自由参数的生成算法，它同时给出成功条件和失败形态，因此可以逐题、逐协议作出可证伪的输出预测。

**前缀信任的局部补全（PTLC）**：模型按输出顺序逐个写坐标；写第k个坐标时，若存在一条显示出来的关系，其其余变量都已输出，就把第k个坐标写成满足该关系的值，并把已输出的值当作可信（即使它是错的）；否则照抄观察值。

它的推论与已有数据的对应：

| PTLC推论 | 已有观察 |
| --- | --- |
| 成功当且仅当DPE₁成立 | 58/58对0/56 |
| 13道“DPE₁负、线性可解”题失败：PTLC只用显示关系，不做跨关系组合 | 13/13零成功 |
| trend负例：保留含错误值的前缀，后部按前缀续写等差 | 关系全成立的错误中99.19%是精确前缀延伸；非法输出全是越界四整数 |
| cross叶在中心之前：中心处三条关系中两条已满足，保留，整体照抄 | 照抄增长集中在DPE₁负cross（同题项+38.11pp） |
| cross中心先输出且被污染：后面的叶去迁就错误中心 | 1,407/1,408保留错误中心，合法修改以单处为主 |

这让GPT的13个反例从“对DPE的反驳”变成“对两种机制的区分”：它们支持“只用显示关系的局部补全”，反对“一般代数推理但受顺序限制”。

三个具体推进：

1. **等价行变换有一个高风险预测。** 我用一个只依赖结构与输出顺序、不依赖污染位置的统一变换（保留最先输出的叶与中心的关系，其余改写为叶与该叶之差），它恰好把13道题全部翻正、不让任何正例变负。PTLC还预测：当最先输出的叶本身被污染时，变换会让后面正确的叶去迁就它，产生新的损坏。这是可被直接否证的预测。
2. **反向输出中有12道cross题能区分PTLC与“纯位置锚定”**（D 3道、P 2道、分支训练池7道），trend在反向下两种解释预测重合。
3. **DPE₁路由是求解器特权。** 概率观测器的价值应该在“同DPE₁、不同状态”的操作交互上检验；现有检查点就能提供两种：阶段（t32对t96）与奖励造成的错误状态（同一原点的DIRECT与R4端点）。若端点权重仍在服务器上，不需要新训练。

## 2. 回答Q1：采用DPE₁；没有更简单的统一规则，但有一个能生成它的行为算法

结论：接受DPE₁，并把13道题作为关键区分子集；在所有不依赖结果的候选规则中，DPE₁是与全部区分格子相容的最简规则，而它恰好是PTLC算法的成功条件。

### 2.1 候选结构规则逐一对照区分格子

| 候选规则 | 它的预测 | 被哪些已有格子否定 |
| --- | --- | --- |
| 纯位置：污染在第3、4位才可解 | 只看输出位置 | cross叶在第2位、中心在第1位：源训练中可学（0.25→0.55）；cross叶在第3位、中心在后：D为0.00（2题）、源训练0.02–0.09 |
| 被违反关系数：污染中心（违反3条）易、污染叶（违反1条）难 | 只看角色 | 中心在第1位的2题为0；叶在第4位且中心在前为1.00 |
| 代数组合深度：不论顺序，所需运算越少越易 | 叶的修复只需一次减法b−x\_center，应当容易 | 所有“中心在后”的叶都为0 |
| 一般前缀线性可识别（d\_lin） | 允许跨关系消元 | 13道d\_lin正题全部为0 |
| DPE₁：存在一条显示关系，其余变量都已先输出 | 显示关系的局部可完成性 | 无 |

所以13道题不是孤立反例，而是唯一能区分“显示关系的局部补全”与“允许代数组合但受顺序限制”的格子；数据站在前者一边。

### 2.2 把DPE₁写成生成算法：PTLC

输入：错误观察x̃、显示关系H、输出顺序σ、数值域0–99。按σ逐个输出：

1. 对当前坐标k，找出所有“含k、且其余变量都已输出”的显示关系R\_k。
2. 若R\_k为空，输出x̃\_k（照抄）。
3. 若R\_k中各关系用已输出值（不论对错）解出的k值一致为v，输出v（v可能就等于x̃\_k）。
4. 若各关系要求的值冲突：存在严格多数时输出多数值，否则输出x̃\_k。
5. 越界规则必须在核对前二选一并登记：V1照样输出越界值（记为非法）；V2越界时改为输出x̃\_k。

PTLC没有可调参数，只有第5步的两个预先登记变体。它是确定性的“众数行为”预测器；真实策略是随机的，因此检验指标是“与PTLC输出完全一致的比例”以及各结构类的成功率，而不是要求每条输出都符合。

| --- | --- | --- | --- |

## 5. 回答Q3并给出可冻结的下一步

结论：DPE₁足以解释“哪些题被锐化掉”，但作为路由是求解器特权；概率观测器的价值应在“同DPE₁、不同状态”的操作交互上检验，而现有检查点已能提供两组这样的检验，不需要先做新训练。

### 5.1 观测器的三种作用要分开

| 作用 | 本批中谁足够 | 观测器是否有独立价值 |
| --- | --- | --- |
| 解释哪些修复被学会、哪些被锐化掉 | DPE₁（结构标签） | 否，这是任务结构分析 |
| 识别哪些题会成为荒漠 | t32的行为读数pX已几乎足够（4.3节） | 不需要结构标签，但也不需要复杂状态 |
| 选择下一步操作，并预测其收益 | 需要知道失败机制与当前状态 | 待检验：同DPE₁下状态不同，操作收益是否不同 |

在无求解器的真实任务里，DPE₁不可得；免真值的行为特征（照抄率、对观察前缀的精确延伸、早输出值被锚定、C=1且M≥2）是否能代替它诊断“前缀信任型失败”，是观测器在一般任务中的潜在作用。本任务可以先验证这种代替是否成立，但不能把求解器权限迁移出去。

### 5.2 两个“同DPE₁、不同状态”的冻结检验

**T1 阶段状态。** 同一组题、同一协议探针，在61001的t32与t96检查点上各做一次。状态变量是PTLC遵循度（4.4节：P上trend负例前缀保留35.63%→93.75%）。

**T2 奖励造成的状态。** 同一原点（如61001\_t96）经DIRECT\_REPAIR\_R4与R4各32步后的两个端点；题目与DPE₁完全相同，但DIRECT使晚期trend负例照抄增加18.75pp。
