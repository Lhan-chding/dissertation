# 本轮实验概览

## 核心决定

**先用已存在的真实9B检查点做“结构×状态”的冻结推理，不再训练更多奖励分支。**

过去多轮讨论已经明确：
- 晚期主要错误与输出顺序、显式关系局部性相关，但不是“后面输入不可见”。
- 前缀锚定很强，完整PTLC程序只解释部分输出；二者必须分开。
- B1风险题需按程序逐题预测，不再假设8题都应产生新错误。
- 同一干预在不同状态下效果不同，不等于状态路由优于统一方案。

## 这次做什么

| 问题 | 实验 |
|---|---|
| 生成变量的先后是否重要？ | 原协议O0与反向输出A1 |
| 是否只是关系组合不够显式？ | 原关系B0与等价叶差表达B1 |
| 单纯关系行排列是否影响表现？ | BR仅反转行顺序 |
| 输入位置与输出位置是否混淆？ | 有标签输入的L00/L01/L10/L11完整2×2 |
| 早晚状态是否调节效果？ | 61001 t32与t96 |
| 已有奖励历史是否调节效果？ | 同一t96原点的R4和DIRECT H32端点 |
| 是否只在已看过的题上成立？ | 未运行结果的U22，另用61003 t32/t96复核 |

主要读数仍是精确恢复pX，但同时保留copy、anchor、PTLC完整匹配、局部关系、越界和其他输出。程序匹配是行为，不是内部算法权重。

## 资源与工作量

主矩阵使用6个旧检查点、最多5张单卡并行。实际编译得到509个case，其中35个B0与O0完全相同提示可别名复用。完整计划70,656条新回答，技术smoke最多80条；**0次新训练、0次额外似然评分**。

这不是一次性等全部跑完再看。最先交付S96核心完整对照，其余阶段并行。四到五张卡的实际工期由首个完整块的生成吞吐估计，不承诺未经测量的小时数。

## 样本与精度

D48、对照每题32次；U22每题64次。固定样本量，不按效果无限追加。少量关键题可以检验较大方向变化，不能承诺1个百分点或更小的逐题精度。报告点差、单题边际区间、固定面板测量不确定性及场景异质性；不用所有指标必须通过同一安全阈值卡住研究。

## 完成后能说什么

可以说：哪些协议改变了哪些行为；这种影响是否受检查点状态调节；字面程序在哪些子集获得支持或被削弱。

尚不能说：找到了唯一内部机制；冻结提示改善证明原协议能力提高；SSVC已经有效；概率状态一定比统一协议更有价值。

下一次是否训练，取决于本轮究竟支持哪一种问题：协议能帮助求解、训练能把帮助迁移到无辅助条件，还是语义观测能够选出更合适操作。三者不混为一项收益。
