# 供后续讨论：事实、候选解释与不可区分项

本轮已完成冻结矩阵并统一揭晓。以下讨论不授权新实验；事实以FINAL_FINDINGS_zh.md及逐题证据为准。

## 已观察事实

1. 新题上的两调用固定协议组合比O0重复高约12.94 pp，条件场景区间为正；同16次发现预算下MIX增加82–92题同时丢失0–3题。推理互补与训练集合变化都有直接证据。
2. 固定SFT设置下MIX扩大支持集合，也降低每题平均曝光；其J内sentinel有9/11、10/11两组未完全再现，不能假定发现成功必然充分拟合。O0的6/16 sentinel则由J内6/6、J外0/10组成，不能以此误判已训练目标学不会。
3. 学生O0主比较为+3.052 pp，[−0.008,+6.120]；相对V上按B16冻结的SELF_SINGLE+2.018 pp，[−0.366,+4.411]。优势尚不确定，并非等效证据。MIX在难层明显更高，却在父已有成功层和duplicate上有所损失。
4. GOLD_ALL、S96 GOLD_MATCH均有更高E点估计；GOLD_MATCH只匹配数量与family×损坏位置，不匹配完整难度或相同J。图像保持性接近天花板，S96 GOLD_ALL仍出现小幅下降。
5. R0有限32步整体约49.76%，88/128次当前优势全零；它既非等计算SFT对照，也不是一般RL能力否定。

## 与事实相容、但没有被单独识别的解释

- MIX扩大难层训练覆盖，可能提高这些区域的原协议生成成功；同时固定总更新令每题曝光稀释，可能影响已掌握区域。现有设计一起改变支持集合和曝光，不能在两者之间作因果分摊。
- GOLD_MATCH的更高表现可能与未被匹配的难度、覆盖或优化互动有关；同一输入的规范真值相同，因此不能笼统声称“金标字符串质量”胜过验证正确self标签。
- 格式非法率下降与合法错误率上升并存，说明仅看可解析性不足以解释完整修复收益；PTLC/copy/F/B/M是诊断关联，不是已验证的中介机制。
- 图像接近满分限制了可见改善空间；64对的E/G变化差可能由E改善驱动，不能自动叫图像遗忘。duplicate的实际下降应独立保留。

## 仍不能回答的问题

- 新的独立父训练轨迹是否复现；两父×两嵌套repeat不足以给出父总体推断。
- 固定更多曝光是否解除MIX拟合/保持代价；本轮没有追加步数或重新选最佳checkpoint。
- 复杂观测器/路由器是否优于当前简单固定策略；本轮没有该干预。
- 0–99新分布与历史0–49任务的域变化贡献；12题旧范围E子组不是可靠ID复现。
- SFT后继续RL、动态奖励、teacher刷新或多轮自训练是否有效；这些均未执行。

结论措辞宜限定为：协议互补能改变可验证成功集合，原协议学习获得正的相对点估计，但主比较尚未确证优势且存在保持性代价。不能写“复杂SSVC得到全面验证”“GOLD是真正能力上界”“原先零概率能力被创造”或“RL不可学”。本轮数据已揭晓，以后不得再称这批E为未见测试集。
