# V3 建模定义、推导与实现契约

本文件区分三类内容：上一轮实测（见 `evidence/`）、本轮建议检验的模型、经典数学恒等式。以下推导是设计依据，不自动构成论文创新或真实模型安全保证。

## 1. 状态与主估计目标

固定题目 i、完整训练原点 s=(θ,m,ν,step,RNG,配置)。同一 bank 的所有候选从这个原点恢复，实际执行一次 Adam 后得到 θ⁺_b、θ⁺_u。

四事件顺序固定为 X,S,W,I，真实事件差：

\[
C_i=(C_{X,i},C_{S,i},C_{W,i},C_{I,i})^\top,
\quad C_{c,i}=P_{\theta^+_u}(c\mid i)-P_{\theta^+_b}(c\mid i),
\quad\mathbf1^\top C_i=0.
\]

输入是实际参数差 e=θ⁺_u−θ⁺_b，不是 reward 系数差、梯度范数或梯度乘学习率。四事件是可验证输出事件，不是四种内部隐藏认知状态。

主指标：C_X、C_v=C_X+C_S+C_W=−C_I。群体指标用固定 prompt 权重平均。条件 q_X 需要另外测得两个端点的绝对 p_X/v；仅有差值不能恢复两个比值。v 的支持不足时返回 UNKNOWN。

Helmert H∈R^{4×3} 满足 HᵀH=I、Hᵀ1=0，真实零和向量可以无损写为 HᵀC。但有噪声原始估计 \hat C 一般不满足零和：只保存 Hᵀ\hat C 会丢掉观测质量残差 M=1ᵀ\hat C。若要完全保留原始观测，保存 (Hᵀ\hat C,M)，逆变换为 H(Hᵀ\hat C)+M1/4。

**M 是测量残差，不是第四种独立语义自由度。**

## 2. 共同样本的差值观测

固定 proposal ρ，且它覆盖 π_u−π_b 的支持。对 a_j~ρ：

\[
w_j=\frac{\pi_u(a_j)-\pi_b(a_j)}{\rho(a_j)},\quad
z_j=w_j\,e_{c(a_j)},\quad
\widehat C=\frac1n\sum_jz_j.
\]

E[z]=C，E[w]=0，M=\bar w。分类器必须对完整动作空间构成不重叠且穷尽的分区；截断、空输出和解析失败不能丢弃。

### 2.1 两端点混合 proposal

ρ=(π_u+π_b)/2 时：

\[
w=2\tanh\left((\log\pi_u-\log\pi_b)/2\right),\quad |w|\le2.
\]

这避免直接对两个接近的极小概率相减。每条序列先独立抽取来源 B/U，再从对应策略生成；为吞吐分组执行可以，但不能把独立 Bernoulli 来源偷换成未经修订的固定比例抽样。

若三策略等权混合用于同时测两种差值，则任一对比 |w|≤3。不能套用二策略界。主对比仍保留二策略检查。

### 2.2 ORIGIN proposal

ρ=π_origin 可跨候选共用一批输出；其权重无统一 2 的界。使用 logsumexp/expm1 的稳定实现；记录每条贡献、权重尾部、二阶矩和样本支持。高总体 ESS 不保证 X 已得到观测。观察不到 X 不表示 P(X)=0。

### 2.3 不做的隐式修正

零和修正之前必须保留并审计raw质量残差。若概率评分不对应实际归一化采样策略，E[w]=0的前提可能不成立；把残差强行投影成0会掩盖系统错误。发现显著、可重复的raw质量偏移时先检查decoder/评分/支持，不能靠修正“修好”证据。

主估计不裁剪权重、不自归一化、不把负的概率差截为零。SNIS 和裁剪可以作为单独的有偏诊断，但不可继续称作同一个无偏估计器。

## 3. 零和约束：观测几何的七个对照

定义修正 A_b=I−b1ᵀ：

\[
\widetilde C_b=\widehat C-bM.
\]

b 固定且 1ᵀb=1 时，修正后逐次零和，仍无偏。

- RAW4：b=0，保留原始无偏观测；单次不保证零和。
- EQUAL_ZERO_SUM：b=(1/4,1/4,1/4,1/4)。对应旧 Helmert 投影。
- DROP_W：b=(0,0,1,0)。不改 X、S、I，将 W 定义为其他差值的负和。
- PRESERVE_XI：b=(0,1/2,1/2,0)。不改 X、I，因此 pX 与 v 完全保持原始估计；残差只分配给 S/W。
- KNOWN_COV_ORACLE：用完整动作分布的真实协方差，仅作为 CPU 诊断上限。
- PILOT_COV_ZERO_SUM：用独立 pilot 估计协方差，冻结 b 后用于 main 样本。
- PILOT_SHRINK_ZERO_SUM：独立 pilot 的协方差收缩，并限制 b 的 L1 范数；本轮候选方法。
- CROSSFIT_COV_ZERO_SUM：二折交叉拟合，作为后续效率对照；推断需重跑整个交叉拟合流程。

RAW4 与受约束模型拟合的兼容性必须明示：不可先把 RAW4 静默乘 HHᵀ 再称 raw。可直接四输出回归，或在 GLS 中显式施加真实输出零和约束。输出约束前后都保存。

### 3.1 为什么等权投影可能损害 pX

P=I−11ᵀ/4。对真实零和 C：

\[
\|P\widehat C-C\|^2=\|\widehat C-C\|^2-\frac14(1^\top\widehat C)^2.
\]

整体欧氏误差不增加，但单独 X 的误差没有同样保证。不能用总误差改进证明每个语义目标都改善。

### 3.2 已知协方差的最优线性修正

令 Σ=Cov(z)（每条样本贡献的协方差），v_M=1ᵀΣ1，c=Σ1。
若 v_M>0：

\[
b_*=\frac{\Sigma1}{1^\top\Sigma1},\qquad 1^\top b_*=1.
\]

\[
\operatorname{Cov}(\widetilde C_{b_*})
=\frac1n\left(\Sigma-\frac{cc^\top}{v_M}\right).
\]

对任意固定 b：

\[
\operatorname{Cov}(\widetilde C_b)
=\frac1n\left(\Sigma-\frac{cc^\top}{v_M}
+v_M(b-b_*)(b-b_*)^\top\right).
\]

最后一项半正定。这是经典控制变量／受约束估计的结构，不宣称新的通用统计方法。

### 3.3 pilot 系数估计的代价

若随机 \hat b 只由独立 pilot 决定，main 的 n 条样本与它独立，则条件与无条件均值都等于 C，并且：

\[
\operatorname{Cov}(\widetilde C_{\hat b})
=\frac1n\left(\Sigma-\frac{cc^\top}{v_M}
+v_M\,\mathbb E[(\hat b-b_*)(\hat b-b_*)^\top]\right).
\]

因此，有限 pilot 的误差可能吃掉甚至超过 oracle 方差收益。不能将已知 Σ 的“不增方差”结论直接移植给有限 pilot 方法。

同成本比较必须使用 N_total=n_pilot+n_main：RAW4/EQUAL/DROP_W/PRESERVE_XI 允许使用全部 N_total 条；另保留只使用 n_main 的配对诊断以分离 pilot 成本。主设计 pilot 占 1/4；比例优化只能用 development。

### 3.4 稳定化与边界

采用 \hatΣ_η=(1−η)\hatΣ+η tr(\hatΣ)I/4，η∈{0,0.1,0.5,1}。
若 pilot 完全没有权重变化／分母为零，返回 `PILOT_UNINFORMATIVE` 并使用预先固定的 PRESERVE_XI，保留 fallback 次数；不得宣称估得了真实最优系数。

\hat b 的 L1 上限为8。超出时向等权 b 收缩到可行范围，保留原系数和收缩量，不按测试误差挑选 fallback。此时不再适用 oracle 协方差最优性结论。

两策略 MIX 且 ||b||_1≤8 时，任一事件修正后贡献的绝对值≤2(1+|b_c|)≤18。范围有限可用于保守集中界，但界可能很宽；这不能替代经验精度检验。

若 1ᵀz 在精确算术下逐次为0，则不再执行质量控制变量修正；v_M=0 的公式不能除零。

### 3.5 联合协方差

对一个 prompt 的全部候选对比，把逐次贡献堆为向量。共同 origin、共同 baseline、共享样本、共享 alias 的相关性都进入 Cov(vec C)。若相同实测对象复用两次，不得当作两个独立观测。

pilot 固定后条件协方差按 A\hatΣAᵀ/n 传播；若不同对比共用随机 pilot，跨对比的额外不确定性通过外层重复或重拟合 bootstrap 处理。二折估计均值仍可无偏，但不能把两折当相互独立来给区间。

## 4. 校准方向覆盖与可辨识性

对同一完整原点的校准差向量 e_1...e_m，令 Q 为其未中心化列空间的正交基。对查询 e：

\[
e_\parallel=QQ^\top e,\quad e_\perp=e-e_\parallel,
\quad\rho(e)=\|e_\perp\|/\|e\|.
\]

e=0 单列，不除零。rho 是几何覆盖描述，不是危险概率。还需记录最小非零奇异值、条件数和 span 内 leverage：

\[
h(e)=a^\top(A^\top\Omega^{-1}A+\lambda I)^{-1}a,
\quad a=Q^\top e.
\]

小 rho 但很高 leverage 的查询仍可能不稳定。加 ridge 会产生偏差，不能把这个式子直接当成已校准置信区间。

### 4.1 未覆盖方向的不可识别见证

若 wᵀe_j=0 而 wᵀe≠0，则 J 和 J'=J+uwᵀ 在全部校准输入上给出相同响应，在查询上却不同。
在额外假设未建模方向的导数范数≤κ时，存在两个不可区分映射，使查询预测的最坏误差至少为 κ||e_perp||。没有这样的 κ 上界时，误差可任意大。

所以 `NO_CALIBRATION_EXCITATION` 只能返回 UNKNOWN。作为统计基线的零预测仍须保留并评分，但不能作为控制结论。

### 4.2 候选校准的选择

FIRST、分层随机、最大范数、block pivoted-QR、block log-det 全部保留。
一个 bank 包含主/辅/No-X 三候选，作为一个获取单元选择，不能按最有利的单独对比计费。
QR/LOGDET 只读取校准候选池的实际 e 和元信息，禁止读取 heldout 概率响应。为获得这些 e 所进行的 bank 采样和 Adam 分支不是免费。

LOGDET 使用固定数值岭：在候选池的精确几何空间中最大化 log det(λI+Σ e_j e_jᵀ)，λ按development锁定。它是经典设计基线，不以其本身作为创新。

### 4.3 同一原点不等于每个bank的主更新端点相同

各bank的主更新d_b^0不同，因此其C_u是在θ+d_b^0附近产生的差。若f的梯度L-Lipschitz，则从共同原点θ线性化有：

\[
|f(θ+d_b^0+e)-f(θ+d_b^0)-\nabla f(θ)^\top e|
\le L\|d_b^0\|\|e\|+\frac L2\|e\|^2.
\]

推导：沿θ+d_b^0→θ+d_b^0+e积分梯度，再与θ处梯度相减，使用Lipschitz与三角不等式。

因此跨度大时，即使e落在Q内，也可能因为主端点变化而失配。保存d_b^0及其norm；非线性诊断可加这些特征，但不能把基线端点换掉后继续声称同一个目标。该不等式是常规光滑性界，不是已测得VLM的L常数。

## 5. 模型与维数

无偏 C 的理论三维表示保留；观测处理先固定，再比较模型。
依次比较 ZERO、FULL_RIDGE、FULL_GLS、PCA、随机Q、普通响应SVD、群体加权响应。额外 RBF/ridge 仅用于“线性是否瓶颈”的诊断。

输入秩 k、保留秩 r 与参数总维数 D 分开报告。r=k 时，正交旋转全秩拟合的等价方法合并，不能包装成多种方法互有胜负。只有 r<k 单元用于主张方向选择或低秩压缩收益；全体单元仍完整报告。

参数空间度量保持同一 LoRA 坐标，禁止在候选之间重缩放A/B而不重做几何。跨模型、不同模块mask或不同初始化的基不直接拼接成同一Q。

## 6. 误差分离与下一步决策

有精确 CPU Jacobian 时，依次报告：

真实差值 − 完整局部一阶；
完整局部一阶 − 投影方向一阶；
投影方向一阶 − 精确校准拟合；
精确校准拟合 − 有限观测拟合。

保留向量和交叉项，不按各范数相减声称因果贡献率。

VLM 不能枚举语义事件时，独立参考也是估计。若预测与参考独立，
E[(pred−ref)^2]=E[(pred−C)^2]+Var(ref)。可以报告减去参考方差的聚合 MSE 估计，但有限样本可为负，禁止逐单元clip后伪造正MSE。参考未达到目标精度时，标记REFERENCE_UNRESOLVED。

阈值/区间的冻结、统计单位、漏检与拒判处理见主计划。上述模型暂不控制真实训练。
