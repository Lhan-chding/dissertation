## 2. 指标与成本口径

原始四事件贡献为 z_e = [(p1(a)−p0(a))/q(a)]·1{event(a)=e}；修正为 z′ = z−b·sum(z)。PRESERVE 使用 b=(0,1/2,1/2,0)，因此 X 与 I 不变，质量残差分配到 S/W。RAW4 未先投影到三维再改名为 raw。

- 残差 = 估计的概率变化 − 精确有限动作真值。表中每格为 **MSE / |残差|q95**；概率变化使用 0–1 概率单位，q95 不是置信区间或失败概率上界。
- Δv 定义为 −ΔpI，因此 I 与 Δv 的 MSE、绝对残差分位数完全相同；有符号偏差取反。四事件总 MSE = X、S、W、I 的 MSE 之和，不再次加入 Δv。RAW4 的 X+S+W 与 −I 可因质量残差而不同，不能静默替换定义。
- 偏差是所有 repeat×probe 残差的均值；pooled 方差使用 ddof=0，包含不同 probe 的偏差差异。测量方差则先对每个固定 probe 的 200 次重复计算 ddof=1，再按 probe 数平均。原分析分别保留两者，并保留逐事件 q50/90/95/99，未将它们混成一个“方差”。
- RAW4、EQUAL、DROP-W、PRESERVE 均使用全部 n 条；独立 PILOT 以 n/4 拟合系数，以独立的 3n/4 计算估计；CROSSFIT 用两个互斥半样本交叉应用对方系数，最后使用全部 n 条。主点拆分为 256+768。另有相同 main 子集的简单方法比较，数值 JSON 保留加权 MSE。
- PILOT-COV = 无收缩独立 pilot；PILOT-SHRINK = 预先命名 η=0.1 的独立 pilot 收缩法。η=0/0.1/0.5/1 的全网格使用相同包，无额外生成/评分；本报告未通过结果另选 η。
- 独立计数使用同总生成量 n、两端点各 n/2；相同策略触发精确别名零对比捷径，不新抽独立计数样本。ORACLE 使用精确协方差，精确事件枚举直接读取有限动作真值，均拥有额外信息，不能算作可部署观测方法的同权限胜出。
- 这里的评分是已缓存有限动作概率的查询，无真实模型 forward；相同抽样量不能直接转换为两张 PRO 6000 的吞吐或费用。

- 显式相同策略及所选实际别名的 pilot 回执为 PILOT_UNINFORMATIVE，fallback 到 PRESERVE_XI，比例 100%。原身份哈希池含 4/12 此类身份，因此整体 fallback=1/3；把两种 case 合并为 192 单元后为 2/3。这两个汇总率主要反映纳入的同策略对照比例，不是非零策略上系数失败率。
- ORACLE 的 fallback 率缺原始回执，保留 MISSING_INPUTS，不能用相同策略的已知零残差推测一个数值。系数逐单元 L1 分位数保留在原 SUMMARY，未将逐单元分位数平均伪装为 pooled 分位数。
