## 6. N/L 对比

在本次冻结评估中，N 相比 L：

- 采样 pX 高约 0.188，qX 高约 0.130，合法率高约 0.148。
- 采样 pI 从 0.190 降至 0.042，pS 从 0.203 降至 0.031。
- greedy 的 pX、qX 和合法率同样高于 L。
- N 中图像接口通常比纯符号接口好；该差异在 cross_series 和 trend 上最明显。
- 这些是冻结协议之间的观测差异，不是训练效果或因果效应。
