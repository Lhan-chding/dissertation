# Qwen3.5-9B P1/P3 严格复核与下一步决策

日期：2026-09-09。依据、外部资料与证据层级见 `sources/SOURCES.md`。

## 0. 结论与执行顺序

**接受现有 N/L 结果作为“待原始产物审计的冻结策略基线”，不接受它们作为训练动态、SSVC 安全性或跨规模因果证据。** 不重跑整套 P3，不自动恢复 3B/7B，不换模型寻找预期现象。

下一步改成：**原始产物与估计量审计 → 推理/训练实现门禁 → 小型配对任务诊断 → 组构成及真实更新响应 → 两组短训练 → 再决定 SSVC。**

本轮主要模型保持 `Qwen/Qwen3.5-9B`，报告中的 revision 保持不变。主要训练对照先做 `X_BASE` 与 `X_VALID`；答案验证器差异先在固定 rollout 上计算，不马上扩成四组长训练。L 保持独立的 legacy-derived 诊断/迁移评估轨道，不与 N 混合训练。

## 1. 当前结果真正支持什么

### 1.1 直接支持的描述性结论 [F, S0 §§1–5]

| N 分组 | pX | v | qX | pW |
|---|---:|---:|---:|---:|
| duplicate / 图像 | 98.05% | 99.09% | 98.95% | 0.52% |
| duplicate / 纯符号 | 73.05% | 98.57% | 74.11% | 22.40% |
| cross_series / 图像 | 79.04% | 98.44% | 80.29% | 16.54% |
| cross_series / 纯符号 | 8.20% | 95.31% | 8.61% | 82.94% |
| trend / 图像 | 59.24% | 95.44% | 62.07% | 32.55% |
| trend / 纯符号 | 7.03% | 87.76% | 8.01% | 76.43% |

当前最明显的是“合法输出”与“精确恢复”的脱节，尤其是纯符号关系任务。若数据与 parser 审计通过，单靠移除非法输出无法消除这些 W 错误。

N 中图像相对于纯符号的 pX 差值，由表中数字相减得到：duplicate +25.00、cross_series +70.84、trend +52.21 个百分点。[C] 它们不是已估计的机制因果效应：图像提供了额外的真值信息，模型可能直接读图，也可能结合图像与约束修复。

### 1.2 不支持的结论

不能据此写“大模型解决/加重了 RL 奖励反转”“SSVC 已有必要性证据”“内部错误状态已修复”“参数规模导致了改进”。本轮只有一个模型的冻结评估，而且 L 不是历史 C3 精确复现。[S0 §§1,7]

当前 X 是输出世界报告经严格解析后等于真值，不是对模型隐藏状态的直接观测。

### 1.3 必须纠正的表述精度

报告对 L 的 S 解释为“合法但世界错误的输出更多”，方向不算错，但不够精确：**S 还必须满足由该错误世界执行得到的答案正确。W 同样是合法且世界错误，但答案错误。** 因而 S 上升不能直接替换成所有合法错误增加。

N 的 `truth_given_answer=0.9458` 与 `qX=0.5649` 条件事件不同：前者为 P(X|A)，后者为 P(X|V)。二者同时成立不矛盾。[S0 §3]

## 2. 当前报告最重要的缺口

### 2.1 P1 的 PASS 没有证明训练路径通过

报告明确写 `backward_calls=0`、`optimizer_updates=0`，且范围为真实 CUDA 冻结评估。[S0 §§1–2] 先前方案中 P1 本来还包含真实反向传播、LoRA 更新和保存恢复测试。[S1 §8, P1]

因此应拆分状态：`INFERENCE_PASS` 与 `TRAINING_SMOKE_PASS`。目前能从报告确认的是前者。不能据 17.6 GiB 的加载峰值推断训练峰值或 Adam 状态、梯度检查点、LoRA 适配均可用。

### 2.2 缺少逐题分布、样本独立性与区间

没有看到每个 prompt 的 nX/nS/nW/nI、copy rate、原始文本、错误位置修复情况、约束满足率、真实采样参数和 scene 配对键。也没有置信区间。

每题 16 次输出是同一题下的重复采样，不是 16 道独立题。N 的 288 个 prompt 若确为 144 场景×两接口，独立场景数量不能按 288 或 4,608 计算。这个配对结构要由 manifest 证明，不从旧计划自动继承。

对某题 0/16 个 X，单侧 95% 二项上界约为 17.1%；不能据此声称该题在模型中没有正确支持。[D: 1−0.05^(1/16)]

### 2.3 条件纯度的聚合口径必须命名

设每题有效率为 vi、条件纯度为 qi。以下不是同一个估计对象：

- `qX_pool = Σ wi*pXi / Σ wi*vi`：随机抽取题和输出之后，条件于输出合法的真值比例；
- `qX_prompt_macro = Σ wi*(pXi/vi)`：先为每题求条件纯度，再按题平均。

低有效率题在第一种口径下自动获得较小权重。当前表格在四舍五入精度上与第一种口径相符，但仍需查代码。SSVC 主保护量采用明确固定权重的 pX 与 qX_pool；逐题宏平均只作为另报诊断，零有效样本题不能填零。

### 2.4 N/L 组成不同：已有一个可复核的算术线索

在“每题恰 16 条采样、六组穷尽、普通四位小数舍入、无隐藏加权”条件下，穷举整数分母得到唯一一致的题数配置：[C；本包 `checks/SUMMARY_ARITHMETIC.json`]

| 轨道 | duplicate 两组 | cross_series 两组 | trend 两组 |
|---|---:|---:|---:|
| N | 各 48 题 | 各 48 题 | 各 48 题 |
| L | 各 16 题 | 各 36 题 | 各 36 题 |

这不是读取原始 manifest 的结果，必须由服务器数据确认。若确认，N 的家族权重各为 1/3，L 约为 18.18%/40.91%/40.91%。L 更偏重当前困难的两个关系家族。

按三个家族等权重重新计算 L 的 pX，约为 36.76%，而原始混合为 35.26%。这个约 1.50 个百分点的差异只说明组成效应的一部分，不能解释整个 N/L 差异，更不能被当作控制了接口、答案映射、长度等所有因素。

N/L 保留原始分布结果，另做同权重标准化；不要把它们强行合并为一个总准确率。

## 3. 低 S 不等于答案奖励已经没有问题

N 的 pS=3.10%，L 为 20.35%。L 的 collision/separating 组本来就与答案映射有关。[S0 §§3,5] 这些差异可能来自不同的答案纤维、运算、错误类型、题目组成及策略输出，不能只归因于模型减少了“取巧”。

原 N 方案的三个答案映射是 sum4、difference_pairs、range4。[S1 §4.5] 对恰一处错误的原观察：

- sum4 和 difference_pairs 的每个坐标系数都非零，直接复制原观察必然改变答案；
- range4 对某些非极值坐标的改变不敏感，复制原观察可能保持答案正确。

因此需要补报 operation×事件、copy×事件、h(observed)=h(truth)、错误位置是否处于极值及答案纤维的分层结果。可以对同一批已生成世界用不同 h 做离线重标注，测量标签对 h 的敏感性；这不是模型在新 operation prompt 下的实际行为。

真正决定 A 与 X 奖励比较是否可测的，不只是总体 pS，而是**同一个 prompt 的 K 个样本中，两套归一化优势是否真的不同**。这可以先用已有 bank 计算。

## 4. 本轮最重要的理论补强：把“有效率”拆成奖励实际起作用的组构成

以下为本次对固定 rollout 组的代数推导 [D]，不是已经观察到的 Qwen 更新动态。

### 4.1 全合法组中，validity 权重严格不起作用

rj(λ)=2·1[Xj]+λ·1[Vj]。若一个组中所有输出都合法，则 λ 给全组加同一个常数，减去组均值后消失。无论 λ 多大，联合 z-score 优势不变；ε>0 也成立。

目标分组很少产生 I 不代表它不受影响，因为其他分组产生的参数更新仍可迁移到这里。但它本身直接暴露于 validity 变化的机会有限。

### 4.2 没有 X 的组可能被辅助奖励单独激活

若组里没有 X，而有合法错误 B=S∪W 与 I，X_BASE 的该组奖励优势为零；加入 λ>0 后，B 获得正优势，I 获得负优势。

例如 K=8，一个组有 7 个 W 和 1 个 I。在 ε=0 时，任何 λ>0 都给 W 优势 1/√7，给 I 优势 −√7。把 λ 从 1 改成 0.01，并不会把这些优势缩小为 1%。

ε>0 时极接近 λ=0 才会平滑缩小；过渡尺度约为 ε/√Var(V)。因此**很小的原始奖励权重不一定意味着很小的归一化干预。** 这是下一步必须直接测试的 SSVC 可控性问题。

注意：优势为零只表示当前组的 reward gradient 为零；Adam 仍可能因历史动量更新参数。其他 prompt 的梯度也可能提升该组未采到的 X。不能由上述组内事实直接推出“整体 X 一定下降”。

### 4.3 连续权重的局部可调性主要来自三个奖励层同时出现

将 S/W 合并为 B，仅用于 X+validity 的奖励分析。设某组的经验比例为 x、b、i，且 x+b+i=1；v=x+b。

令 r̃=r−mean(r)，z=V−mean(V)，s²=Var(r)+ε²，则

    dA/dλ = z/s − r̃·Cov(r,V)/s³。

在 ε=0、Var(r)>0 下：

    Var(r) = 4x(1−x) + 4λxi + λ²vi，
    (1/K)||dA/dλ||² = 4xbi / Var(r)²。

推导：一般主权重 α 时，Var(r)Var(V)−Cov(r,V)²=α²xbi；对归一化向量求导并取均方得到 α²xbi/Var(r)²，取 α=2 即上式。

因此三个奖励层 X、B、I 都出现，才有非零的区间内优势方向敏感度。只有两个奖励层时，正的奖励间距通常被标准化抵消；λ=0 的并列边界另算。K=2 不可能同时出现三个层，正好与原计划的排序不变区间结论一致。

这不意味着真实神经梯度或 Adam 更新必然可调：不同样本 score 可以抵消，优化器还会进一步改变响应。它提供的是需要测量的“优势层可控性”指标，不是安全证书。

### 4.4 应新增的三个量

对固定 prompt 的真实概率 x=pX、b=pS+pW、i=pI：

    exposure_V(K) = 1−(1−i)^K−i^K；
    activation_without_X(K) = (1−x)^K−b^K−i^K；
    three_level(K) = 1−(1−x)^K−(1−b)^K−(1−i)^K+x^K+b^K+i^K。

它们分别衡量：组里能否看到合法性差异；辅助奖励是否在没有 X 的组里单独提供信号；是否有三层样本使 λ 在区间内真正改变优势方向。

不要把所有 prompt 的平均 p 代进这些非线性函数后称为精确实际组频率。

### 4.5 充分利用已有 16 次采样，无须先扩大 GPU 规模

对某题 bank 大小 n=16、正确数 nX，未来 K≤16 的无 X 组概率可估为：

    choose(n−nX,K) / choose(n,K)。

这是对 bank 所有 K 子集事件指示量的平均；原 bank 为同一冻结策略的独立同分布样本时，它对该题的未来 K 样本组概率无偏。其余组事件同样可用组合计数计算。

重叠子集不独立，不能把 choose(16,8) 当作独立组数计算极窄区间。K>16 不允许用该 bank 伪造新支持；有放回重采样只能命名为经验分布诊断。

仅供直觉：若将 cross_series/SYMBOLIC 的平均 pX≈0.082 当作每题相同，K=8 时无 X 概率约 50.4%；trend/SYMBOLIC 对应约 55.8%。实际逐题异质性会改变这些数值；由于 (1−p)^K 的凸性，真实组均值若已知，先平均再代入给的是无 X 概率下界。当前只是带采样误差的报告均值，不能冒充已观测频率。

## 5. 任务诊断：不把差结果自动归因于模型能力，也不擅自修成简单题

唯一解求解器必须独立于生成器；验证 C(o,cue)={x: Hamming(x,o)=1 且满足 cue 且在整数域内} 恰等于 {truth}。cross_series/trend 低分既可能是真实逆推困难，也可能是索引、约束表达、模板、采样或输出分割问题。当前汇总无法区分。[H]

建议固定一个不按模型表现筛选的 calibration panel，比较：原纯符号、同信息更明确的表达、移除下游运算提示、图像+原线索、仅读图、告知错误位置但不告知值。再在很小的子集区分更长输出预算与 thinking 模式。

这些都是诊断干预。提供错误位置改变信息量；仅读图改变任务；thinking 改变策略与预算。结果必须分别命名，不能合并到 P3 主曲线，也不能通过它们直接宣布模型内部机制。

发现真正的数据或实现错误，应版本化修复并建立新基线；只是提示改写提高成绩，不得删除原协议或据此篡改原实验结果。

## 6. 工程上应该先优化什么

报告中两个 forward/token 比例都恰为 2；按报告生成阶段秒数计算吞吐约 5.73 与 7.39 token/s。[C, S0 §2] 这是审计线索，不是“代码重复算了两遍”的证明：计数可能包括嵌套模块、生成与重算、合法的打分路径。

先按顶层调用原因计数，再考虑复用生成 log-prob、一次 teacher forcing 计算完整输出似然、正确的普通生成缓存和图像编码复用。保留 prefix recompute 作为数值参考，不优先追求 I4 自然隐藏状态分叉。

Qwen3.5 是混合结构，官方文档提示可选加速内核缺失会使用较慢实现。[W1] 本轮只核验已安装源码的实际路径；不因看到最新在线文档就升级环境或套用另一块 GPU 的设置。

786,432 像素和 768 视觉 token 在 patch=16、merge=2 时算术上相容，但实际 grid、缩放、视觉 token 数仍要记录；不能单凭请求参数断言实际执行值。[D/W4]

## 7. 为什么缩小第一轮训练矩阵

当前最重要的是判断 **X_VALID 相对于 X_BASE 的真实局部响应及短期结果**，而不是同时完成所有论文对照。四组×多种子、完整 SSVC、FSA、I4、完整核预测一起运行，会放大尚未解决的测量与实现问题。

本轮：两组×64 steps×B4×K8=4,096 条训练输出，seed=17；同初始化、同 prompt 顺序、相同优化协议、各自 on-policy 采样。冻结评估先读现有 bank，梯度审计可以离线比较 A/X 四种奖励。

N 是主要训练协议。L 是独立迁移/legacy-derived endpoint，允许不同的原始长度/模板；只做各自协议内部的 arm 差值，不将 N/L 总体差值当作训练效应。

后续若需要完整 verifier×validity 交互，再追加 A_BASE/A_VALID，并保持同等预算与样本构成。三种子确认属于下一轮，不由单种子良好结果自动代替。

## 8. 对 SSVC 的具体优化方向

第一，继续同时保护绝对正确率 pX 和条件纯度 qX，而不只保护 qX。第二，在选择 λ 前测量组构成、优势敏感度以及真实 Adam 响应；λ 网格若产生等价更新，不能把它们当成多个有效控制方向。第三，区分 SAFE/UNSAFE/UNKNOWN；测不出下降不等于安全。

相对安全比较必须是同一起点的 θ⁺(λ) 对 θ⁺(0)，并恢复相同优化器状态。还要保留独立 X_BASE 长期训练轨迹，二者不是同一个保证。

若验证了“λ=0 到很小正值几乎是激活开关”，原始 λ-continuation 可能缺少平滑控制空间。届时可另行研究联合更新增量的受控缩放，或组构成相关控制。但它们是新的算法族，需要重新定义实际优化器干预、预算和安全比较；本轮不悄悄加进 X_VALID 或原 SSVC。

在估计误差与曲率界尚未落实前，只做经验性离线筛选，不称为 certified SSVC。多个候选、多个群体和反复选择需要共同覆盖或独立审计数据，不能只给选中候选一个普通区间。
