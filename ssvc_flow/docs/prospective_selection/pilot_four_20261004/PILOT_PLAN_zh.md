# 首四条探索性小实验：分析前固定流程

2026-10-04。范围固定61001–61004，8原点，88个已观测H32分支；不追加GPU训练，不使用剩余开发/调参数据或最终T。已有端点曾被查看，本轮是开发探索性离线回放，不能称独立前瞻确认或无偏科学验证。

外层4折leave-one-lineage-out，同源32/96两个原点共同留出。每外层只将其余3条的标签交给拟合函数。内层再按lineage作3折（2条拟合、1条验证）：归一化、核尺度、系数、BestStatic只从inner-fit得到；Z0–Z3均使用原6个alpha[1e-4,1e-3,.01,.1,1,10]。按内层三个lineage等权的所选动作实际J决定alpha；距离最高分小于.001（浮点容差1e-12）优先更大alpha。随后用外层3条重拟合全部预处理/系数/BestStatic。

候选仅R0–R7；预测相对R0的H32 J差，沿用原核与历史/metadata权重，tau=.005回退BestStatic。先写每折选择与预测文件（函数不接收外层标签），再与已有H32端点关联评分。模型序列化中的FROZEN只表示该折模型对象不可变，不是主实验freeze.json，不放行最终测试。

输出四层32个held-out选择、全部候选预测、折内超参数评分、可复用模型、核诊断、8原点和4lineage配对收益，以及BestStatic、SAW_R4、GDPO_R4、DIRECT_REPAIR_R4对照。平均先在lineage内平均两个anchor，再四lineage等权。所有alpha外层结果另存为事后敏感性，不参与选择规则，不据此挑最好结果。regret仅对同原点已观测R0–R7最大J计算，是含噪开发描述。

稳定性包括：alpha改变时动作是否改变、预测最优和默认动作差、tau回退频率、Z3/Z2动作一致性、逐lineage/阶段差、拟合核谱。报告预测误差但不以R²选超参数。不以4个lineage做强显著性或泛化宣称；同源anchor、动作、生成样本均不是额外独立训练轨迹。

完整分析包应含原训练/评估JSON(L)原件、前置四层packet、全部任务/完成/核验回执、版本/协议、派生表、模型和复算脚本。基座、完整Adam/adapter张量与共享数据集大文件留服务器，只提供索引及覆盖说明；不得将该包称为可重训权重包。失败attempt保留、隔离，不作为成功数据重复计数。历史E单列，不用于本轮选择器拟合/调参/评分。
