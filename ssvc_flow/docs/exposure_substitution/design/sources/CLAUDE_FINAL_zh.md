## 4. 用数据对分歧点的核对与补充分析

三项核对都只读E\_test原始输出与训练曝光表，无新模型调用；均为揭晓后探索。

### 4.1 误触发的叶位置跟同结构供体的位置走

对“中心被污染、中心已修对、另改了叶”的输出，统计被改叶的位置份额；对同一臂同一单元，从discovery\_fit\_exposures统计该中心结构内叶污染训练目标（供体）的曝光份额。四单元平均：

| --- | --- | --- | --- |
| 4 | 1 | 0.01 / 0.01 / 0.00 / 0.33 | 0.00 / 0.00 / 0.00 / 0.00 |
| 4 | 2 | 0.53 / 0.52 / 0.49 / 0.33 | 0.57 / 0.53 / 0.54 / 0.46 |

读法：中心在第4位时，误触发在第2、3位的份额与供体份额几乎一致；中心在第3位时，误触发集中在中心之前的第2位，中心之后的第4位虽有供体却几乎不误触发（SINGLE除外，0.32）；第1位在任何臂都不误触发，GOLD\_ALL有第1位供体也不例外。跨81个“臂×单元×叶位”行，供体份额与误触发份额的相关为0.45——中等，主要由“前位叶”这一条件驱动。

它支持的说法是：误触发限定在“中心之前、且不在第1位”的叶，并按该结构内供体的位置分布出现。它不识别内部规则，也不排除训练顺序与共现的作用。

### 4.2 与GPT删改投影的一致性

按GPT的等价关系，“删改后可公开验证”当且仅当回答在污染位已写出正确值。对中心污染题，这等于我分类中的X与“中心修对但另改叶”之和：c4j4上父89.0%、O0 99.8%、MIX 72.7%、SINGLE 86.5%、GOLD\_ALL 55.7%，与GPT的投影率逐一吻合。两套分类互为检验。

### 4.3 前瞻叶题上的“值错”里有多少是选错操作数

见3.2节表：MIX 12.9%、SINGLE 7.1%用了另一片叶代替中心做减法，GOLD\_ALL 1.3%。这把“求值精度”再拆成“配对对象”与“算术”两层；后者（±2以内）各臂都只有约4%以下。

## 5. 下一步：可以冻结的方案

三方在“先识别原因、后试修正”上已经一致；下面是我建议冻结的版本，训练只有一个问题。

### 5.1 不训练先登记的四项

1. **固定三协议发现分配**（V选择，含无偏敏感性）作为发现基线；在新T′上验证。
2. **删改投影**作为推理期基线，与“验证双协议组合”并列：只用原回答、原关系与公开验证器，不枚举数值。它给出每个检查点“正确值已在、只需去掉多余改动”的可兑现量。
3. **未经R0的基座同协议探针**：同模板、同解析、全体分母，报严格X、合法率与合法条件X。
4. **E′与E\_confirm分开**：E′放大c2j2、c3j3、c4j4、c3j2、c4j2、c4j3等单元，用于诊断与设计选择，因此算开发集；最终确认另留未揭晓的E\_confirm；总分用预先固定的权重。

### 5.2 唯一训练问题：结构特异的曝光替换

采用GPT第10.3节的框架，补上读数与预期方向：

| 要素 | 冻结内容 |
| --- | --- |
| 起点 | 同父权重（S96、REP96），同fresh AdamW，256步，12焦点＋4回放 |
| 共同槽位 | 同一道题在同一step/slot；回放完全相同；不因集合变更重新shuffle |
| 可替换槽位 | 预先固定数量与位置，约等于一个单元内c4前位叶供体的曝光量 |
| 臂A | 可替换槽位放预定背景供体（与中心结构无关的已验证题） |
| 臂B | 同槽位放c4前位叶供体（c4j2、c4j3） |
| 臂C | 同槽位放匹配的其它中心前位叶供体（如c3j2） |
| 重复 | 每父两个优化种子，另加一对完全相同数据的换种子重复 |
| 主读数 | c4j4、c3j3、c2j2的X；供体对应叶题的X；总体O0 pX |
| 次读数 | 五因子链；混合锚点签名；删改投影可兑现率；duplicate保持 |

**预期方向（不作判据）**：若干扰是结构特异的，B−A在c4j4为负、在c3j3接近零；C−A在c3j3为负、在c4j4接近零。若两臂在两个中心上同向下降，说明“学会改前位叶”有跨结构扩散；若都不动，当前曝光关联更可能来自题目身份或训练路径。

它同时回答新成员的耦合警示：把某结构的前位叶加入训练，是否只伤该结构的中心。

### 5.3 之后再做：修正方法

- 当前学生在训练池上新采样，按M≥2与混合锚点签名筛负例；不用旧teacher bank，不回流E。
- 两臂对照：只用投影正例z做SFT；z＋成对偏好损失（正例z、负例同题原始y）。
- 读数包括全部失败质量（照抄、错位单改、正确值消失），不把多改减少本身当成功。
- GRPO另立阶段：先在训练池上做预更新采样、定义非法成本g、在优势层显式组合主辅两项。

### 5.4 观测器在这条线上的具体决策

若5.2支持结构特异，观测器就有了一个固定分配做不到的决定：**在把新发现的支持加入训练之前，预测它会伤到哪个受保护单元，并相应调整替换对象或份额。** 基线是忽略结构、只按比例分配的固定规则；μ（含签名与投影率）与ν（含结构内供体份额）是它的输入。它是否优于固定规则，仍要用新实例检验。
