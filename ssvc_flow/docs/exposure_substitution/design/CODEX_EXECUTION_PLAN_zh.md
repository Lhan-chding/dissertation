# SSVC 下一轮实施方案：结构匹配的训练曝光替换（SER-J2）

**版本：2026-10-07；本文件为下一轮唯一执行规范。**

本轮是受控的真实 Qwen3.5-9B 监督训练实验。目标是识别：在共同训练内容、时刻、输出目标和总预算固定时，少量供体题的关系中心位置改变，是否导致相应中心修复任务发生不同的收益或损失。不是新奖励算法的效果确认，也不是上一轮 MIX 的精确复现。

## 0. 结论与范围

最终保留的研究主线是：**语义行为概率 μ → 实际训练曝光与时序 ν → 可检验的干预响应 → 后续操作控制。**

本轮只识别一个干预：**把同一批训练槽位中的局部叶修复题，替换为同数值、同修复位置、同正确目标，但关系中心位于更后位置的题。**

### 本轮执行

- 2个既有父模型：S96、REP96；不重建源RL轨迹。
- 3个供体条件，3套真实不同的训练题序，合计18次SFT，每次256步。
- 每步11个共同题＋1个供体题＋4个共同回放题；即仍是12 focus＋4 replay。
- 新的同根配对评估；主读数是两个中心修复单元的差异性响应。
- 现有输出的删改投影作为独立的无模型调用后处理读数。
- 原始未加LoRA的同版本基座，只在诊断面板作一次冻结观察。

### 不进入本轮

不新增RL，不加入M惩罚／unlikelihood／DPO，不改变发现协议分配，不训练状态路由器，不跑梯度影响核，不做两档剂量，不重跑GOLD_MATCH换题矩阵，不扩大模型。后续修正方法的讨论保留，但不作为本文件中的可选训练分支。

**效应小、方向相反或区间宽不是执行故障，也不是追加剂量或改目标的理由。**

## 2. 最终设计比来稿进一步收窄的地方

Claude最后建议B使用c4j2/c4j3，而C使用c3j2。直接实施会同时改变**中心位置和被修复的位置组成**。另外，背景供体若用trend，会改变家族；若用中心污染题，会改变修复角色。

本轮作以下明确的设计修改，并不声称这些细节已经由此前实验验证：

1. **只固定污染第2坐标（j2）作为供体。** 两种后置中心c3、c4在该位置均属于“中心在目标后面”的情况。c4j3的扩展留到后续，不混入主比较。
2. 背景A使用c1j2：仍是cross、仍修第2位、仍是叶节点，但中心已经位于前面。
3. 同一供体根在A/B/C中保留完全相同的观察四元组、正确四元组、下游运算和规范输出token；只改变显示关系中哪一坐标是中心。
4. **A是有实际学习作用的参照，不是无影响／中性数据。** 主结构比较主要依靠B与C的接收单元交互；A用于界定相对损害和整体背景效应。

因此主张限于：**固定j2供体下，显示关系中心角色的训练替换总效应。** 不能凭本轮一次结果宣称解释了全部c4j2+c4j3历史退化。

## 3. 三个训练臂与一个完整例子

所有位置表述从1开始；代码索引从0开始。

| 臂ID | 供体结构 | 通俗含义 |
|---|---|---|
| A_LOCAL_C1 | c1j2 | 用已靠前的中心修第2位叶；有学习信号的匹配背景 |
| B_FORWARD_C4 | c4j2 | 用第4位中心修第2位叶 |
| C_FORWARD_C3 | c3j2 | 用第3位中心修第2位叶 |

例如，三个条件的观察都为`[17,91,8,14]`，目标都为`[17,43,8,14]`。

- A的关系：`a+b=60; a+c=25; a+d=31`。
- B的关系：`a+d=31; b+d=57; c+d=22`。
- C的关系：`a+c=25; b+c=51; c+d=22`。

三者各自的可靠关系＋单处修复约束，都有同一个唯一正确修复；但一般线性方程的完整解集并不相同。**这是匹配训练任务的结构干预，不是声称三套关系是同一方程组的等价行变换。**

关系行仍按历史O0渲染器的固定顺序生成，不额外随机打乱。输入的变量名、输出顺序与数值域都不改变。

供体是明确的生成器金标参照：其正确监督使用构造时的真值，并经独立单处枚举验证。各臂拥有同样权限。不把供体称为本轮新发现的自生成成功样本，不把本实验当作无需真值的部署算法。

## 5. 固定slot训练算法

### 5.1 每个实际更新

固定0起始槽位：

- slot 0..10：11条共同focus；
- slot 11：1条供体，A/B/C取同一根的不同关系中心变体；
- slot 12..15：4条共同回放。

总曝光：每臂2816 common＋256 donor＋1024 replay＝4096条目标序列。

供体占focus的1/12＝8.333%，占所有监督序列的1/16＝6.25%。这与历史**全部c4前位叶供体**的数量级相近，但本轮把诊断剂量集中给j2，不能说是复现历史单一j2的自然剂量。

**只用256这个剂量。** 不设看到结果不显著就追加的512档。128步检查点同时减少了共同训练、回放与优化时间，不能把它当作“其他均固定的半剂量实验”。

### 5.2 真正的重复来自不同题序

使用3个schedule seed：108701、108702、108703。每套改变共同题的排列、供体根的出现时刻与回放排列。每个block内，A/B/C的共同题、回放和供体根必须在同一step/slot。

两个父模型使用相同三套计划，以便比较条件差异。总计2×3×3＝18个训练作业。

仅换`torch.manual_seed`而不换任何输入顺序，在dropout=0、固定起点、固定优化器时不构成有意义的独立随机训练条件。**不额外浪费两条完整训练去实现这种空重复。** 同数据同slot的确定性恢复只做短技术检查。

每个block独立恢复父LoRA，fresh AdamW；block不是前一block的续训。三个block不是三个独立父模型。

### 5.3 不允许重新shuffle数据集来实现替换

旧 `SFTRuntime.bind_data()` 对每臂focus列表建立`ShuffledCycle`，会随着列表变化移动所有共同题。这次不能直接调用旧逻辑采样。

新增 `ExplicitScheduleSampler`：按已保存计划加载task_id，逐step取固定16槽。恢复时用已提交step与schedule版本恢复，不由当前数据集长度重新推算cursor。

必须逐行断言：同block同step，三个臂的common/replay task_id完全一致；donor root_id一致；donor target字节和EOS token完全一致；只有供体公开关系不同。

### 5.4 供体单独microbatch

为避免供体prompt长度改变共同样本的padding形状，固定五组前反向：

`common[0:4]`, `common[4:8]`, `common[8:11]`, `donor[1]`, `replay[4]`。

各组都按序列平均NLL求和，再除以**16**；不是各microbatch均值等权相加。三个臂使用相同分组顺序。这样改变供体长度不会改变共同样本的batch-padding形状。

共同输入固定不等于后续共同梯度固定：权重已经因供体分叉，这是要测的训练效应。不要把后续共同梯度不同视为违规。

## 6. 模型、SFT目标与数值设置

### 6.1 继承而不重置

- 基座 `Qwen/Qwen3.5-9B`，revision `c202236235762e1c871ad0ccb60c8ee5ba337b9a`。
- 父：S96（61001_t96）、REP96（61003_t96）。使用原父，不从MIX学生继续。
- BF16基座冻结；原96个语言MLP LoRA模块，rank8/alpha16/dropout0，LoRA参数FP32；视觉冻结。
- 不重新初始化LoRA，不堆叠第二个adapter。

### 6.2 精确目标

对第r条目标，令有效回答token（含唯一EOS）数为L_r：

`ell_r = -(1/L_r) * sum_t log p(target_t | prompt, target_<t)`。

每步：

`loss = (sum_{11 common} ell + ell_donor + sum_{4 replay} ell) / 16`。

因此focus总系数仍为0.75，replay为0.25。供体单独前反向不改变其1/16权重。

prompt token和padding label为-100；t−1位置logit预测t位置标签；只附加一个tokenizer主EOS；PAD=EOS也不改变padding必须被mask的规则。不截断prompt或目标，不把源回答里的多余格式作为gold target。最长总token沿用1024；越限是输入契约问题，不能截断后继续。

### 6.3 优化器

fresh AdamW：lr=1e-5，betas=(0.9,0.999)，eps=1e-8，weight_decay=0，grad_clip=1.0。第t步lr=`1e-5*min(t/8,1)`，之后常数；总256步。

新实验恢复时必须恢复**学生自己的**Adam、scheduler/step、RNG和显式schedule cursor；绝不能以fresh Adam继续一个中断的学生。`fresh`只发生在每次从父模型新分叉时。

有限的零梯度不等于故障；显式零梯度仍可能经Adam历史产生更新。缺失本应连通参数的梯度、非有限数或错误参数白名单才是技术故障。不要把0梯度替换成None并跳过步进。这个约定与旧runner的“任何0梯度即抛错”区分记录。

### 6.4 不宣称数值路径等价

上轮共同固定的是full-sequence SFT，原prefix/full-sequence的BF16差异仍然保留。本轮也使用full-sequence；donor隔离使microbatch分组改变，三个臂必须统一采用新分组。

只做一次目标mask、参数恢复、同分组重复和恢复桥接，不要求新路径与旧prefix梯度逐位相同。也不自动换FlashAttention、compile、量化、cache或包版本。

## 7. 对照与因果量怎样定义

令`p_{s,b,a,h}`为父s、schedule block b、臂a在新确认面板c_hj_h上的逐题平均X率。主保护中心h为3、4。

先对2父×3block等权。定义：

- `Delta4 = mean(p_B,4 - p_C,4)`；
- `Delta3 = mean(p_B,3 - p_C,3)`；
- **唯一主比较** `Gamma = (Delta4 - Delta3)/2`。

若同结构供体优先损伤自己的中心，预期Delta4<0、Delta3>0，因此Gamma<0。主区间采用双侧95%，不切换成单侧以获得有利结论。

**Gamma<0只表示相对响应具有这种结构交互。** 还需要并列查看B4−A4、C3−A3，以及相对父模型的变化，才能说发生了“损害”。一个臂变好较少不等于它比训练前退化。

预先登记四项次比较：B4−A4、C3−A3、B3−A3、C4−A4。c1j1、c2j2、全部供体叶单元和c4j3作进一步次级诊断。

这估计的是：**在本套共同背景、数据根、更新数和两个父状态下，替换供体关系结构的训练方案总效应。** 不等于历史MIX退化的完整因果分解，不等于已识别内部算术模块，更不等于已经估计可用于任意任务的K核。

## 8. 固定语义读数

### 8.1 主评分不变

O0输出严格完整JSON四整数、域0..99；不搜索子字符串、不使用真值重排、不在多个解析之间挑最好。length结束但完整合法JSON按旧规则评分，另记truncated；不能一律丢弃。

X=正确世界；S=合法错误世界但固定下游答案正确；W=合法且下游答案错误；I=其余。所有主概率以全部采样为分母。

### 8.2 编辑与值出现

解析后单列域合法性；合法部分记录M/B/L/F。必须检验M=B+L、F≤L，不写成B=M−1⇔F。

额外记录对全部输出定义的：

- `value_present = parse & (y[j]==truth[j])`；
- `value_present_but_not_X = value_present & not X`；
- `X = value_present - value_present_but_not_X`的逐计数恒等式。

它允许正确污染值与域外叶值共存，不把这种样本误叫合法多改。

### 8.3 混合锚点

公开签名：输出可解析，中心h相对观察被改动，且存在被修改的叶k满足`y[k] = b(h,k)-observed[h]`。由此该叶与最终中心不相容。这个签名不需要知道中心是否被污染或是否修对。

审计签名再增加`h==j`和`y[h]==truth[h]`，用于解释具体中心修复。两张表分开。

误改叶位置同时保存：P(某叶被改 & 中心正确)、P(某叶被改|中心正确但整体错误)、每回答修改掩码。不要只报告“所有误改中的位置份额”，因为总错误量也可能改变。

### 8.4 操作数签名

保存 wrong_partner、other_relation_constant、off_by_2、equals_hub 等全部匹配位，而不是用一个优先级消去重叠。真值只用于审计。不把数值碰巧相等称为已识别操作数。

### 8.5 删改投影

对同一回答，最多构造4个候选：仅保留回答提出的一个值，其余恢复观察。验证器只检查合法性、原关系全部成立和恰改一处，不读取真值，不枚举新数值。

它是独立后处理指标，原始X不变；单列验证次数和CPU时间。若唯一解前提成立，其成功当且仅当原可解析回答在污染位置已给出真值。这是可兑现质量诊断，不是新训练收益。

### 8.6 联合概率

保存`event × edit_mask × mixed_anchor_bits × value_present × parse/domain`稀疏计数与原始输出。边际可以重叠，不把copy/anchor/PTLC等比例相加当混合权重。不再扩写PTLC程序以解释本轮残差。

## 10. 精度、重复与阈值

主保护单元从旧的12题提高到128个独立数值根。并不要求把每个单元测到±1 pp。

对每个根先形成六个已训练条件的平均配对Gamma读数，再按128根做5000次cluster bootstrap，固定seed=107079，给双侧95%区间；每次重采样保留该根的全部臂、两个父和三个block。该主区间条件于实际训练的六个父×题序组合。

同时报告六个block的单独效应、父内平均、离散程度；额外的父内schedule重采样仅作为小样本敏感性分析，不把两个父推广成任意模型的总体结论。

量级规划：若根级配对差的标准差为0.3/0.5，128根的正态近似95%半宽约5.2/8.7 pp；80%功效可辨差约7.4/12.4 pp。标准差在新干预前未知，这只是规划范围，不是保证。8次采样增加的是题内精度，不能替代独立数值根与训练路径。

同一设计下，主Gamma的保守独立采样MC方差上界为`1/(4*n_draws*6*128)`，其95%MC半宽约1.25 pp；这不包含题间差异和训练随机性。必须与根bootstrap分开说明。

预设5 pp作为结果讨论的实际意义参考，不作为“通过/不通过”门槛，不用它删臂或自动追加样本。

次比较报告95%描述性区间；若使用“确认多个次效应”的表述，另列四项Bonferroni 98.75%区间。不要把描述性子群区间替代唯一主检验。

零成功题按0/n报告，并给Wilson/精确二项区间；不得报告概率严格为0。五因子链条件分母为0时为null，不补0或1。

**不设“必须回到85%”“下降不到20 pp就是偶然”“某参考单元未显著变化就证明不受影响”等标准。**

## 14. 结果如何解释

| 结果 | 能支持什么 | 不能支持什么 |
|---|---|---|
| Gamma负，B4−A4和C3−A3也负，供体叶改善 | 本固定训练替换有结构特异的收益—保持取舍 | 直接识别内部规则、普适干扰核或自动控制器 |
| Gamma负，但两个中心都不低于A/父 | 结构响应不同，可能只是相对增益不同 | 已发生绝对损害 |
| B/C在多个中心同向下降 | 有跨结构影响，简单局部保护假设不足 | “只伤同结构”成立 |
| 原始X降，value_present不降，投影增益增大 | 更多正确值与额外错误共存 | 正确值计算能力必然没变于所有题 |
| value_present也降 | 正确值出现与组合两层都可能参与 | 只惩罚多改即可修好 |
| 供体训练NLL未改善且叶题未改善 | 当前剂量/优化下该干预的学习作用弱 | 历史关联必定错误 |
| Gamma区间宽或不明确 | 本设计未分辨，保留范围与实际变化 | 结构效应不存在／模型不可学 |
| 主效果成立 | 为未来状态观测与曝光控制提供一个因果训练方案案例 | 已证明动态策略优于所有固定规则 |

E_DIAG、旧E、最新来稿的事后分层不用于改写E_CONFIRM主比较。新提出来的分析加上“探索性”标记，保留原结论。
