# 建模阶段 CPU 验收清单

“工程测试通过”与“低维模型足够好”分开。各条应填写实际测试名、日志位置、状态与失败原因。

## A. 表示和统计

- [ ] X/S/W/I 是互斥完整类别，执行故障不混入 I。
- [ ] 固定原始计数、题目/场景/接口/checkpoint 身份。
- [ ] 四概率/Helmert 可逆、距离保持；原始四概率与对比编码线性回归结果相符。
- [ ] v/q/s 的映射和所有零分母分支正确。
- [ ] 未观察到 X 和“真实 P(X)=0”分开。
- [ ] S 结构为空与有限采样未观察到 S 分开。
- [ ] 频率 MLE 与嵌套 MLE 映回等价。
- [ ] Fisher 恒等式/有限差分在 FP64 内部点通过。
- [ ] 计数区间与条件区间按实际分母计算；分母零返回未知。
- [ ] 群体 q 使用加权概率之比，不是逐题 q 平均。
- [ ] simplex 投影前后结果分别保留，不悄悄删负概率预测。

## B. 微型系统与优化器

- [ ] 72 train / 36 probe base scenes，三家族、两接口无泄漏。
- [ ] 唯一修复与执行器独立核验。
- [ ] 每题 16 个候选，候选顺序改变不影响概率和梯度。
- [ ] 44维输入不包含隐藏标签/changed_index/类别。
- [ ] EVIDENCE_PROXY 明确不是图像模型。
- [ ] 网络 737 参数，固定初始化、float64、CPU。
- [ ] 联合归一化 epsilon/总体方差正确，零组不重采。
- [ ] toy loss 为单步 finite action 的 B*K 分母，未冒充 64-token VLM loss。
- [ ] 全零梯度保留 Adam 更新，与 None 语义区分。
- [ ] 同起点分支完全恢复参数/Adam/RNG，主轨迹不被污染。
- [ ] exact p 与 sampled counts 使用分离的视图和随机种子。

## C. 可识别性与维度

- [ ] W1–W6 的观测相同/响应不同项可独立复算。
- [ ] 复制或共线候选不提高数值秩。
- [ ] Q 只用 local fit 更新，未读 test bank 的 d。
- [ ] 校准矩阵不错误中心化而删除共同动量方向。
- [ ] `r_cap` 与每锚点实际 r、k 同时记录。
- [ ] ridge/维数规则只用 selection seeds，test 前冻结。
- [ ] 有全 J、低维 J、拟合响应和真实有限步四级误差。
- [ ] 不从有限校准子空间推出正交方向无影响。
- [ ] B0–B6/O0–O1 都有实际结果或明确技术原因，未无声删基线。
- [ ] B4/B5 作为经典低秩工具/候选选择规则，不标成已证明创新算法。

## D. 跟踪、界和评估

- [ ] 固定 H=1/2/4/8/16，窗口内不刷新 J/U 却声称廉价。
- [ ] 净位移与累计路径两个界都测试。
- [ ] 已知解析 L 的覆盖检查通过。
- [ ] 非线性模型的经验误差带不标记为全局保证。
- [ ] 每步中间误差保留，不只比较端点。
- [ ] 测量噪声/训练随机性/表示误差分开实验。
- [ ] 同 seed 两臂及所有分支为同一顶层统计簇。
- [ ] 低信号样本量和未知状态报告完整。
- [ ] 校准、方向估计、JVP、推理、I/O 成本全部计入。
- [ ] 原始预测和输入哈希在测试揭盲前冻结。

## E. 实施、来源和交付

- [ ] 独立 worktree；未修改现有正在运行实验的源文件/配置。
- [ ] smoke 后测得 core 预算，超限按方案停止。
- [ ] 真实数据只读；未用范数/哈希伪造更新向量。
- [ ] 新 S1 产物状态以实际完成证据核实，未沿用旧缺口判断。
- [ ] 新测试与相关旧测试实际运行并存日志。
- [ ] reference tests 不冒充完整建模实验。
- [ ] 最终 modeling_status 可以为 NO_ACCEPTABLE_R/UNIDENTIFIED。
- [ ] 没有新 Qwen 调用、sbatch 或在线 SSVC。
- [ ] 最终报告包含明确的表示/维度选择与失效范围。
