# 建模资格实验：一页结论

**精确概率条件下存在可用的短程预测结构；当前有限采样局部回归尚未同时达到可辨识性、成本和适用窗口要求。**

## 可保留

- 固定题目身份及X/S/W/I计数；Helmert三坐标作为无冗余线性拟合坐标；(v,q,s)作为解释视图。
- 在固定数据、固定初始化的小系统里，付费局部校准的一维模型对整体单步响应NRMSE为0.2334，优于零响应1.0000、普通日志0.7159、更新PCA0.3123。
- 全Jacobian oracle的NRMSE为0.02643；当前短步变化并非因强非线性而完全无法预测。

## 必须收紧的结论

| 核心问题 | 独立复算 | 研究意义 |
|---|---|---|
| 能否区分辅助操作？ | exact r1对joint1−joint0的群体pX/v差异NRMSE为0.9652/1.0169 | 总体变化拟合好不等于能支持操作选择 |
| 方向是否稳定可估？ | n16/64/256方向与exact方向夹角中位数约83.0°/82.1°/82.7° | 有限样本同时破坏方向与系数估计 |
| 消融是否有效？ | 七项关键消融全部r0、NRMSE1 | 不能从它们判断表示、输入方向、校准预算的价值 |
| 每4步测一次是否可靠？ | exact r1 H4聚合达标，但25%的60个窗口至少一处超过预测门槛 | 不是逐轨迹保证；失败指预测资格，不是任务安全事故 |
| 是否节省成本？ | 原口径25面板，已验证短窗4；逻辑别名可减成本但未建立合格交集 | 暂无可运行检测频率 |
| Qwen是否低秩？ | 每bank选定子集仅一或两个不同位移，秩1/2 | 不能据此认定其语义动态维数 |

## 下一阶段最小动作

**只读现有数据：**分开总体响应与候选差异评分；取得其余59条轨迹原件；使用既定非零配置恢复退化消融；补齐明确的工程回归缺项。

**需追加CPU预算：**分别检验方向估计与系数估计；显式建模共享起点造成的相关噪声；先达到预定候选差异精度，再延长窗口。所有新选择在独立验证前标记为事后开发。

**Qwen/GPU边界：**不因exact r1通过就追加训练或上线SSVC。真实桥接需要匹配的观测、独立锚点和有限预算资格。
