**N4 已实际完成，独立数值复算通过；两个冻结代理的预测 NRMSE 通过，但绝对误差分辨率不通过。当前没有达到全部要求、可推荐使用的局部代理。**

| 决策项 | 推荐与边界 |
| --- | --- |
| 目标 | 直接测量同一 bank 的候选差异 `joint_1 − joint_0`；保留 `no_x_off_1 − joint_0` 及一致性差异作为次目标 |
| 当前 toy 的观测方式 | `D_KNOWN_EVENT_LOGP`：已知完整 X/I 动作集合时，直接评分并求事件概率差 |

## 3. 新 locked-test：预测通过，分辨率失败

pX 是 X 事件概率，v=1−p(I)。NRMSE用真实候选差异能量作分母；零能量保持无信号状态。主门槛分别为 pX/v NRMSE≤0.75，绝对误差q95≤0.000125。

| 冻结配置 | pX NRMSE | v NRMSE | pX误差q95 | v误差q95 | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| C5 / O_LR_ORIGIN / n64 / fit2 / r4 | 0.617471 | 0.485930 | 0.000360527 | 0.001328021 | 预测PASS；分辨率FAIL |
| C6 / O_LR_MIX / n64 / fit2 / r4 | 0.611913 | 0.486467 | 0.000355042 | 0.001325705 | 预测PASS；分辨率FAIL |

两者的 pX q95 约为门槛的2.84–2.88倍，v q95约为10.61–10.62倍。程序字段 `science_status=PREDICTION_PASS` 只对应预测门槛，不能解释为整体建模资格或安全认证通过。

联合观测必须保留共享baseline、候选之间、共同packet和exact alias的协方差；同bank候选差异中的共同起点项代数消去。原N1联合协方差/估计器见证与独立复算保留，不能用边际标准误拼成独立对角矩阵。

**N4没有给出C5/C6方向投影相对于C3/FULL的额外精度收益。** 同观测、同n、同alpha/eta、同fit2时，对应C3/FULL与C5/C6的聚合误差指标在浮点精度内一致。当前k≤4而r上限为4，不能据此包装成更有效的新低秩表示。

C5/ORIGIN与C6/MIX之间同时改变了方向规则和观测方式，二者差异也不能单独归因于联合协方差。N4未新增C2对照，协方差处理的对照证据仍来自原N2；本轮不声称新的协方差因果优势或新颖性。
