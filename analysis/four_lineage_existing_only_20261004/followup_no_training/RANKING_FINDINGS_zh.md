# 无需新训练：现有动作排序有多稳定？

本次用已保存的H32逐题X计数完成条件重采样；同时复用上一轮固定8/8拆分，检查“在一半输出选出的带噪赢家”在另一半输出上的表现。没有新增模型输出、训练seed、选择器拟合或超参数搜索。R0–R7与11动作的描述分开，原折内BestStatic始终固定。

## 1. 方法与边界

每原点的11动作×144题均有16条已有输出。对每个动作/题，从这16个二元X标记内有放回抽16次；充分统计量实现为 `Binomial(16, X_n/16)`，与从已有二元记录重抽完全等价，不是在调用模型生成新回答。固定seed=20261004，每原点10,000个联合重复，共80,000个原点重复；两候选集合复用同批重复，不重复计数。

重采样条件于当前训练状态、当前固定题目和观察到的经验分布，假设固定题/端点内及不同端点的输出可按独立抽样处理。不包含新训练seed、lineage总体差异或最终T不确定性。尤其0/16和16/16保留退化，不能生成从未见过的成功或失败。下表的2.5%–97.5%分位数仅是**条件重采样分布范围**，不是总体置信区间或“某配方真实最优”的后验概率。展示的top/runner由全样本事后确定，这些范围也不是经过赢家选择校正的置信区间。

## 2. 前两名差距有的可辨、有的很脆弱

下表用R0–R7，遇并列按字典序指定展示的前两项；完整最大值集合另存，不抹去平局。单位pp。

|原点|原观测第一/第二|观测差|固定面板MC标准误|条件重采样2.5%–97.5%|

|61001_t96|R3/R0|0.5642|0.1465|0.2604至0.8247|

|61003_t32|R3/R4（并列）|0|0.2790|−0.5208至0.5208|

MC标准误使用各题 `p(1−p)/(16−1)` 的独立两动作方差相加，再乘固定题权重平方；重采样使用经验分布，二者不是完全相同的方差估计，故不要求分位数等于正态近似。数据见 `ranking_margin_summary.csv,candidate_set=R0_R7`。

61001_t96中，R3在并列最大值均分计数后占99.9633%的条件重采样首位；相对原BestStatic R4的观测差+0.5642 pp，重采样范围+0.2604至+0.8681 pp，99.96%重复为正。这说明**这一个现有原点的动作差不能简单归成完全无法辨别的抽样波动**；不证明新训练重复、其他原点或最终测试会复现它。该原点保存选择器却选R4，因此“所有未捕获机会都因评估排序不可辨”也不足以解释本批记录。

61003_t96则不同：R7相对第二名R1只领先0.0434 pp，首位均分频率约55.20%。但相对较低的BestStatic R3，R7仍领先0.1302 pp，96.4%重采样重复为正。**第一名身份的不稳定与能否胜过一个指定基线是不同问题**。逐动作对R0/BestStatic的分位数、正/零/负频率和最大值集合频率见 `conditional_ranking_stability.csv`；不根据这些频率部署或宣布胜出。

## 3. 在一半挑到的优势，能否在另一半保存输出上维持？

从既有半表取8条输出上的最大值，平局则等权平均所有并列者在另一半的pX。再交换两半。原BestStatic不重算，不使用另一半挑赢家。以下每格为4原点×2方向均值，单位pp；两方向共享输出，不能算8个独立原点。

|候选集合/阶段|选择半赢家−原BestStatic|同一赢家在另一半−原BestStatic|两半差值|
|---|---:|---:|---:|
|R0–R7/早|+0.42318|+0.05425|0.36892|
|R0–R7/晚|+0.36892|+0.28212|0.08681|
|11动作/早|+0.66189|+0.16819|0.49371|
|11动作/晚|+0.49913|+0.44488|0.05425|

这直接量化本次固定拆分中“选最大值”与反向半表表现的落差。早期差距更大，不能把原点带噪最大值直接当选择收益。晚期平均保持较多优势也不构成新选择器验证：动作是在同一原点的部分端点结果上事后挑选，实际前瞻选择时不可用。此表不评估Z2/Z3的泛化，仅诊断既有端点的排序稳定性。全部32行见 `existing_half_winner_transfer.csv`。

## 4. 哪些题左右第一、第二名？

`ranking_margin_prompt_contributions.csv`固定1/144权重，精确将第一−第二的差拆到144题，未删题重算目标、未用终点标签挑前置特征。晚期各原点非零差只在混合题；61001_t96和61004_t96前两题占全部绝对margin质量100%，61002_t96为85.714%，61003_t96为66.667%。早期前两题仅占13.95%–35.71%。这把“晚期少数题决定排序”定位到逐原点、逐题与正负抵消，不是提出修改评价目标。

## 5. 这次解决了什么？

已经分清：哪些原点的当前排序对输出重采样脆弱，哪些现有优势在该条件下较稳定；按一半取最大值有多少优势未转移到另一半；前两名差距由哪些固定题贡献。尚不能确定真实训练重复下的最优动作或各来源噪声的因果份额。旧4条lineage仍是4条，不被80,000次计算扩成新实验。

复现：`python3 analysis/four_lineage_existing_only_20261004/followup_no_training/ranking_stability.py --repetitions 10000 --seed 20261004`，需NumPy。实际命令、输入、计数与限制见 `ranking_scope.json`。
