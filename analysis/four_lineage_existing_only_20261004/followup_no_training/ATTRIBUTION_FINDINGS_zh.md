# 不重新训练即可回答：Z3 与 Z2 的保存预测为什么几乎相同？

本次已完成精确代数归因。两者均值完全相同；在现有保存系数下，Z3 新增修复项与旧奖励项减权产生很强的数值抵消。相对折内 BestStatic 的预测变化最大只有 **1.9147836800×10⁻⁶ pX**（0.000191478 个百分点），8 个原点的全部动作排序均不变。这解决了“现有预测数值上如何抵消”的问题，不能据此断言修复信息无用、修复与奖励信息冗余，或修改核权重就会增加选择收益。

## 1. 归因对象与恒等式

仅使用原始保存的 Z2、Z3 模型及其前置观测包。记 `p2 = μ2 + k2 β2`、`p3 = μ3 + k3 β3`。`k` 是当前留出原点对 6 个训练原点的核行向量；`β` 是已保存的 6×8 系数矩阵。两条精确路径是：

```
p3 − p2 = (μ3 − μ2) + (k3 − k2) β2 + k3 (β3 − β2)  [forward]
p3 − p2 = (μ3 − μ2) + (k3 − k2) β3 + k2 (β3 − β2)  [reverse]
```

这里只做乘法和减法，没有求解新的 β、训练混合模型、搜索新 alpha、搜索核权重，亦未评估任何新方案的收益。第二条路径展示分项归因不唯一；两条路径总和相同，不能把任一路径当因果效应。

4 折均验证训练原点及顺序相同，均值相同，共同组件的保存尺度、标准化参数、训练与查询 embedding 相同；保存 alpha 均为 10。因此 `k3 − k2` 可按原有参数准确拆为：

| 分项 | Z2 保存权重 | Z3 保存权重 | 本次计算 |
|---|---:|---:|---|
| current reward | 1 | 0.5 | 原有当前奖励核行向量的 −0.5 倍 |
| history reward | 0.25 | 0.125 | 原有奖励变化核行向量的 −0.125 倍（相对未加权组件） |
| repair | 不存在 | 0.5 | 保存的当前修复组件 |
| repair_history | 不存在 | 0.125 | 保存的修复变化组件 |
| nuisance | 0.25 | 0.25 | 差为 0 |

每个组件分别使用其自身原保存尺度，未重新归一化。`history` 是当前与先前 embedding 的差，不能把它当成单独先前观测的核。repair 与 repair_history 的尺度不必等于 reward 的尺度；具体尺度逐折列于 `attribution_scope.json → fold_checks`。

## 2. 相对 BestStatic 的 56 个有效动作对比

在 8 原点×8 动作中，排除每原点 BestStatic 自身，剩余 **56 个动作对比**。表中每个数均是预测 pX 单位，未乘 100。将 current 与 history 两个减权项合计为 `reward_reweight`，将 repair 与 repair_history 合计为 `repair_added`：

| 汇总量 | forward（乘 β2） | reverse（乘 β3） |
|---|---:|---:|
| 两组项符号相反 | 56/56 | 56/56 |
| Σ绝对 reward 减权项 | 3.3990641330×10⁻⁴ | 3.3995414604×10⁻⁴ |
| Σ绝对 repair 新增项 | 3.3191562574×10⁻⁴ | 3.3195563018×10⁻⁴ |
| Σ绝对两组项合计 | 2.8077825900×10⁻⁵ | 2.8080275722×10⁻⁵ |
| 按绝对值总和定义的抵消比例 | 95.820645% | 95.820826% |
| β 变化项最大绝对值 | 6.3211770164×10⁻⁸ | 6.3442910893×10⁻⁸ |
| 完整预测变化最大绝对值 | 1.9147836800×10⁻⁶ | 相同 |

抵消比例的明确定义为：`1 − Σ|reward_reweight + repair_added| / Σ(|reward_reweight| + |repair_added|)`。这是对这批保存预测分项的描述比例，没有置信区间，也不是信息冗余比例或性能损失比例。分项先以原动作减去该折 BestStatic 的对应分项，再进行上述汇总。β 变化项另列，没有混入该抵消比例；均值与 nuisance 差严格为 0。

相对 R0，64 行中 8 行 R0 自身恒为 0，forward 的其余 56 行有 52 行两组项符号相反，抵消比例 95.683677%；完整预测差最大 **2.0993346107×10⁻⁶ pX**。两种基准回答不同问题，不能混用分子分母。

证据：`saved_Z3_Z2_attribution_summary.csv` 的 `origin=ALL`、`baseline=BestStatic/R0`、`path=forward/reverse` 四行；逐动作原项见 `saved_Z3_Z2_attribution.csv` 全部 64 行。

## 4. 已解决与仍不可识别

**无需新训练已经解决：**Z3 与 Z2 的均值、共享尺度、共享 embedding、训练顺序是否一致；旧 reward 是否恰好减半；差异究竟来自哪几个代数项；新增 repair 与减权 reward 是否数值抵消；抵消后剩余预测变化多大；β 变化项大小以及所有动作排序是否变化。

**本次仍不能解决：**修复信息在不同表示或学习器下是否能改善选择；保持 reward 权重不变单独加入 repair 的因果收益；减小 alpha 的未运行值是否有效；前置修复信息与端点噪声各自贡献多少。原因是现有 Z2→Z3 同时改变表示、组件权重和保存 β，纯代数分解不构成控制变量实验。两条分解路径只说明“数值抵消在这两种路径下均明显”，不能消除上述不可识别性。
