# 哪些问题不用新训练就能分清？本轮已完成的答案

2026-10-04。本轮承接上一轮已有数据边界：新训练、新模型调用/评分、新样本、选择器重拟合、超参数搜索、GPU提交和最终T读取均为0。只复用已交付计数表与保存模型，新增精确代数分解及明确标记的统计重采样。

**有四类诊断可以直接解决，现已完成。最实质的新增结论是：晚期主要失败确实从未修对原错误坐标；Z3新增修复项又被reward减权项高度数值抵消。排序噪声只解释一部分现象，不能把所有未捕获动作差都归为噪声。** 这缩小了后续需要区分的范围，但没有验证修改训练或选择器后的新收益。

## 1. 主要错误到底卡在哪一步？——已经分清

以前仅知道“28题在所有44个晚期端点均未见X”，尚可能有两种解释：原错误坐标始终没修对；或原错误坐标修对了，却破坏其他坐标。

原保存语义规定：F是原错误坐标是否修对的0/1指标，X当且仅当F=1且B=0；I的F/B/M无定义。对已有计数进行完整互斥分解，得到：

|晚期28题中的输出类型|条数|
|---|---:|
|I：非法输出，F无定义|2,183|
|copy：复制原污染记录|9,150|
|合法、进行了修改，但原错误坐标仍未修对|8,379|
|原错误坐标修对、但破坏了其他坐标|**0**|
|合计|19,712|

因此，**17,529条合法输出中F=1为0**，而不是把2,183条I也当F=0。针对这28题，可排除“主要已经修好原坐标，只差保护其他坐标”的解释；记录中的瓶颈更早，在正确修复原坐标之前。也不能一概说模型只在复制，因为8,379条已修改但仍修错。

晚期全部“F=1但B>0”的175条错误都位于另外8道混合题，只占全部晚期错误175/21,672=0.8075%。所以仅解释这类额外破坏，无法解释本批主要错误。这里没有把175条假定成可自动兑现的收益，也没有宣称未来不可能修好那28题。

证据：[失败结构说明](FAILURE_FINDINGS_zh.md)、[跨动作汇总](failure_pooled_summary.csv)中`H=32,stage=late`及`posthoc_H32_class=unseen_X/mixed`；完整逐题/群体行见[failure_decomposition.csv](failure_decomposition.csv)。训练无X组与评估题仍只做家族/接口/阶段对应，不作逐题因果连接。

## 2. 配方差究竟增加了修复，还是增加了破坏？——已经代数分清

对保存计数有恒等式：

`X = F1 − F1damage`，所以 `ΔpX = ΔF1事件质量 − ΔF1damage事件质量`。

这里的事件质量使用全部输出分母，F条件均值使用有效输出分母；两者不混用，I的F没有补零。

|阶段/动作，相对R0|F1计数变化|F1damage计数变化|X计数变化|ΔpX|
|---|---:|---:|---:|---:|
|早期 R4|+79|+29|+50|+0.5425 pp|
|晚期 R3|+13|+13|0|0 pp|
|晚期 R4|+8|+18|−10|−0.1085 pp|
|晚期 DIRECT_REPAIR_R4|+9|+5|+4|+0.0434 pp|

每行每动作分母均为4原点×144题×16=9,216条已有输出；不是配对回答逐条发生的转移，也不是因果干预效果。晚期R3“pX没涨”不能解释成“完全没有增加正确修复”，而是观察到的正确修复事件增加与额外破坏增加在计数上抵消。

全部11配方、每原点、六群体及H32事后类都已分解，且仍保留原pX目标。[failure_delta_decomposition.csv](failure_delta_decomposition.csv)给同分母差分，[failure_action_tradeoffs.csv](failure_action_tradeoffs.csv)并列原有C/copy/坐标/B/M指标；没有为追认胜出构造综合分。

## 3. 为什么Z3与Z2几乎给出相同预测？——数值机制已经分清

对保存模型精确展开：

`p3−p2 = (mean3−mean2) + (k3−k2)β2 + k3(β3−β2)`。

四折训练原点顺序、共同组件尺度与embedding一致，均值完全相同；Z3将当前reward权重从1降至0.5、history reward从0.25降至0.125，同时增加repair及repair_history。使用保存的β，不求解任何新系数，可以把核变化分项准确算出。

结果：相对原折内BestStatic的56个非自身动作对比中，**reward减权项与新增repair项56/56符号相反**。按`1−Σ|两项之和|/Σ(|两项|)`定义的数值抵消比例为95.8206%；β变化项另列。抵消后的完整预测变化最大仅**0.0001915 pp**，8个原点的全部动作排序均不变。反向分解路径结果相近，抵消比例95.8208%。

这已解释“当前保存模型的数值项为何变化极小”。但**95.82%不是信息冗余率，也不是因果贡献或性能损失率**。两种分解路径展示代数归因不唯一；不能从此直接断言保持reward权重再加repair就有收益。那是未验证的不同模型。

证据：[代数归因说明](ATTRIBUTION_FINDINGS_zh.md)、[逐动作归因](saved_Z3_Z2_attribution.csv)、[归因汇总](saved_Z3_Z2_attribution_summary.csv)中`origin=ALL,baseline=BestStatic,path=forward/reverse`。128条重放值分别与各自原保存预测逐位一致，恒等式最大残差5.65×10⁻¹⁹以内。

## 4. 排名差到底是不是噪声？——已分清条件稳定性，不能推广为总体答案

从每个动作/题的16条已有二元X中有放回重抽16条；这等价于`Binomial(16,X_n/16)`。每原点10,000个联合重复，共80,000个原点重复，seed=20261004；11动作与R0–R7复用同一批计算。它不是新回答、新训练seed或新实验。

计算固定当前训练状态与144题，假设输出在固定题/端点内及跨端点按独立抽样处理。0/16与16/16仍退化，因此不会创造未观察到的成功/失败。2.5%–97.5%范围是**条件重采样分位数**，不是总体置信区间、后验概率或对观察后赢家作过选择校正的置信区间。

两个不同例子：

- **61001_t96**：R3相对原BestStatic R4的观测优势为+0.5642 pp，条件分位范围+0.2604至+0.8681 pp；99.96%的重复为正。它的保存选择器仍选R4。因此不能用“现有端点差都完全不可辨”解释全部未捕获机会，但这仍不保证其他训练重复或最终测试会复现该优势。
- **61003_t96**：R7相对第二名R1仅领先0.0434 pp，条件分位范围−0.1736至+0.2604 pp，首位均分频率约55.20%。这里“究竟谁第一”很脆弱；与对指定BestStatic是否有优势是不同问题。

八个原点全部结果见[排序说明](RANKING_FINDINGS_zh.md)与[逐动作条件稳定性](conditional_ranking_stability.csv)。晚期前两名差距来自少数题；[逐题margin贡献](ranking_margin_prompt_contributions.csv)只做固定权重恒等分解，没有删题换目标或据端点挑选前置特征。

另外复用原8/8拆分，在一半选最大值、另一半评价同一赢家，平局等权平均，交换两半再汇总。原BestStatic不重算：

|候选集合/阶段|选择半相对BestStatic|另一半相对BestStatic|
|---|---:|---:|
|R0–R7 / 早|+0.4232 pp|+0.0543 pp|
|R0–R7 / 晚|+0.3689 pp|+0.2821 pp|
|11动作 / 早|+0.6619 pp|+0.1682 pp|
|11动作 / 晚|+0.4991 pp|+0.4449 pp|

这是这一次固定拆分的事后诊断，两方向不独立；不是新选择器的前瞻验证。它进一步说明“带噪最大值”不能直接当可实现收益，尤其早期。证据：[existing_half_winner_transfer.csv](existing_half_winner_transfer.csv)。

## 5. 哪些已解决，哪些仍不能仅用现有记录解决？

|问题|本轮状态|答案边界|
|晚期主要失败是原坐标没修对，还是修好后破坏？|**已解决：观察定位**|28题17,529条合法输出中F1=0；不等于未来不可能修复|
|动作差由正确修复与额外破坏怎样构成？|**已解决：计数恒等分解**|逐题至阶段全部给出；不作回答间因果转移|
|Z3与Z2数值上为何几乎不变？|**已解决：保存模型代数**|新增与减权高度抵消，完整排序未变；非因果权重归因|
|哪些原点当前排序脆弱，哪些较稳定？|**已解决：条件性诊断**|固定面板/状态/经验支持；不涵盖新训练seed或总体|
|改候选动作、训练支持后能否修好28题？|现有记录不能证明|没有相应干预结果；计数缺正例不能识别唯一成因|
|保持reward权重单加repair，或改学习器能否增加真实选择收益？|现有记录不能证明|未重新拟合；代数分项不代表新方案的验证收益|
|噪声、表示、学习器分别造成多少因果损失？|现有记录不能唯一分配|当前设计存在混杂，4条lineage不由重采样扩增|

因此，讨论可以具体收敛到两处：候选动作/支持层应关注**如何出现正确修复原错误坐标的对比**；表示/学习器层应区分**保存核项的抵消与真正可泛化的动作响应信息**。不必再把主要时间花在“是不是都修对后又弄坏”“是不是tau回退”“是不是修复信息根本不存在”这些已有证据能够排除的解释上。如何改动能带来新收益仍需相应验证，不能由本轮分析代替。
