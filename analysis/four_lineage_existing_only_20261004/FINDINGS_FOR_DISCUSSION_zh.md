# 讨论页：当前零选择增益，先区分什么？

2026-10-04｜4条开发lineage、8原点｜只分析已有数据，未读取最终T

**结论：零增益并非“什么信息都没有”。现有动作对晚期主要错误的突破未被观察到，同时保存选择器强收缩。两者与噪声、表示混杂并存，不能指定唯一原因。**

**已排除的极端解释**

- 仅由tau回退导致：32/32原选择的预测第一名已是折内BestStatic，回退0；256条保存预测代数重放误差0。
- 所有动作完全相同：观察到非零差异；但逐原点带噪最大值不能算已实现的选择收益。
- 修复信息完全由reward决定：P同题同reward内存在不同F/B/M。晚期多结构覆盖306/9,216输出，不能说信息不存在。
- 晚期所有训练信号消失：无X组仍有B/C差异和W/S正优势；缺正确修复正例并不等于零信号。

**有直接支持的定位**

- 晚期28/144题在44端点下均未见X，贡献19,712/21,672错误（90.956%）；全是symbolic cross_series/trend。动作pX差全部来自8混合题，绝对差质量前两题占84.44%。
- 晚845个无X训练组四个时间窗均未观察到F=1；其中39组全I、F无定义，806组有F观测。早125个含F无X组集中前16步，但与题目排程混杂。
- Z2/Z3最大状态修正约0.021 pp，edf约0.140；内验证效用完全平局38/48。已有弱alpha虽改排序，仍未显示稳定选择收益。
- reward/repair核X–X相似度项约81.8%/80.3%，状态差异主要在两个符号群体；Z3另将reward权重减半，增量信息比较有混杂。

**仍不能区分**

动作响应是否缺乏稳定状态差异、修复结构是否与可选收益无关、信号是否被表示/强收缩压低，以及观测噪声各贡献多少。4条lineage不支持确定的总体显著性结论；8/8拆分只是已有输出的条件稳定性诊断。

**讨论优先级（不执行新方案）**

1. **先问候选动作/训练支持层**：现有动作在剩余困难群体提供了正确修复对比，还是主要改变复制、破坏和关系满足？
2. **再问估计/学习器层**：小幅、少数题主导的动作差，能否被效用调参分辨，而不是被噪声与平局规则主导？
3. **随后问表示层**：保持reward权重可比时，新增B/M结构是否对应动作收益？非冗余信息不自动等于选择信息。保留pX目标，不造综合分追认胜者。
