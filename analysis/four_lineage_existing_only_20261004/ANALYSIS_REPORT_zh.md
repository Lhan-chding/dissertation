# 首四条 lineage：已有数据中的零选择增益诊断

日期：2026-10-04。执行类型：**EXISTING DATA ONLY**。研究单位为4条开发lineage、8个相关原点；本报告是描述性诊断，不是最终T测试，也不输出总体显著性结论。百分比用于概率，**pp表示百分点**；CSV概率差均保存0–1尺度。

## 1. 结论与本次新增信息

当前“零增益”首先是一个精确的决策事实：保存的Z0–Z3在32个原点×信息层组合中均选择各折BestStatic，因此引用相同已运行端点，选择收益差恰为零。这并不意味着各动作效果相同、修复信息不存在，或奖励训练没有任何改善。

本次结果支持两个同时存在的瓶颈。**动作与训练支持侧**：晚期剩余错误集中在两个符号群体，现有11配方均未使其中28题产生一次X；无X训练组在整个32步窗口均未观察到F=1。**估计与学习器侧**：保存模型的状态修正很小，效用调参大量平局/近平局，Z2/Z3强收缩；但既有弱alpha没有显示稳定选择收益，故不能仅归因于alpha过大。前置修复信息可辨识，但晚期主要是B/M结构，不能直接等同于“哪一动作能提高pX”的信号。

下一次讨论**首先应定位候选动作及其训练支持层**：这些动作是否提供了对剩余困难群体真正不同、且有正确修复对比的干预？在此基础上再讨论估计/学习器是否能分辨小幅排序，以及表示比较中的reward权重混杂。保留pX主目标；本次没有依据支持改造综合分追认胜出。此优先级是跨表证据形成的讨论判断，不是已识别的因果排序，也不执行任何新方案。

## 3. 动作机会：差异存在，但晚期集中在少数混合题

### 3.2 逐题分解与差值来源

[prompt_effect_contributions.csv](prompt_effect_contributions.csv)有12,672行：8原点×11动作×144题。固定六群体各24题，所以每题权重为1/144；`contribution=(candidate pX−R0 pX)/144`。每原点/动作的贡献和与宏观delta_pX一致，最大浮点误差约1.01×10⁻¹⁶；结构差值逐题另列，不被混入主目标。

[prompt_posthoc_classes.csv](prompt_posthoc_classes.csv)按阶段44个H32端点×每题16输出分类：

|阶段|全X题|未见X题|混合题|未见X题贡献错误/该阶段全部错误|
|---|---:|---:|---:|---:|
|早|43|20|81|14,080/24,023 = 58.61%|
|晚|108|28|8|19,712/21,672 = 90.9561%|

晚期28题为cross_series/SYMBOLIC 13题与trend/SYMBOLIC 15题；每题在44×16=704条输出里未见X。它们与108全X题在现有配方之间的**pX差贡献均为零**；晚期所有观察到的动作差都来自8混合题。这是事后H32诊断，不是事前特征，不证明真实成功概率为0或1。

把晚期40个非R0“原点×动作”对比的逐题贡献绝对值求和，前两题占84.44%，前三题占95.11%。前两题分别是cross_series/SYMBOLIC的`2a54f9a7…0c4c6`与trend/SYMBOLIC的`0fc63ab3…519fc`（均difference_pairs）；第三题`0c50c720…f74a`是trend/IMAGE、range4。完整ID与各原点正负方向见贡献表。这里是**绝对差值质量**，不能当有符号总收益，也不是独立样本。单个非零晚期对比达到80%绝对差通常仅需1–4题；早期需13–26题，零差对比为0。见[prompt_effect_concentration.csv](prompt_effect_concentration.csv)，`stage`及`branch_recipe!=R0`。

六群体定位也有结构差异：晚期R0的cross_series/SYMBOLIC pX=38.6719%，有效copy=46.9251%，坐标准确率79.2318%；trend/SYMBOLIC pX=33.7240%，copy=8.2203%，坐标准确率51.7253%，全关系成立却错误占13.0859%。两者不能笼统归成同一种“修复失败”。分母与F/B/M见机会表对应六层行。

## 5. 保存选择器：状态信息被用了多少？

[saved_prediction_decomposition.csv](saved_prediction_decomposition.csv)逐行复算`Y_a=J_a−J_R0`及`prediction=mean+k_query_train@beta`，256行与旧预测最大误差0；16个K与保存gram最大误差0，保存beta方程残差约3.47×10⁻¹⁸。未调用fit或solve。32个保存选择的预测第一名本身就是BestStatic，tau回退0/32，故“仅因tau强制回退”的解释可排除；状态修正非零，故也不能说模型完全没用状态。

每折n=6；Z2/Z3 alpha=10，ridge=nα=60，edf=Σλ/(λ+nα)，不含独立均值项。中心化谱仅来自HKH的描述，**未拟合中心化模型**。Z1较大端点对应一个alpha=1折，其余为10。见[kernel_geometry.csv](kernel_geometry.csv)，`component=TOTAL,stratum=ALL`。总mean diagonal均1.5，但谱不同；同名alpha不代表各组件保留了相同有效状态方向。

当前reward核正非对角相似度81.800%来自X–X项，repair为80.331%；repair边缘项按来自X的质量拆分embedding，分子不含X–非X交叉项。它们不是“H32全X题占比”。另一方面，固定的trend与cross_series两个SYMBOLIC层占reward/repair状态平方距离80.591%/83.905%。总体相似度由正确输出质量主导，区分状态的变化集中少数群体，支持表示有稀释结构的可能性；不能据此认定改变表示会改善收益。见核表`component=current/repair,stratum!=ALL`及[kernel_pair_geometry_D.csv](kernel_pair_geometry_D.csv)。

Z3把reward current权重从1降为0.5，reward history从0.25降为0.125，同时加入repair及repair history；所以Z3−Z2混合了“加修复”与“减奖励权重”，不是纯增量信息对照。

[existing_tuning_diagnostics.csv](existing_tuning_diagnostics.csv)显示外折6个alpha效用全平局7/16，近平局合格集合有多个alpha为15/16；48个内验证组合全平局38/48。保存规则从合格集合选更强alpha。这是已运行调参的复读，没有新搜索。

原有最弱alpha=0.0001使Z2/Z3各8/8原点的完整动作排序变化，5/8第一名变化，但只有1/8最终动作变化；8原点平均相对BestStatic的既有开发结果为−0.005425 pp。故强收缩有直接证据，**“调弱alpha即可恢复收益”没有证据**。这仍是事后敏感性，不是弱alpha的新验证。详细组件尺度与原表行组见[D_FINDINGS_zh.md](D_FINDINGS_zh.md)。

## 7. 相同面板时间变化与既有成本

[matched_panel_time.csv](matched_panel_time.csv)严格在共同24题比较H8每题8输出与H32每题16输出。44个早期端点的同题pX变化均值+5.0308 pp、范围−0.7813至+11.4583；晚期均值+0.0414 pp、范围−2.0833至+1.0417。每原点×配方及六群体逐行保留，样本量不同带来精度差异。这不等于整体D提升，也没有相减完整P与D均值；早晚用不同源状态，不能推成同一条训练曲线。

[cost_existing_only.csv](cost_existing_only.csv)按成功记录累计**单GPU作业工作小时**：分支训练432.942小时，其中生成测得57.492小时，sampling总体77.169小时（含生成），更新355.699小时，段内其他0.074小时。sampling减生成的19.677小时包含未分开的评分/准备/检查等，不能把它全称评分。源训练另50.086小时；H8/H32/P/E保存sampling总计分别14.220/172.462/31.399/29.827小时，不混成并行墙钟。

分支精确零优势1,241步的更新耗时159.255小时，仅为**已有优化机会的计量**，不是已可节约时间。两个GDPO微小非零更新仍保留，最小绝对非零优势4.42×10⁻¹⁸，对应总更新0.2107小时。没有实现跳过反向，没有等价性实验，也不以零梯度推出参数零变化。额外scored_sequences=0仅指额外模型重评分，不代表所有语义评分耗时为零。独立评分/加载和可合并墙钟缺项见input_scope与CF说明。

## 8. 原因边界与下一次讨论顺序

|候选解释|当前证据状态|可说什么；仍缺什么|
|零收益仅由tau回退|已排除|32/32预测第一名已是BestStatic，回退0|
|保存预测复算错误|本次未发现|256预测、16K、均值目标复核一致；不是重新证明所有历史实现无错|
|所有动作完全相同/根本无机会|已排除极端说法|已有非零差异；但晚期差值集中8混合题，带噪上限很小，稳定机会未识别|
|晚期无X组仍有充足正确修复正例|与记录不符|0/845组观察到F=1；39全I组缺失，不能扩展为总体不可能|
|训练所有结构信号均消失|已排除|B/C变化、W/S正优势仍存在；其对pX的作用未知|
|修复信息完全由reward决定|已排除|P同题同原子多FBM反例存在；有效选择信息量尚未识别|
|学习器强收缩|直接支持|状态修正/edf/谱及平局规则一致；单改alpha有效性未证实|
|总体表示稀释困难层|受支持的可能机制|X–X主相似度、符号层主差异；未做反事实表示，Z3另有权重混杂|
|排序和条件分布计数噪声重要|受支持|8/8部分反转、同支持距离修正明显；不能分摊噪声导致的因果份额|

讨论先问候选动作/训练支持：**在未见X的两个符号群体中，现有动作究竟有可利用的正确修复方向，还是主要重新分配复制、破坏与关系满足？** B/C显示这一问题先于把稀疏结构交给更灵活选择器，但没有证明动作空间必然不足。

第二问估计/学习器：**在只有4条lineage、晚期主要由少数题决定的亚百分点动作差下，效用调参能否识别状态修正而不被平局和计数噪声主导？** D的强收缩是真实事实，旧弱alpha表现又阻止把它认作唯一原因。

第三问表示：**在保持reward信息权重可比的条件下，同reward的B/M差异究竟对应可选择的修复收益，还是只描述不同失败形态？** 当前Z3对照有混杂，E只证明非冗余，不证明决策充分性。目标层目前保留pX；需要讨论的是固定宏观目标如何呈现局部机会与剩余错误，而不是新造综合分改变胜负。

动作差太小、训练支持缺口、表示稀释、强收缩与噪声可同时成立，现有记录不能给它们分配唯一因果贡献。以上问题留待讨论；本次全部工作止于已有数据分析。
