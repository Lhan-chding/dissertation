1. 一页执行摘要：实际完成的路径/更新/生成数与固定分母、是否发生技术偏离、唯一主比较及其条件区间、四个配对块、是否存在保留或报告遵从的代价。注明只是两个固定J6父模型的探索性训练实验。
2. 输出 RUN_BINDING.json、PNG/processor与旧96张原图绑定、烟测所有回执、澄清四格及配对差中差、训练逐步commit、各端点身份、完整失败与重试日志。不把技术漏行填为模型判错。报告实际运行时间/硬件/峰值显存/CPU与GPU时数、所有尝试与成功的生成token。不设GPU小时科学停止线。
3. 主表：transfer8/conflict/24步的R、G、D和PARENT水平；D−G点估计与95%条件区间；b0×11031/11032、b1×11031/11032全部列出。每臂三种基线角色不同；父模型是未继续训练的参照，不是新增训练重复。加上12步轨迹，但不能拿更好的时间点替换24步。负值与未知保留。三臂、两个已选父、两个训练种子不能当成十二个独立总体样本。
4. 机制表：每种训练处理的真实槽位数、预定清单冲突机会及根题、模型实际输出与诱导集合一致/不一致/不可判，按前中后8步分层；每组J=0..8条成功数、对应A/S/B、协议/证书诊断。D与G相同输入但后续策略不同，不要求后续回答相同。不能用某个添加项的标量值估算梯度份额。
5. 迁移与保留表：逆字母相容/冲突各自的A、S、B、U、A并U、UNKNOWN，以所有被分配回答为分母；10类单列，名单作为合法来源单列；swap8两两/四格同draw均正确；前缀三条件分别报告原格式、原A、S_hit、已知率、绑定、后验/严格诊断分开、上下界。选对但答错、答对但错选/错绑同时报告。来源读数诊断不等于完整视觉感知，真实前缀不能算自发感知。
6. 特别分离：原生历史 J 只用于兼容任务；名单合法参照等新语义、10类不能伪装为 J。全分母比较主分；“已知者中率”和“补括号结果”只能并列作解释。保留集合完全相同但证据顺序不同、完整报告仍选择错误、冲突报告且结果正确等反例。
7. 给下次讨论的可定位案例：事先按 root_id/parent/seed/view/draw 排序，在每个可用类型内取前3个；若没有则报0，不能另外反复采样。每例附实际输入图片引用、prompt、原文、诊断推导与qid/request_id，可比较D与G；区分可观察声明和内部过程。诊断为筛选案例而非总体估计。
8. 轻量复算包至少含原回答投影、评分明细、冻结清单与版本、统计代码、表和路径映射；大张量/权重留服务器并给检查点摘要。生成 REPORT_zh.md、analysis.json、all_endpoint_levels.csv、paired_blocks.csv、dose_by_step.csv、resources.json、deviations.json、completion_receipt.json。若真实阶段阻断，给 PARTIAL 状态与剩余分母；不得用合成测试示例作真实结果。
